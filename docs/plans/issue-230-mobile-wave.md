## 5. 移动规范草案(阶段 2 拍板后落 `docs/frontend/conventions.md` 新增「移动端」节 + `index.css` token)

1. **命名断点**(审计 §1.3):`--bp-phone-s` ≤ 480 / `--bp-phone` ≤ 767 / `--bp-tablet` 768–1024 / `--bp-shell` ≤ 1024(壳开关,JS 与 CSS 共用)/ `--bp-desktop-m` ≤ 1280;收编现有 10 个 `@media` 宽度取值,1023 / 1024 双口径归一;容器查询(早报 960 / 680 / 420、播放条 640 / 900)保留。实现方式(Tailwind v4 `@custom-media` / `@theme --breakpoint-*` / JS 常量)阶段 3 定。
2. **触控目标**:主要动作 ≥ 44×44,行内次要 ≥ 32 并以 `::after` 扩命中到 44;所有输入控件字号 ≥ 16px;列表行 / 源行 ≥ 44(48 更佳)。
3. **悬停语义**:装饰性 `:hover` 一律包 `@media (hover: hover)`;功能性悬停入口(显隐 / 改文案 / 位移)在触屏**常显**;破坏性动作触屏两击确认或 toast 可撤销;eslint / 守卫脚本拦新增无守卫 `:hover`。
4. **层原语**:sheet / drawer / page / popover 四种,统一经一个组件 / hook 负责 `useLayerHistory` 握手(返回先关最上层)、遮罩「按下与松开同在遮罩」判定(同 `Modal` / `utils/overlayClose`)、`useModalA11y` 焦点与 Esc、下层 `inert`;`Modal`、分享浮层、往期月历、灯箱、动作单、抽屉全部改走它;每层在 iOS PWA 独立窗口下必须有可见关闭。
5. **视口与安全区**:移动可达的高度一律 `dvh` / `svh`;壳与 TabBar / 顶栏 / 坞垫全部四向 `env(safe-area-inset-*)`;横屏播放条默认迷你。
6. **字号刻度**:移动壳只用一组刻度(待随视觉方向定,目标 ≤ 8 档,现状 22 档),字重 400 / 600(早报头条 900),字体栈只用 `--font-sans` / `--font-serif`。
7. **动效**:全部受 `data-motion` 开关;清单随视觉方向拍板(样页 README「动效清单」);退场与入场成对。
8. **验证基线**:`scripts/check_mobile_reader_e2e.py` 扩到 375 / 390 / 360 / 412 四档 + 亮暗,断言:无横向溢出、触控目标、输入字号、返回键矩阵、长按动作单保持、安全区、DOM 规模;真机清单(审计 §6 R-01 ~ R-20)作每次移动波的验收模板。
