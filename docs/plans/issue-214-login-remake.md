## 1. 目标与边界

- 保留:深空主题、鼠标运镜(横移偏航、纵移推轨)、左题词右玻璃卡、三幕演出、蒙眼彩蛋、失败撞偏、成功跃迁后交给 App 抵达幕的时序(`WARP_FLASH_MS` 1500 / `WARP_DONE_MS` 2140 与 v1 相同),文案基本不动。
- 必须保留 #213 的两组游客入口:登录按钮下方小字「游客登录」(`guestEnabled` / `onGuestEnter`,`.guest-enter`);叠层登录(`fromGuest` / `onBackToGuest`,`.guest-login-layer`)卡顶「返回继续逛逛」(`.guest-back`)。`LoginScreen` 的 props 契约不变。
- 约束:品牌豁免(配色与动效硬编码、不随减少动效降级,2026-07-25 拍板)沿用;不引第三方库(原生 WebGL1);标签页隐藏时 rAF 自动挂起;读者面文案不漏内部架构词;新增动效不写 OS 媒体查询。
- 不做:注册入口、第三方登录;改动 App 抵达幕(`.app-arrive*`、`.auth-warp-flash` 原样保留)。

## 2. 旧版问题盘点(重制前截图对照)

- 星座按屏幕距离临时连线,镜头一动就闪烁重组;景深偏平;固定盒子绕中心转,偏航久了推轨变成横移、画面变稀。
- 标题「让AI资讯」缺空格;徽标「语义检索」与现状不符。
- 手机:hero 占满首屏、表单在折线下(#230 审计 M-16,归本波);桌面卡等比缩小,四周留边、眉题 / 字段名 / 页脚照搬;离场光轨的消失点会偏。
- 全局 `html { scrollbar-gutter: stable }` 让独立登录页右侧露出一条浅色槽。

## 3. 方案

### 3.1 场景引擎 `frontend/src/components/login/deepSpace.js`

`mountDeepSpace(canvas, { arrival })` → `{ live, cleanup, setVeil, ping, kick, startWarp, setAnchor }`。以摄像机为中心、环面回绕的三维星场(尘埃 / 场星 / 星图三类),星图是三维里成组的真实结构(每组 4–8 颗树状连线),开场按落定取景预置几组保证构图。WebGL1 两个程序:背景(近黑底 + 跟随登录卡的靛辉 + 开场在 GPU 上烘焙一次的圆柱全景星云)与胶囊精灵(星点 / 景深光斑 / 运动光轨 / 连线 / 脉冲同一图元,一次 drawElements,加色混合)。

- 演出接口:开场「跃迁抵达」;`setVeil` 密码聚焦失焦;`ping` 键入时一道信号沿星图连线跑过;`kick` 失败撞偏 + 琥珀星闪红;`startWarp` 跃迁离场。
- 触屏:只认同一次按压之内的滑动(横滑转头),两次轻触之间的跳变不注入;不做指针视差。离场时偏航(含环境自转)0.35s 内归零、视差归零,光轨严格从屏幕中心放射;竖屏另加一枚紧致光核做焦点;速度光按短边归一。
- 兜底:空闲 12s 降半帧率;前 140 帧平均帧间隔 > 24ms 降到 1× 像素、尘埃减半;像素量封顶 7.2e6;无 WebGL / 着色器失败退 Canvas 2D 静止一帧(`live = false`,成功登录不演跃迁直接进入);处理 context lost / restored;画布真正离开文档才 `loseContext`(兼容 StrictMode)。

### 3.2 版式

- 桌面:双列(左题词贴合内容、右卡 340–432px,最大宽 1140)。平板横屏仍双列;平板竖屏单列居中卡。原 880px 私有断点并入命名档(`bp-phone`、`bp-tablet` + 竖屏),`breakpoints.test.mjs` 私有例外只剩榜单 1120。
- **手机竖屏(`bp-phone` + 竖屏)= 原生形态**:上半屏品牌区(logo 在上、字标在下、标题、引言,在剩余空间里垂直居中);登录表单是贴底的玻璃底页(顶部 28px 圆角、透出星空、按钮在拇指区),去掉眉题与页脚,字段名只留给读屏,控件 52 高、「游客登录」命中 44 高;顶沿光唇代替桌面卡的一周描边。矮屏按高度收起引言(≤ 660)与副题(≤ 580)。触屏输入框 16px(低于它 iOS 聚焦放大整页)。引言按分句成块换行。
- **触屏键盘态 `.is-kbd`**(粗指针聚焦输入框):品牌区收成 46px logo(蒙眼彩蛋仍看得见),底页标题 / 副题收起、底页上提铺到底,输入框与按钮在软键盘之上;FLIP 补间;失焦 260ms 后才展开;收起用「脱离文档流 + 隐身」,不用 `display:none`(否则逐字显影 / 品牌凝聚 / 条目就位的动画在展开时重播)。
- 矮横屏(横屏且高 ≤ 500):双列紧凑,题词只留品牌与标题,卡去掉眉题 / 副题 / 字段名 / 页脚。
- 独立登录页 `scrollbar-gutter: auto`(`html:has(.auth-stage):not(:has(.guest-login-layer))`)。

### 3.3 演出

分镜见剧本 v2 节。要点:跃迁抵达 → 题词逐字显影(按实测位移居中)→ 登录卡浮现(桌面描边沿一周画出、光头化作环绕彗星;手机底页自屏底滑上、顶沿光唇自中点亮开)→ 品牌名凝聚 → 跃迁离场。手机离场:收起软键盘,底页沉下、文字散去,logo 压在底页之上飞到屏幕中心(消失点)、轨道环荡开,随后没入光核,再接平色幕布。
