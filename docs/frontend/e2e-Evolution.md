1. **手机 → 桌面覆盖阅读快照**：旧移动 DOM 会先按新宽度重排并派发 scroll，媒体查询通知稍后才换视图。实测原进度约 0.275 被旧 DOM 的约 0.366 覆盖，阅读章节 07 跳到 09。修复为仅在 DOM 版式仍与当前媒体查询一致时记录滚动快照；断言同时检查进度和附近章节，不只比较数值。
