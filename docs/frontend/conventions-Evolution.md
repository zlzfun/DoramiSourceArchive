# conventions Evolution

## 2026-09-20 · 未就绪态动作占用 mini-seg 槽位

- 发生：issue #122 读者点播首版用整宽 `.action-button-secondary`；用户反馈「点播按钮太大了完全不符合我们要求的前端设计的原则」。
- 分析：播放器里已有「原节目 / 精品导读」`mini-seg`；未就绪时另开 L/M 档次按钮抬高视觉权重，违背轻量密度与「勿再造」。同一槽位可表达可点播 → 生成中… → 已就绪切换。
- 改变：`conventions.md` 微型分段条补充——播放器内未就绪态动作优先占用既有分段槽位，不另开整宽次按钮。
