## 1. 为什么做

2026-10-13 从设计与审美的角度审视存量前端,结论是**不缺设计,而是同一类东西有好几种画法**:阅读器一屏 4 种字体族、
5 种底色、3 种标签画法、2 套选中语法;元信息约 50 处小于 12px;Mac 与 Windows 字体呈现不一致(#176)。
方向是收敛:同一类东西只留一种画法,高级感主要来自一致。

## 3. 字体基础设施(#176 W0a + W0b)

### 3.1 自托管思源宋体「Dorami Serif」

- 来源:google/fonts 固定提交 `2e61f43`(Noto Serif SC 2.003,SIL OFL 1.1)的可变字体,sha256 `050080d9…`。
- 生成:`uv run --with fonttools --with brotli python scripts/build_dorami_serif.py`——实例化 600 / 900 两个静态字重,
  按 `scripts/fonts/noto_serif_sc_ranges.json`(Google Fonts 对该字族的 101 组按字频 unicode-range)切 WOFF2,覆盖全部 30928 字符。
- 产物:`frontend/public/fonts/dorami-serif-v1/`(202 片约 6.35MB + `dorami-serif.css` + `OFL.txt`),Vite 原样拷进 dist;
  `index.html` 直接引用样式表。目录名带版本号,换字体或字重时把脚本里的 `FONT_VERSION` 加一。
- 字体样式表单独成文件:两档字重的 unicode-range 声明约 200KB(gzip 62KB / brotli 18KB),不并进主样式;
  SPA 首屏要等 JS,这条样式表并行加载不拖慢可见内容。
- 浏览器只下载页面实际用到的分片:一期早报标题约 17 片 / 0.75MB(冷缓存),之后缓存;
  nginx(Docker 与裸机两版)对 `/fonts/` 给 `expires 1y`、缺文件 404。
- 未加载完时的回退:`Dorami Serif → 宋体-简(Mac)→ 雅黑(Windows)`,不落到没有粗体的中易宋体。

### 3.2 W0a(栈、字重、字号、层叠)

- `@theme` 重定义 `--font-sans`(系统黑体,西文在前)与 `--font-serif`,新增分数字体 token `--font-score`;
  `App.jsx` 的 `font-sans` 不再遮蔽为 Tailwind 默认栈;阅读正文的 SF Pro 栈并入 `--font-sans`。✅
- 字重只用 400 / 600(宋体海报头条 900):index.css 248 处、mobile.css 与 JSX 原子类归并。✅
- 字号下限 12px:241 处;豁免来源字母徽标、头像字母、▸ / 排序箭头与登录品牌演出。✅
- 未分层 `font: inherit` 退役(preflight 在 base 层已有同一条)。退役前后对 21 个页面导出按钮 / 输入框的计算字号字重做差异,
  就地改正「从未生效、一生效就不对」的几类(带拇指的分段字重恒 400、导航 / 筛选未选 400 选中 600、输入框正文 400、次按钮 400 主按钮 600、

  全局开启会改动所有中西混排的间距,日期与数字要逐处豁免,且与 Mac / Windows 一致性无关(两端都是 Chromium 系)。记入 backlog。
- 护栏:`frontend/test/typography.test.mjs`(字重 / 字号 / 陷阱回潮 / 同源字体 / 字体 token)+ eslint(`font-medium|bold|extrabold`、

## 5. 这一波不做

- 早报条目配图缩略图(需要早报接口提供首图与尺寸)。
- 自托管黑体(按 #176 的门槛:Windows 实机验收发现粘连、层级难辨或截断再议)。
- 登录页与品牌演出(品牌豁免)。
- `text-autospace`(见 §3.2)。
- 尾区「阅读器按钮字号」历史钉法并回层内(值仍有效,改到哪条并哪条)。
- 管理面死类清扫(`.field-box` / `.source-*` 目录族 / `.scope-toggle` 等;字体扫描时一并统计在案,不影响渲染)。

## 5.1 实现中的取舍

- **早报头条**:降级版面(订阅源最新更新)不设头条,头条位如实写「今天没有达到入选标准的内容」——没达标的内容不该被印成头版;
  只有深度阅读 / 播客精选时取其中最高分作头条。海报与条目新增收藏(与条目列同一份收藏状态)。
- **移动壳早报**不再叠「我的早报」顶栏,眉头(早报 · 日期 · 往期)即顶栏;窄宽下「重新编排」只留图标(可访问名不变)。
- **发现页**按定稿撤掉单独的「预览」钮,整卡点开即预览;名称按钮是唯一的「打开」控件,订阅钮浮在覆盖层之上。
- **账户增长**仍是「两量一张图」(v3.55 拍板):累计画阶梯线,新增作为抬阶处的「+N」标注,不再柱线双轴;阶梯从窗口前的存量起步,
  窗口第一天就有人加入时那一阶也看得见。
- **导轨微标签**随字号下限从 10px 到 12px(悬停整面揭示的机制不变)——这是 #176 Windows 可读性的直接要求,目检时请留意。
