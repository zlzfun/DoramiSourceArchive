## 1. 为什么做

2026-10-13 从设计与审美的角度审视存量前端,结论是**不缺设计,而是同一类东西有好几种画法**:阅读器一屏 4 种字体族、
5 种底色、3 种标签画法、2 套选中语法;元信息约 50 处小于 12px;Mac 与 Windows 字体呈现不一致(#176)。
方向是收敛:同一类东西只留一种画法,高级感主要来自一致。

## 3. 字体基础设施(#176 W0a + W0b)

### 3.1 自托管思源宋体「Dorami Serif」

- 来源:google/fonts 固定提交 `2e61f43`(Noto Serif SC 2.003,SIL OFL 1.1)的可变字体,sha256 `050080d9…`。
- 生成:`uv run --with fonttools --with brotli python scripts/build_dorami_serif.py`——实例化 600 / 900 两个静态字重,
  按 `scripts/fonts/noto_serif_sc_ranges.json`(Google Fonts 对该字族的 101 组按字频 unicode-range)切 WOFF2,覆盖全部 30928 字符。
- 产物:`frontend/public/fonts/dorami-serif-v1/`(202 片约 6.35MB + `dorami-serif.css` + `OFL.txt`),Vite 原样拷进 dist;
  `index.html` 直接引用样式表。目录名带版本号,换字体或字重时把脚本里的 `FONT_VERSION` 加一。
- 字体样式表单独成文件:两档字重的 unicode-range 声明约 200KB(gzip 62KB / brotli 18KB),不并进主样式;
  SPA 首屏要等 JS,这条样式表并行加载不拖慢可见内容。
- 浏览器只下载页面实际用到的分片:一期早报标题约 17 片 / 0.75MB(冷缓存),之后缓存;
  nginx(Docker 与裸机两版)对 `/fonts/` 给 `expires 1y`、缺文件 404。
- 未加载完时的回退:`Dorami Serif → 宋体-简(Mac)→ 雅黑(Windows)`,不落到没有粗体的中易宋体。

### 3.2 W0a(栈、字重、字号、层叠)

- `@theme` 重定义 `--font-sans`(系统黑体,西文在前)与 `--font-serif`,新增分数字体 token;消除 `App.jsx` `font-sans` 遮蔽;
  阅读正文 SF Pro 栈并入。
- 字重只用 400 / 600(宋体海报头条 900);归并 500 / 550 / 650 / 700 / 800。
- 字号下限 12px(来源字母徽标例外)。
- 未分层 `font: inherit` 迁入 base 层,逐项核对计算字号;试移除 `-webkit-font-smoothing`;开 `text-autospace` / `text-spacing-trim`。
