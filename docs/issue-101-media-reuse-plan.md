# Issue #101：接收端文件复用与同步进度

实现基线：`cdc2a71`。内网接收端默认 local；兼容现有 OSS 写入、缓存读写租约与元数据条件更新。

## 实现边界

- 整页校验与元数据事务保持。文件依照已接纳的 authority、清单大小、SHA-256、MIME/扩展名检查。
- 校验本地内容寻址文件；完整则复用并完成状态登记，否则下载、验证、唯一临时文件原子替换。
- 本地校验按块读取，文件读写及 OSS 持久化期间持有缓存租约；文件 I/O 不持有数据库读事务。
- 复用与下载共用状态提交，提交时条件匹配原始身份、权威及版本，不能覆盖并发新清单或音频撤回。
- 不提前推进 checkpoint，不改变数据流顺序，不加入日期过滤或下载并发。

## 进度契约

Job 增加可空 `progress_json`（配套 Alembic），接口新增 `progress`。
V2 上报绝对累计已处理记录数、当前流及该流已处理记录数、复用/下载文件数及字节数。
阶段切换和首条完成立即落库，其余沿用任务进度节流；失败终态保留最后成功进度。
文件完成状态提交后才计数，媒体页尾不再次累计。音频 tombstone 计入记录数但不计为文件。
前端显示当前阶段和实际计数，不从当前页大小推算全任务百分比；V1 与旧任务保持原有展示。
