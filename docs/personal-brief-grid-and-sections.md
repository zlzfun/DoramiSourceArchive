# 个人早报:板块顺序、分值驱动网格与公共日报排除(issue #74)

> 状态:PR #80 检视收口,待合入(分支 `feat/issue-74-brief-grid`,2026-09-14 实现,2026-09-15 检视)。样页 `docs/design/dorami-brief-grid-quiet.html`
> (六种策略对照 + 「同一张数换分数」画板 + 整页节奏,策略 F 为拍板方案)。

## 0. 起因

用全新账号 `test01` 看生产早报,三处问题:

1. 「哆啦美 · AI资讯日报」出现在个人早报里;
2. 同一板块四张卡在三列容器下呈「3 + 1」,右下角大片留白;
3. 「学术论文 / 行业资讯 / 模型发布」板块顺序每天不同。

读码结论(issue #74):① 候选查询只在全站分支排除日报,订阅池分支没有,而默认订阅第一项就是日报、分析补偿扫描也不排除
`daily_brief` 体裁;② 网格是 `auto-fill minmax(320px)`,布局层不知道余数,只有「头版通栏」「单卡通栏」两条规则;
③ 板块按条目首次出现建组,`position` 是通道顺序(重大事件 → 兴趣 → 质量)的副产品,板块顺序随当天最高分条目的体裁漂移。

## 1. 公共日报排除

- **范围层一刀切**:`resolve_personal_digest_source_ids` 剔除 `dorami_daily_brief`——它是文章容器的主菜,不是早报素材;
  报头「订阅的 N 个来源」也不再数它。
- **机械双保险**:`_query_candidate_rows` 两个分支与 `_load_latest_fallback` 都显式排除。
- **退役** `DigestGenerationReason.DAILY_BRIEF_READY` 触发链(`notify_public_daily_brief_ready` 与日报落盘后的调用、
  `calculate_due_source_ids` 的日报特例):它的存在前提是「日报能进早报」;枚举值为历史行保留。
- 不动默认订阅名单;不在分析入队层堵体裁(日报以后若要在阅读器挂分数 / 标签不该被堵死)。
- 升级当天的副作用:升级前冻结的今日版本 `expected_source_ids` 含日报,与当前解析结果不等 → `scope_stale` 提示
  「你的订阅已更新,下次编排生效」一次,读者点重编或次日即消失。

## 2. 板块固定顺序 + 板块内分数降序

`digest_selection.SECTION_ORDER`(单点,与 `GENRE_SECTIONS` 同处):

重大事件 → 模型发布 → 行业资讯 → 开源动态 → 学术论文 → 工程实践 → 观点洞察 → 技术大会 → 社交动态 → 资讯聚合 → 其它 → 订阅源最新更新

「发生了什么」在前,「怎么看」在后。落库前 `_assign_positions` 统一重排:板块按序,板块内按分数降序、缺分殿后、同分保序;
通道不再影响顺序(兴趣命中靠卡头「兴趣 · 标签」标识)。记录在重排前刻意不 `session.add`——三段构建之间的查询会触发 autoflush,
先按临时 position 写入再改写会在 `(edition_id, position)` 唯一键上互撞。历史版本不回填;前端分组时按快照分数再排一次,
老版本也得到同样的版式前提。

## 3. 分值驱动网格(策略 F)

网格改 6 等分单元,`utils/briefGrid.planSectionSpans(scores, cols)` 给每张卡 `--span`(2 小卡 / 3 半宽 / 4 ⅔ / 6 通栏):

1. 分数 ≥ **T = 9.0** 独占一行(与「9+ 完整渐变」同档:见渐变即值得看,通栏是同一个信号);
2. 两卡并排,分差 ≥ **Δ = 1.0** 用 ⅔ + ⅓,否则各半(一个整数档;复评有 ±0.5 摆动,更小的差异不该驱动版式);
3. 余 1 时头卡比第二张高 ≥ Δ 才通栏,否则头两行改 2 + 2,每行再按 2 定;
4. 余 2 时头两张按 2 配对;整行恒三小卡。

每一处横跨都有理由:通栏 = 过线或高出一档,⅔ = 比同行高一档,各半 = 咬得紧;「2 + 2」只在四张分数都接近时出现。
头版(整报第一板块首张)恒通栏并放大字号,板块规划的是它之后的卡。≥ ⅔ 宽才分栏(分数进右栏,⅔ 卡右栏 150px);
半宽不分栏。列数由 `ResizeObserver` 量报纸面内容宽给出(3 ≥ 988 / 2 ≥ 654 / 1,与旧断点一致):两列只保留通栏 / 各半
(⅓ 只有 246 宽放不下衬线标题),单列全部通栏、只有头版分栏(移动壳 CSS 显式 `1 / -1`,免得 6 等分 span 撑出隐式列)。
骨架屏没有分数,固定画「通栏 + 一行小卡」。T 与 Δ 是常量不是旋钮——视觉刻度随尺子版本走,不随运营参数走(v3.54 同一口径)。

明确不做:板块间借条(破坏板块语义)、按运营旋钮联动阈值、后端算版式(版式是呈现层的事,快照里有分数就够)。
