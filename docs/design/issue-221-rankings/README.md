- 直接双击 `index.html`(file://)即可,单文件、离线可开:字体按用字切子集内嵌,图标内联,不请求任何外部域名。

  样页里不存在的去处(读一篇、点源栏)会弹一句话,交代实现时去哪。
- 每个画框下方列着「这一屏的人工处理」,随所在段变化。

## 三个方向

### A 同页三段——改动最小

- 分段 热点 · 文章榜 · 播客榜,热点默认。文章榜 / 播客榜保留 话题 · 产业 · 实体,标签行换成上面的标签卡;点开是趋势加高分内容。
- 段末「必读 / 必听」按事件去重。全局高分榜删掉:生产 10 条里 8 条是 GPT-6 同一系列(9 月),全站历史几乎不动。
- 观感:最像现网,读者不用重新学。但文章榜仍在回答「哪些标签出现得多」——话题轴头部「AI 智能体」85 次、「大语言模型」42 次天天在;播客话题轴 10 项里 9 项各 1 次、1 个来源,标签卡几乎是空的。

### B 热点 + 好文——文章榜改定位

- 分段 热点 · 文章 · 播客。文章段 =「近 7 天值得读」前 10,同一事件只留一篇,卡上写「另 N 家报道」,点它开该事件详情。
- 标签降成列表上方一条「风向」签:三轴里 ≥ 3 次、≥ 2 个来源、较上周(前 7 天)次数上升的标签,按增量排,至多 8 枚。点一枚列表换成该标签的高分内容,再点取消。
- 播客段同构「近 7 天值得听」。播客够门槛的标签只有 2 个、升温的 1 个,风向整条不出——这本身是结论:播客的标签口径撑不起风向。
- 观感:三段里信息量最高,打开就是能读的东西。弱点在去重:见下「数据告诉我们的」第 2 条。

### C 一页总览——不分段

- 一页:热点前 5 → 本周好文前 5 → 话题风向(三轴各前 5,紧凑行)→ 本周好听前 3。每块「全部 →」进完整列表(就是 B 的对应段,带返回)。
- 桌面双栏:左 热点 + 好文,右 风向 + 好听。手机按序堆叠,风向块用 话题 / 产业 / 实体 分段,只露一轴。
- 观感:桌面一屏看全貌,很舒服;手机要往下滚三屏,完整列表多一层进出。手机页头是纯标题「榜单」,没有转盘。

## 人工处理 / 近似 / 示意(页面画框下也写着)

- **「值得读 / 值得听」是近似**:线上没有这个列表,需后端新增。样页把三轴 30 个标签的高分内容取并集(文章 176 篇、播客 27 集)按分排序。
- **按事件去重只用平台真值**:文章 id 出现在已拉事件的 `members` 里才算同事件;同事件留分最高的一篇。只有近 7 天前若干大事件的归组可得,其余按单篇。
- **「另 N 家」**= 该事件其余可见发布主体数。
- **热点卡的「最新」一行**取自详情接口:榜单项还没有 `latest` 对象(方案 §5 的契约小改)。
- **只有 3 件**:截取真实榜前 3,不补位、不拉伸。**空榜**:生产今天是满榜,按空态口径画。
- **示意件**(默认关,开时虚线框 + 「示意」签):接前报、「同一发布还有一集播客 / 一篇论文」都没有数据。标题借自真实条目:
  第 7 件接前报借「Claude套餐大升级！Max 20x 升级为 Ultra…」(近 7 天事件);第 6 件借播客「OpenAI：当AI智能体用电脑比你更快」;第 1 件借论文「约束解码有害还是有益？…」。
- **摘要**:分析接口只取了列表里会露出的 88 篇;没取到的不画摘要行(详情里的高分内容本来就不带摘要)。
- 排名变化:标签榜 `rank_change` 照接口;热点 `previous_rank` 全空,不画。

## 取舍(拿不准、我替你先定了的)

- 名次变化为 0 时不画(现网写「持平」);昨天不在前 10 写「进榜」。
- 「新」签放在名次下,不放标题前,标题左缘对齐不被打乱。
- 风向签只收**升温**的(较上周次数 > 0);增量写在签上「+k」,「较上周」只在行首写一次,没有每枚签都重复。手机上风向是现网内容类型带那种镀层胶囊,横滑。
- 文章卡右栏的徽标 = 本篇来源 + 同事件其余发布主体,让「另 N 家」看得见;没进事件的只有一枚。
- 详情抬头写「首报」= 成员里最早的**发布时间**;`first_seen_at` 是入库时间(例:DeepSeek 事件入库 11月1日 08:04,最早一篇报道 10月31日 17:32),只用来判「新」。来源分组只写发布主体,同主体多渠道时括注「还有 …」(待拍板 3b 的建议);主体键照后端 `publisher_key`(owner 小写 + 别名表:Sam Altman 归 OpenAI、Google DeepMind 归 Google)。
- 列表里的 30 日走势用最弱的灰;只有标签详情里的大趋势线用 accent——抽屉里没有别的强调色。
- 分数用 `qualityScoreText`(整数不带「.0」),颜色按分档(灰线 6.0)。
- 空榜 = 一句话 + 一个文字钮(「看文章榜」/「看本周值得读」):空态指向第一个动作。C 的热点块空时只有那句话。
- C「话题风向 · 全部」B 里没有对应段:画成三轴各 10 项的紧凑列表,桌面三栏并排。手机 C 的「全部 →」是整页推入(盖住底栏),返回钮在头像原位。
- 桌面版心:A / B 820,C 1120(双栏)。详情抽屉 500 宽,沿用在册 `.ledger-drawer`,头部去掉浅底。
- 桌面「榜单」入口画在现网位置(源栏栏头下方);副标题随段变:热点 10 件 / 近 7 天标签趋势 / 近 7 天值得读 / 近 7 天值得听。
