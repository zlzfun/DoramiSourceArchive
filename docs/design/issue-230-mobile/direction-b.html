方向 B · issue #230 手机端(H5 / 窄屏)视觉方向

仪器

把现在的「静默仪器」做到手机该有的精度:44px 一档的触控栅格、一族带拇指的分段控件、分数落在固定右列;顶栏、控制带、播放坞、TabBar 都是贴边的实底面板。信息密度最高(约 6 条 / 屏),和现状最连续、改动面最小;动效只在状态切换时出现——拇指滑过去、读过的标题退色、收藏的星点亮。

关键屏6 × 亮暗动效状态切换 4 种 + 既有 3 种新增 token5 个(布局量)条目密度约 6 条 / 屏数据9 月 16 日本地库快照(真实标题 / 摘要 / 分数)

试玩 页面顶部「动效」可切「减少」,看降级后的样子

怎么玩

点「全部 / 未读」、内容类型、TabBar 看拇指滑动;长按条目出动作单,点「收藏文章」看星点亮;「全部标读」看读态回落。

① 条目流

顶栏 + 全部 | 未读 + 内容类型 + 条目(分数 / 来源 / 时间 / 读态)+ TabBar + 播放坞
  • 简顶栏五个控件都保留,但放大到 44px;标题做成两行读数:栏名 + 当前来源(点任一处开抽屉)。
  • 新控制带:全部 | 未读 与内容类型是同一族分段(well 槽 + 拇指);类型那条横滑,一枚拇指跟着选中项走。
  • 简摘要一行(尾部渐隐),约 6 条 / 屏;分数落在固定 34px 右列,纵向对齐成一条线;收藏星挪进元信息行。
  • 新TabBar 选中改为一枚中性拇指在六格之间滑动;播放坞贴在 TabBar 上沿,单行:封面 · 标题 / 节目 · 时间读数 · −15 · 播放 · +15。

② 正文页

眉头 / 标题 / 原标题 / 署名 / 听导读 / 译钮 / AI 速读 / 正文 / 上一篇下一篇 / 顶部动作
  • 简顶栏:返回 · 来源面包屑(徽标 + 名)· 收藏 · 分享 · 更多;顶栏「原文」去掉(文末「查看原文」与「更多」里都有)。
  • 新译钮下沉成标题下工具行右侧的「原文 | 中文」分段,中文态拇指与字走 AI 渐变(与桌面同语);左侧「✦ 听导读」。
  • 留AI 速读保留细线卡;上一篇 / 下一篇是两枚等宽读数卡(64px 高)。

③ 源抽屉

过滤器,不是目的地:全部文章 / 订阅 | 兴趣 / 信息角色分组 / 有未读 / 暂不可用
  • 新订阅 | 兴趣 改为整宽分段(拇指);顶部恢复「全部文章」聚合行;组名吸顶。
  • 简源行 44px(现状 40);选中 = 中性加深 + 600(#184 选中语法);有未读只靠墨色。

④ 长按动作单

桌面右键菜单同构:读态 · 收藏 → 链接 → 该源全部已读
  • 新对象行:来源徽标 + 标题一行 + 来源 · 时间(现状只有一行 12px 灰字)。
  • 留行高 48,图标 18 留在行首;组间细线;items 与桌面右键菜单同构。

⑤ 我的 + 设置栈

「我的」页(亮)与设置栈一级页(暗);试玩里可切游客视角
  • 留现状的分组卡语法,行高统一 48、图标 18;外观三态换成同族分段(拇指)。
  • 留设置栈:组名 + 卡片;反馈未读用 wash 小胶囊(既有 .m-row-badge,wash 只用于这类「待处理」状态)。

夜航版式的手机档:眉头 · 往期 · 重新编排 → 头条 → 评分栏 → 板块
  • 新眉头做成吸顶工具带:「早报 9月16日 周三 今天 | 往期 | 重新编排」,滚动时一直在。
  • 新评分栏做成读数面板(画布底 + 软环):维度 / 分数 / 理由三格对齐;头条 900 / 30px。
  • 留板块名吸顶在工具带下;条目分数落右列,与条目流同一条线;AI 环境光保留。

风险

  • 和现状最像,「眼前一亮」的程度最低;高级感主要来自精度,要靠像素级验收兑现(conventions §8.x 的量 bounding box 那套)。
  • 类型分段不等宽,拇指位置靠 JS 量;字体晚到会让宽度变,需在 fonts.ready 后再量一次。
  • 播放坞改单行要动 #199 的手机排版;±15 常在、倍速 / 缩小 / 关闭进展开态,需要用户确认。
