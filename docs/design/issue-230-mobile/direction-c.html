方向 C · issue #230 手机端(H5 / 窄屏)视觉方向

夜航

把早报的「夜航」气质铺到整个手机壳:内容铺满全屏,顶栏、TabBar、播放坞都是浮在内容上的磨砂镀层,往下读时退场、往上一划就回来;大标题随滚动收进顶栏;来源改成可拖拽的底页,长按时那一条先「抬起来」;正文页没有顶栏,动作落在拇指够得着的浮动坞里。动效最多、手感最强,对低端机与内置浏览器的要求也最高。

关键屏6 × 亮暗动效弹簧 + 拖拽 + 退场 8 种新增 token7 个(镀层 5 + 弹簧 2)条目密度约 3.5 张卡 / 屏数据9 月 16 日本地库快照(真实标题 / 摘要 / 分数)

试玩 页面顶部「动效」可切「减少」,看降级后的样子

怎么玩

在列表里往下滚,看 TabBar 与播放坞退场、大标题收进顶栏;点卡片看正文从卡片里「长」出来;长按卡片看它抬起;打开来源底页后按住把手往下拖。

① 条目流

顶栏 + 全部 | 未读 + 内容类型 + 条目(分数 / 来源 / 时间 / 读态)+ TabBar + 播放坞
  • 新内容铺满全屏:宋体大标题 34px + 来源范围;滚过后收进磨砂顶栏(栏名 · 来源 ⌄)。
  • 新条目是一张张卡(亮:白卡 + 极浅投影;暗:抬起面),按下有纵深;摘要两行,分数 19px 在卡角。
  • 新筛选是一排吸顶的磨砂胶囊:全部 | 未读 是带镜片拇指的分段,类型胶囊选中 = 墨色实底。
  • 新TabBar 与播放坞是两枚浮动胶囊;播放坞用 #199 的封面模糊底 + 封面外圈进度环;往下读时两者退场,底部有一段渐隐垫底。
  • 简右上 收藏 / 全部标读 / 搜索 是三枚磨砂圆钮(36px 视觉,44px 命中);☰ 去掉,来源从标题下进入。

② 正文页

眉头 / 标题 / 原标题 / 署名 / 听导读 / 译钮 / AI 速读 / 正文 / 上一篇下一篇 / 顶部动作
  • 删顶栏:返回是左上一枚磨砂圆钮,收藏 · 分享 · 更多是右上一枚磨砂胶囊;往下读时淡出。
  • 新拇指区浮动坞:上一篇 · 原文 | 中文 · 下一篇(译钮下沉到拇指区);文末一张「下一篇」大卡。
  • 新正文从被点的那张卡片矩形「长」出来(容器展开),返回时收回原位;进度线在状态栏下沿。

③ 源抽屉

过滤器,不是目的地:全部文章 / 订阅 | 兴趣 / 信息角色分组 / 有未读 / 暂不可用
  • 新左侧抽屉改为底部底页(停在屏高约 1/6 处),按住把手往下拖即关;订阅 | 兴趣 在标题右侧。
  • 简分组改为圆角卡片组(设置式),源行 50px,选中 = 600 + accent 勾;仍是过滤器,不进 TabBar。

④ 长按动作单

桌面右键菜单同构:读态 · 收藏 → 链接 → 该源全部已读
  • 新被长按的卡片先「抬起」成预览卡,动作组在它下面;两段弹簧入场,原卡淡到 35%。
  • 新动作组按 items 的分组断成三块;图标挪到行尾(上下文菜单的读法);items 与桌面右键菜单同构。

⑤ 我的 + 设置栈

「我的」页(亮)与设置栈一级页(暗);试玩里可切游客视角
  • 新大标题 + 资料卡(头像 60);行首图标住进中性小方块;外观三态是镜片拇指分段。
  • 留设置栈同样大标题 + 圆角分组,左上磨砂关闭钮;反馈未读是 accent 小胶囊。

⑥ 个人早报

夜航版式的手机档:眉头 · 往期 · 重新编排 → 头条 → 评分栏 → 板块
  • 留夜航本色:AI 环境光加强一档、头条 900 / 37px(现状手机档上限 40)。
  • 新往期是磨砂胶囊、重新编排与收藏是磨砂圆钮;板块名是吸顶的磨砂胶囊,条目是卡。

风险

  • backdrop-filter 在低端安卓、华为浏览器、微信 X5 内核上掉帧或不支持;降级档(94% 近实色)已写,但磨砂观感会丢。
  • TabBar 下滚退场与 iOS Safari 自己的地址栏伸缩叠在一起,容易「两层一起动」;阈值要真机调。
  • 底页手势与系统返回、下拉刷新抢手势;样页已只在把手上生效,真机仍要验。
  • 与 conventions §7「工作区 feedback-only」冲突最大;改动面也最大(抽屉 → 底页、正文去顶栏是结构性改动)。
