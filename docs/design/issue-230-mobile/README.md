> 状态:**方向 C「夜航」已选定,第 1 轮返修**(2026-10-28)。A 纸面 / B 仪器已舍弃,原三方向样页见提交 `18f0064` 的历史。
> 样页是设计记录,落地后不随实现更新,现行 UI 以 `frontend/src` 为准。编排与审计见 [`../../plans/issue-230-mobile-wave.md`](../../plans/issue-230-mobile-wave.md)。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 方向 C 单文件样页:屏幕切换 11 屏(条目流 / 正文页 / 读到文末 / 来源底页 / 长按 / 我的 / 设置栈 / 早报 / 往期三方案),亮暗两台手机并排、都能点;右侧是当前屏的说明;页尾动效清单与 token |

`index.html` 不依赖同目录任何文件、不用 iframe:双击即可离线打开,也可以直接发给别人。字体是仓库自托管的 Dorami Serif / Dorami Latin Serif 按本页用字取的子集(data URI)。

## 查看

- 顶栏四个开关:页面主题(亮 / 暗)、中性色(瓷 / 墨 / 宣)、动效(完整 / 减少,即 `<html data-motion="reduce">`)、机型宽度(360 / 390 / 430);都记在 localStorage。中性色与动效开关成本低,保留。
- 舞台:点屏幕标签切屏;「显示」可只看亮或只看暗;切到「⑥ 早报」时多出「往期方案」三选一,决定早报里「往期」入口打开哪一种。
- 手机里都能点:点卡片进正文、长按(或右键)出动作单、点「全部来源」开来源底页、点「往期」开所选方案;Esc 或浏览器返回关最上面那一层(与 `useLayerHistory` 同语义)。
- 可选参数:`?screen=feed|read|read-end|drawer|sheet|me|settings|brief|hist-sheet|hist-strip|hist-list&width=360|390|430&cols=both|light|dark&motion=reduce`。

## 设计陈述

把早报的「夜航」气质铺到整个手机壳。内容铺满全屏,顶栏、TabBar、播放坞是浮在内容上的磨砂镀层,往下读时退场、往上一划就回来;大标题随滚动收进顶栏。来源是可拖拽的底页,长按时那一条先「抬起」,动作组在它下面。正文页没有顶栏,返回与动作是浮在内容上的磨砂钮,上一篇 · 原文 | 中文 · 下一篇落在拇指够得着的浮动坞里。动效用弹簧(阻尼振子采样成 `linear()`,与播放条同一种做法),全部受 `<html data-motion>` 开关控制。

数据是真的:条目、标题、摘要、分数、评分依据、早报编排取自 `docs/design/visual-refine-final/assets/data.js`(本地库快照,9 月 16 日那一期),播放坞节目取自 `docs/design/podcast-player`。示意的部分:版本更新条目「Claude Code 2.0.37」、正文段落(据真实摘要改写)、读者名、往期里除 9/16、9/15、9/10、9/9、9/7 以外的日期,以及各期的版次 / 编排时刻 / 篇数 / 失败日。

## 动效清单

全部挂 `<html data-motion="reduce">`:减少动效时 CSS 过渡由全局兜底压到 1ms,需要终态的局部规则另写;JS 编排的形变(容器展开、弹簧)直接落终态。

| 动效 | 触发 | 时长 · 缓动 | 目的 | 减少动效时 |
|---|---|---|---|---|
| 镀层退场 | 列表 / 正文向下滚(越过 140px 且速度 > 6px/帧) | 420ms · `--motion-sheet`(弹簧) | 把整屏让给内容;往上一划就回来 | 常显,不退场 |
| 大标题收拢 | 滚过 44px | 240ms · `--motion-medium` | 栏名收进顶栏,顶栏换上磨砂 | 只剩显隐 |
| 容器展开 | 点卡片 / 早报卡 → 正文;返回 | 420ms 弹簧 clip-path + 90ms 后正文淡入;返回 320ms 收回原卡 | 来处即去处 | 120ms 淡入 |
| 底页弹簧 | 来源底页 / 往期月历 / 动作组 / 播放展开 | 420ms · `--motion-sheet`(超调 2.5%) | 物理感,与拖拽同一套参数 | 1ms |
| 跟手拖拽 | 按住把手下拉底页 | 跟手;松手 > 96px 或速度 > 0.6px/ms 即关 | 直接操纵 | 拖拽照常,无回弹 |
| 抬起预览 | 长按卡片(条目流、早报) | 420ms · `--motion-sheet`(0.96 → 1)+ 原卡淡到 35% | 告诉你「选中的是这一条」 | 无缩放 |
| 按压纵深 | 按住卡片 / 早报头条 / 磨砂钮 | 100ms 压到 0.985(头条 0.99),松手弹回 | 触感 | 无 |
| 镜片拇指 | TabBar / 全部 \| 未读 / 订阅 \| 兴趣 / 外观 / 语言 | 420ms · `--motion-sheet`,按第几项定位 | 连续 | 瞬移 |

## 风险

- backdrop-filter 在低端安卓、华为浏览器、微信 X5 内核上掉帧或不支持;已写降级(镀层 94% 近实色、底页实色)。Playwright 自带的 WebKit 截图里磨砂也不生效,看到的就是降级观感。
- TabBar 下滚退场与 iOS Safari 地址栏伸缩叠在一起,容易「两层一起动」;阈值要真机调。
- 底页手势与系统返回、下拉刷新抢手势;样页只在把手上生效,真机仍要验。
- 早报卡长按是新交互,第一次用的人未必知道;收藏的主入口仍是正文页右上的星。
- 改动面大:抽屉 → 底页、正文去顶栏、镀层与手势都是结构性改动。
