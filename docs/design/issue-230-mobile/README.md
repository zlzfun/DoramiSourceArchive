## 三个方向:设计陈述

### 方向 A「纸面」

把手机当成一张印好的纸:全壳同一底色,分隔只剩发丝线与留白;标题用宋体放大一档,读起来像报纸的栏目;界面词代替图标——TabBar 是六个字,过滤是一行字;动效只有「翻页」与「浮现」两种。它对应「高级感、简约」里安静、克制、文气的那一面,代价是密度最低。

**逐屏要点**(新 = 新增 · 删 = 删掉 · 简 = 简化 · 留 = 沿用)

- **① 条目流**:[删] 顶栏的 ☰、未读分段的槽与拇指、收藏星图标钮;列表面 / 纸面两层底色(全壳一张纸);[新] 报头:宋体栏名 26px + 下方「全部来源 ⌄」——源抽屉是过滤器,标题下写出当前过滤值,点它换来源(§4.1.2);[简] 过滤一行字:全部 / 未读 · 收藏 │ 论文 教程 …(类型横滑);选中 = 墨色 600 + 一道墨线;[新] 条目标题改宋体 600 / 17px,署名行挪到摘要下(来源 · 类型 · 时间 …… 分数);宋体没有 400,读态改为墨色退一档(读屏仍报「未读」);[新] TabBar 去图标,只剩六个字;播放坞是贴着 TabBar 的一条纸带,上沿的发丝线就是进度。
- **② 正文页**:[简] 顶栏只剩 返回 · 收藏 · 更多:分享、查看原文、复制链接都进「更多」(与长按同一份动作);[新] 译钮下沉:顶栏「译」→ 标题区尾行「原文 中文」两个字,与桌面阅读窗的语言二段同语;译文态仍是 AI 渐变字;[简] AI 速读去掉卡片底,改为上下两道发丝线夹住的「编者提要」;分数与评分依据(触屏常显一行)不变;[新] 标题放大到 27px;阅读进度 = 顶栏下沿 1px 墨线;上一篇 / 下一篇是两行宋体题目,点了就「翻页」。
- **③ 源抽屉**:[新] 抽屉顶部恢复「全部文章」:清除来源过滤的显式出口(现状只能再点一次 TabBar);[简] 订阅 | 兴趣 改成两个字;源行 48px(现状 40,不到触控下限);选中 = 600 + 行尾 ✓;有未读只靠墨色,不画计数(§3);[删] 抽屉投影:与列表之间只有遮罩 + 一道发丝线。
- **④ 长按动作单**:[删] 行首图标:动作单只剩字,行高 50;[新] 头部用宋体两行写出被长按的那一条 + 来源 · 时间(现状是一行 12px 灰字,看不清对象);[留] items 与桌面右键菜单同构(读态 · 收藏 → 复制链接 · 分享给… · 打开原文 → 该源全部已读)。
- **⑤ 我的 + 设置栈**:[删] 卡片与行首图标;分组小字 + 发丝线行,外观三态是三个字;[留] 用户名宋体;退出登录独立一组、红字。游客:身份行换成「游客 · 登录后可收藏、订阅、设置兴趣 · 登录」(试玩「游客视角」);[留] 设置栈一级页同一语法:组名小字 + 行 + 右侧灰色说明;反馈未读是一个 accent 数字。
- **⑥ 个人早报**:[留] 夜航结构不变:眉头 · 往期 · 重新编排 → 头条 → 评分栏 → 板块 → 本期编排;[新] 眉头下压一道报头双线;头条宋体 900 / 33px;[删] 头条背后的 AI 环境光(纸不发光;AI 身份仍由 ✦ 与渐变分数承担)——需拍板;[简] 主按钮改墨色实底(一屏唯一实心),收藏是一个字钮。

### 方向 B「仪器」

把现在的「静默仪器」做到手机该有的精度:44px 一档的触控栅格、一族带拇指的分段控件、分数落在固定右列;顶栏、控制带、播放坞、TabBar 都是贴边的实底面板。信息密度最高(约 6 条 / 屏),和现状最连续、改动面最小;动效只在状态切换时出现——拇指滑过去、读过的标题退色、收藏的星点亮。

**逐屏要点**(新 = 新增 · 删 = 删掉 · 简 = 简化 · 留 = 沿用)

- **① 条目流**:[简] 顶栏五个控件都保留,但放大到 44px;标题做成两行读数:栏名 + 当前来源(点任一处开抽屉);[新] 控制带:全部 | 未读 与内容类型是同一族分段(well 槽 + 拇指);类型那条横滑,一枚拇指跟着选中项走;[简] 摘要一行(尾部渐隐),约 6 条 / 屏;分数落在固定 34px 右列,纵向对齐成一条线;收藏星挪进元信息行;[新] TabBar 选中改为一枚中性拇指在六格之间滑动;播放坞贴在 TabBar 上沿,单行:封面 · 标题 / 节目 · 时间读数 · −15 · 播放 · +15。
- **② 正文页**:[简] 顶栏:返回 · 来源面包屑(徽标 + 名)· 收藏 · 分享 · 更多;顶栏「原文」去掉(文末「查看原文」与「更多」里都有);[新] 译钮下沉成标题下工具行右侧的「原文 | 中文」分段,中文态拇指与字走 AI 渐变(与桌面同语);左侧「✦ 听导读」;[留] AI 速读保留细线卡;上一篇 / 下一篇是两枚等宽读数卡(64px 高)。
- **③ 源抽屉**:[新] 订阅 | 兴趣 改为整宽分段(拇指);顶部恢复「全部文章」聚合行;组名吸顶;[简] 源行 44px(现状 40);选中 = 中性加深 + 600(#184 选中语法);有未读只靠墨色。
- **④ 长按动作单**:[新] 对象行:来源徽标 + 标题一行 + 来源 · 时间(现状只有一行 12px 灰字);[留] 行高 48,图标 18 留在行首;组间细线;items 与桌面右键菜单同构。
- **⑤ 我的 + 设置栈**:[留] 现状的分组卡语法,行高统一 48、图标 18;外观三态换成同族分段(拇指);[留] 设置栈:组名 + 卡片;反馈未读用 wash 小胶囊(既有 .m-row-badge,wash 只用于这类「待处理」状态)。
- **⑥ 个人早报**:[新] 眉头做成吸顶工具带:「早报 9月16日 周三 今天 | 往期 | 重新编排」,滚动时一直在;[新] 评分栏做成读数面板(画布底 + 软环):维度 / 分数 / 理由三格对齐;头条 900 / 30px;[留] 板块名吸顶在工具带下;条目分数落右列,与条目流同一条线;AI 环境光保留。

### 方向 C「夜航」

把早报的「夜航」气质铺到整个手机壳:内容铺满全屏,顶栏、TabBar、播放坞都是浮在内容上的磨砂镀层,往下读时退场、往上一划就回来;大标题随滚动收进顶栏;来源改成可拖拽的底页,长按时那一条先「抬起来」;正文页没有顶栏,动作落在拇指够得着的浮动坞里。动效最多、手感最强,对低端机与内置浏览器的要求也最高。

**逐屏要点**(新 = 新增 · 删 = 删掉 · 简 = 简化 · 留 = 沿用)

- **① 条目流**:[新] 内容铺满全屏:宋体大标题 34px + 来源范围;滚过后收进磨砂顶栏(栏名 · 来源 ⌄);[新] 条目是一张张卡(亮:白卡 + 极浅投影;暗:抬起面),按下有纵深;摘要两行,分数 19px 在卡角;[新] 筛选是一排吸顶的磨砂胶囊:全部 | 未读 是带镜片拇指的分段,类型胶囊选中 = 墨色实底;[新] TabBar 与播放坞是两枚浮动胶囊;播放坞用 #199 的封面模糊底 + 封面外圈进度环;往下读时两者退场,底部有一段渐隐垫底;[简] 右上 收藏 / 全部标读 / 搜索 是三枚磨砂圆钮(36px 视觉,44px 命中);☰ 去掉,来源从标题下进入。
- **② 正文页**:[删] 顶栏:返回是左上一枚磨砂圆钮,收藏 · 分享 · 更多是右上一枚磨砂胶囊;往下读时淡出;[新] 拇指区浮动坞:上一篇 · 原文 | 中文 · 下一篇(译钮下沉到拇指区);文末一张「下一篇」大卡;[新] 正文从被点的那张卡片矩形「长」出来(容器展开),返回时收回原位;进度线在状态栏下沿。
- **③ 源抽屉**:[新] 左侧抽屉改为底部底页(停在屏高约 1/6 处),按住把手往下拖即关;订阅 | 兴趣 在标题右侧;[简] 分组改为圆角卡片组(设置式),源行 50px,选中 = 600 + accent 勾;仍是过滤器,不进 TabBar。
- **④ 长按动作单**:[新] 被长按的卡片先「抬起」成预览卡,动作组在它下面;两段弹簧入场,原卡淡到 35%;[新] 动作组按 items 的分组断成三块;图标挪到行尾(上下文菜单的读法);items 与桌面右键菜单同构。
- **⑤ 我的 + 设置栈**:[新] 大标题 + 资料卡(头像 60);行首图标住进中性小方块;外观三态是镜片拇指分段;[留] 设置栈同样大标题 + 圆角分组,左上磨砂关闭钮;反馈未读是 accent 小胶囊。
- **⑥ 个人早报**:[留] 夜航本色:AI 环境光加强一档、头条 900 / 37px(现状手机档上限 40);[新] 往期是磨砂胶囊、重新编排与收藏是磨砂圆钮;板块名是吸顶的磨砂胶囊,条目是卡。

## 动效清单

三个方向的动效全部受 `<html data-motion>` 开关控制:减少动效时 CSS 过渡由全局兜底压到 1ms(与 `index.css` 文件尾同一条),需要终态的局部规则另写在 `:root[data-motion="reduce"]` 下;JS 编排的形变(A 换篇翻页、C 容器展开 / 弹簧)在减少动效时直接落终态。

**A 纸面**

| 动效 | 触发 | 时长 · 缓动 | 目的 | `data-motion="reduce"` 时 |
|---|---|---|---|---|
| 翻页 · 入 | 点条目 / 早报「阅读全文」 | 300ms · --motion-slow · --motion-ease | 正文是列表右边的下一页:列表左移 24% 并压暗 4%,正文整页从右推入 | 直接切换,不位移 |
| 翻页 · 出 | 返回 / 系统返回 | 300ms · 同上 | 同一条路反向走回去 | 直接切换 |
| 翻页 · 换篇 | 上一篇 / 下一篇 | 300ms · 同上 | 方向即顺序:下一篇从右来、上一篇从左来,旧页退 28% 并淡出 | 直接替换 |
| 浮现 · 层 | 源抽屉 / 动作单 / 播放展开 / 搜索行 / 提示条 | 240ms · --motion-medium · --motion-ease | 淡入 + 12–18px 短位移;纸没有投影,只靠遮罩与一道发丝线分层 | 只剩显隐 |
| 浮现 · 内容 | 全部 / 未读 / 收藏 / 类型切换后 | 150ms · --motion-fast · ease-out | 告诉读者「列表换了」 | 无 |

其余一律即时:按下只换底色,选中只换字重与墨线,没有缩放、没有弹簧。

**B 仪器**

| 动效 | 触发 | 时长 · 缓动 | 目的 | `data-motion="reduce"` 时 |
|---|---|---|---|---|
| 拇指滑动 | 全部 / 未读、内容类型、TabBar、订阅 / 兴趣、外观、语言、倍速 | 240ms · --motion-medium · --motion-ease | 状态的位置是连续的,眼睛跟得上「从哪到哪」 | 拇指瞬移 |
| 读态回落 | 打开过 / 标为已读 / 全部标读 | 150ms · --motion-fast(颜色;字重瞬变) | 读过的标题退到次墨色 | 瞬变 |
| 收藏点亮 | 收藏 / 取消收藏 | 240ms · --motion-spring(0.82 → 1.18 → 1) | 唯一带弹性的反馈,确认动作生效 | 只换颜色 |

**A 纸面**

- 宋体条目标题让列表密度降到约 3.5 条 / 屏(现状约 5 条),扫读效率下降最明显。
- 读态只剩颜色一条通道(Dorami Serif 只有 600 / 900):要拍板,或采用「纸面 + 黑体条目标题」的组合。
- 无图标 TabBar 对第一次使用的人略弱(字本身就是语义,风险小)。
- 条目标题用字面大,首屏要多拉几片宋体分片(实测本页 280 个字的子集约 110KB)。

**B 仪器**

- 和现状最像,「眼前一亮」的程度最低;高级感主要来自精度,要靠像素级验收兑现(conventions §8.x 的量 bounding box 那套)。
- 类型分段不等宽,拇指位置靠 JS 量;字体晚到会让宽度变,需在 fonts.ready 后再量一次。
- 播放坞改单行要动 #199 的手机排版;±15 常在、倍速 / 缩小 / 关闭进展开态,需要用户确认。

**C 夜航**

- backdrop-filter 在低端安卓、华为浏览器、微信 X5 内核上掉帧或不支持;降级档(94% 近实色)已写,但磨砂观感会丢。
- TabBar 下滚退场与 iOS Safari 自己的地址栏伸缩叠在一起,容易「两层一起动」;阈值要真机调。
- 底页手势与系统返回、下拉刷新抢手势;样页已只在把手上生效,真机仍要验。
- 与 conventions §7「工作区 feedback-only」冲突最大;改动面也最大(抽屉 → 底页、正文去顶栏是结构性改动)。

**三、设计师意见**(仅供参考,拍板以用户为准):以 **A 纸面** 为主方向。它最贴「高级感、简约、视觉元素精简」——去掉的是框、色块与图标,
留下的是排印;气质与早报的夜航版式、阅读窗的宋体标题一脉相承,三个方向里只有它让手机端像一份「读物」而不是一件「工具」;动效也最克制(两种),
与 conventions §7 的口径冲突最小。它唯一需要权衡的是第 9 项「条目标题改宋体」:若更在意扫读密度与「已读」的字重信号,可以单独否掉、
保留黑体 15 / 600,其余纸面语法不受影响。B 的精度纪律(44px 栅格、同族分段、分数固定右列)其实是三个方向的共同底座,无论选谁都该落;
C 的「来源底页 + 弹簧 + 跟手拖拽」与「镀层随滚动退场」手感最好,但内网读者大量在微信 / 华为浏览器里,backdrop-filter 与手势冲突的风险最大,
建议等真机性能基线(issue 审计面 ⑥)出来再单独评估。
