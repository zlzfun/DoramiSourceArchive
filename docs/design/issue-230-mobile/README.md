## 设计陈述

把早报的「夜航」气质铺到整个手机壳。内容铺满全屏,顶栏、TabBar、播放坞是浮在内容上的磨砂镀层,往下读时退场、往上一划就回来。第 2 轮按 Folo 手机版的**功能组织**重排(视觉仍是夜航,不照搬它的橙色与版式):**底栏是功能模块**——内容 · 订阅 · 榜单 · 设置;**内容类型上移成「内容」页头的视图胶囊**——早报 / 文章 / 播客 / 社交,当前项宽、写名字,其余只留图标;每个视图仍是现网那条独立的流,不混排。来源从「过滤器底页」变成「订阅」这个目的地:按分组列出所有订阅,点一个就在订阅 Tab 里推入它的条目流;发现更多来源、兴趣、收藏都收在这里。「我的」与设置栈一级页合成「设置」。正文页、长按、早报版式沿用第 1 轮。动效用弹簧(阻尼振子采样成 `linear()`,与播放条同一种做法),全部受 `<html data-motion>` 开关控制。

数据是真的:条目、标题、摘要、分数、评分依据、主题标签、早报编排取自 `docs/design/visual-refine-final/assets/data.js`(本地库快照,9 月 16 日那一期);播客节目与社交推文取自 `docs/design/podcast-player/assets/global-data.js` 与 `docs/design/podcast-player/assets/ppg-social-data.js`(本机沙箱库的真实节目 / 推文,含封面、头像、配图);兴趣目录取自 `config/taxonomy-v1-approved-catalog.json` 的 94 个可选规范标签。

示意的部分:

- 第 1 轮起:版本更新条目「Claude Code 2.0.37」、正文段落(据真实摘要改写)、读者名、往期里除 9/16、9/15、9/10、9/9、9/7 以外的日期,以及各期的版次 / 编排时刻 / 篇数 / 失败日。
- 第 2 轮新增:播客 5 期与社交 4 条的发布时间改写成相对样页时钟的「N 小时前」(原数据是 10 月中旬的节目、7 月下旬的推文),已读状态示意;播客里只有 Interconnects 那期有真实分数(8.6),其余不画分数。
- 订阅列表只画了 28 个来源(「全部」行写的 41 个来自早报那期的真实编排);播客 / 社交两组的未读状态示意;收藏多标了 Anthropic 上市、中关村 7B、42章经 三条。
- 榜单:标签名取自规范目录,出现次数、名次变化、来源数、30 日趋势是示意;高分内容取自样页条目(真实标题与分数);播客榜只有 Interconnects 一期有分。
- 社交卡的「译为中文」只给提示条,没有画译文。

### 七条默认取舍怎么画的

本轮先按七条预设取舍画,逐条列进下面「拍板清单」16–22 待拍板,这里只记画法:

1. **底栏四个 Tab**:内容(layers 图标)· 订阅(library)· 榜单(chart)· 设置(settings);「订阅与兴趣」在 Tab 上简写「订阅」。
2. **早报放哪**:默认是内容的第一个视图,启用早报时默认落在早报;页顶「早报位置」切到「独立 Tab」就是五个 Tab(早报 · 内容 · 订阅 · 榜单 · 设置),早报页回到第 1 轮的整页样子,内容里只剩 文章 / 播客 / 社交。往期三方案在两种位置下都能用。
3. **内容页头**:顶栏 + 视图胶囊一层镀层;列表上方最多两条控件带——文章是 视图胶囊 + 类型胶囊,播客 / 社交只有视图胶囊;大标题下的「全部来源 ⌄」移走。
4. **订阅 Tab**:见上表第 3 行;推入页右上的 只看未读 · 全部标读 是这一页自己的状态。「全部」「收藏」「兴趣」推入的是同一种页,全部 / 收藏多一行视图胶囊(文章 / 播客 / 社交)。兴趣段只画 InterestPage 现有能力:点击即保存(回执「保存中… / 已保存」)、搜索标签、主题 / 行业 / 实体三段、目录卡点一下加入再点取消;「我的兴趣」每行可点读它的条目流、行尾 × 移出。
5. **设置 Tab**:原「我的」的外观三态分段与设置栈的「外观」重复,合成一行(行尾写当前值),点进二级页——主题之外还有中性色与减少动效,不丢能力。
6. **游客视角**:页顶「身份」切到游客——内容 Tab 头像换空头像;订阅 Tab 列默认订阅,顶上一张登录引导,「+」、收藏、兴趣都提示登录;设置 Tab 资料卡换成登录引导,锁住的分区挂锁,没有退出登录;早报入选说明写「默认订阅的」(现网 guestCopy 口径)。
7. **正文 / 长按 / 早报版式**:沿用第 1 轮,只改入口;长按顺带扩到播客卡与社交卡(社交卡动作沿用现网推文动作)。

### 「全部 / 未读」:收进顶栏图标

采用顶栏一枚开关图标:空心圈 = 显示全部,带点的圈 = 只看未读;开着时顶栏视图名下面写「只看未读」,切换时有提示条。理由:

1. **作用范围对得上**:现网 `unreadOnly` 是 useReaderState 里的一个全局状态,文章 / 播客 / 社交共用;放在三条流共用的顶栏里,位置就是它的范围。留在筛选行,每个视图都得各放一份,看起来像各管各的。
2. **控件带更少**:保留固定分段的话,播客 / 社交会多出一条只放「全部 | 未读」的行;收进顶栏后,列表上方 文章两条、播客 / 社交一条。
3. **往下读也够得着**:顶栏固定,筛选行会随列表滚走。
4. **第 1 轮的根因在新形态下不成立**:① 开关在固定的顶栏里,不在任何横滑轨里(类型胶囊另起一行横滑);② 它只是 `aria-pressed` 两态的按钮,没有拇指、不量任何宽度,隐藏视图里改状态也不会塌。自检按第 1 轮的步骤复测,外加「切到播客再回来」。

代价是图标不如两个字直白,用「开着时写字 + 提示条」补;若目检仍觉得不清楚,退回第 1 轮的固定分段只要把它放回类型行最左,第 1 轮的修法照样成立。

## 动效清单

全部挂 `<html data-motion="reduce">`:减少动效时 CSS 过渡由全局兜底压到 1ms,需要终态的局部规则另写;JS 编排的形变(容器展开、弹簧)直接落终态。

|---|---|---|---|---|
| 镀层退场 | 列表 / 正文向下滚(越过 140px 且速度 > 6px/帧) | 420ms · `--motion-sheet`(弹簧) | TabBar、播放坞、正文动作把整屏让给内容;往上一划就回来 | 常显,不退场 |
| 大标题收拢 | 订阅 / 榜单 / 设置 滚过 44px | 240ms · `--motion-medium` | 栏名收进顶栏,顶栏换上磨砂 | 只剩显隐 |

## 风险

- **推入页的第二个列表实例**是本轮最大的落地成本(见落地注记)。退路:推入页 = 切到内容 Tab 并带上来源过滤(就是现在抽屉的语义),但那会改动内容 Tab 的状态,与「不动内容 Tab」相反。
- 底栏少了播客 / 社交直达:去社交从点一下变成两下(内容 → 社交胶囊);视图胶囊记住上次所在的视图能缓解,样页没画。
- 订阅列表把三种形态的订阅合在一张表里,订阅多时很长(现网按容器分开列)。太长的话,可在订阅段加一行同款视图胶囊按形态过滤,代价是多一条控件带。
- 视图胶囊的未读点在订阅多时几乎总亮着,信息量有限;嫌吵可撤。「只看未读」只是一枚图标,第一次用的人未必认得;已用开着时写字 + 提示条补,真机目检时留意。
- 早报做内容里的视图时,海报从页头下面开始(往下移约 108px);环境光铺到页头后面补了一部分沉浸感。独立 Tab 时海报仍是整屏。
- 第 1 轮起:backdrop-filter 在低端安卓、华为浏览器、微信 X5 内核上掉帧或不支持(已写降级,Playwright 的 WebKit 截图里磨砂也不生效);TabBar 下滚退场与 iOS Safari 地址栏伸缩叠在一起;底页手势与系统返回、下拉刷新抢手势;早报卡长按是新交互;改动面大(抽屉 → 订阅 Tab、正文去顶栏、镀层与手势都是结构性改动)。
