## 设计陈述

把早报的「夜航」气质铺到整个手机壳。内容铺满全屏,顶栏、TabBar、播放坞是浮在内容上的磨砂镀层,往下读时退场、往上一划就回来。第 2 轮按 Folo 手机版的**功能组织**重排(视觉仍是夜航,不照搬它的橙色与版式):**底栏是功能模块**——早报 · 内容 · 订阅 · 榜单(第 4 轮定稿早报独立成 Tab;第 6 轮设置进头像:四个 Tab 页头左上同一位置放头像,点了推入设置页);**内容类型上移到「内容」页头的标题位**——文章 / 播客 / 社交 三项固定位,当前视图以左沿为原点放大一档、转墨色(第 3 轮定 B 转盘,第 5 轮三项固定位,第 7 轮左锚定;视图上不挂未读点);**第 7 轮四个 Tab 的页头都只有一行**:头像 · 标题位 · 动作,标题位就是本 Tab 的主切换(订阅 / 兴趣、文章榜 / 播客榜 用同一个转盘;早报只放「早报」,日期并进往期钮);每个视图仍是现网那条独立的流,不混排。来源从「过滤器底页」变成「订阅」这个目的地:按分组列出所有订阅,点一个就在订阅 Tab 里推入它的条目流;发现更多来源、兴趣、收藏都收在这里。「我的」与设置栈一级页合成设置页,从页头头像推入(第 6 轮;原为设置 Tab)。长按、早报版式沿用第 1 轮;正文页第 4 轮去掉底部坞,翻译与查看原文进右上「⋯」菜单;往期定为底页月历。动效用弹簧(阻尼振子采样成 `linear()`,与播放条同一种做法),全部受 `<html data-motion>` 开关控制。

数据是真的:条目、标题、摘要、分数、评分依据、主题标签、早报编排取自 `docs/design/visual-refine-final/assets/data.js`(本地库快照,9 月 16 日那一期);播客节目与社交推文取自 `docs/design/podcast-player/assets/global-data.js` 与 `docs/design/podcast-player/assets/ppg-social-data.js`(本机沙箱库的真实节目 / 推文,含封面、头像、配图);兴趣目录取自 `config/taxonomy-v1-approved-catalog.json` 的 94 个可选规范标签。

### 「全部 / 未读」:收进顶栏图标

采用顶栏一枚开关图标:空心圈 = 显示全部,带点的圈 = 只看未读;开着时顶栏视图名下面写「只看未读」,切换时有提示条。理由:

1. **作用范围对得上**:现网 `unreadOnly` 是 useReaderState 里的一个全局状态,文章 / 播客 / 社交共用;放在三条流共用的顶栏里,位置就是它的范围。留在筛选行,每个视图都得各放一份,看起来像各管各的。
2. **控件带更少**:保留固定分段的话,播客 / 社交会多出一条只放「全部 | 未读」的行;收进顶栏后,列表上方 文章两条、播客 / 社交一条。
3. **往下读也够得着**:顶栏固定,筛选行会随列表滚走。
4. **第 1 轮的根因在新形态下不成立**:① 开关在固定的顶栏里,不在任何横滑轨里(类型胶囊另起一行横滑);② 它只是 `aria-pressed` 两态的按钮,没有拇指、不量任何宽度,隐藏视图里改状态也不会塌。自检按第 1 轮的步骤复测,外加「切到播客再回来」。

代价是图标不如两个字直白,用「开着时写字 + 提示条」补;若目检仍觉得不清楚,退回第 1 轮的固定分段只要把它放回类型行最左,第 1 轮的修法照样成立。

## 动效清单

全部挂 `<html data-motion="reduce">`:减少动效时 CSS 过渡由全局兜底压到 1ms,需要终态的局部规则另写;JS 编排的形变(容器展开、弹簧)直接落终态。第 7 轮取消「大标题收拢」(页头本来就是一行,滚过 4px 只换镀层底,随「镀层」一起显隐);切 Tab 时页头瞬切,不带位移动画。

| 动效 | 触发 | 时长 · 缓动 | 目的 | 减少动效时 |
|---|---|---|---|---|
| 镀层退场 | 列表 / 正文向下滚(越过 140px 且速度 > 6px/帧) | 420ms · `--motion-sheet`(弹簧) | TabBar、播放坞、正文右上的钮把整屏让给内容;往上一划就回来 | 常显,不退场 |
| 视图切换 | 页头转盘(内容 / 订阅 / 榜单 / 来源流)点任一项 / ← → | 放大 420ms · `--motion-sheet`;颜色 `--motion-medium` | 当前项以左沿为原点放大一档、转墨色,位置不动 | 瞬切 |
| 推入页 | 订阅 Tab 点来源 / 全部 / 收藏 / 兴趣;页头头像 → 设置页(第 6 轮);设置页点外观 | 420ms 弹簧 translateX(32px → 0)+ 240ms 淡入;返回反向 | 层级感:这是下一层;设置页盖住底栏与播放坞 | 1ms |
| 容器展开 | 点卡片 / 早报卡 → 正文;返回 | 420ms 弹簧 clip-path + 90ms 后正文淡入;返回 320ms 收回原卡 | 来处即去处 | 120ms 淡入 |
| 底页弹簧 | 往期月历 / 动作组 / 播放展开 | 420ms · `--motion-sheet`(超调 2.5%) | 物理感,与拖拽同一套参数 | 1ms |
| 跟手拖拽 | 按住把手下拉底页 | 跟手;松手 > 96px 或速度 > 0.6px/ms 即关 | 直接操纵 | 拖拽照常,无回弹 |
| 抬起预览 | 长按卡片(文章、早报、播客、社交) | 420ms · `--motion-sheet`(0.96 → 1)+ 原卡淡到 35% | 告诉你「选中的是这一条」 | 无缩放 |
| 按压纵深 | 按住卡片 / 早报头条 / 磨砂钮 | 100ms 压到 0.985(头条 0.99),松手弹回 | 触感 | 无 |
| 镜片拇指 | TabBar / 榜单分类 / 兴趣分面 / 主题 / 语言 | 420ms · `--motion-sheet`,按第几项定位 | 连续 | 瞬移 |

## 风险

- 第 6 轮:设置进头像后,想找齿轮改外观 / 阅读偏好的人第一次要想到点头像(老读者靠一次性迁移提示);「添加到主屏幕」也跟着进了头像。反馈回复的角标藏两层(头像 → 设置页 → 反馈与建议),按建议默认不外露,真机后若觉得回复会被错过,再加一次性提示条。早报页头两行让头条下移 24px。
- **推入页的第二个列表实例**是本轮最大的落地成本(见落地注记)。退路:推入页 = 切到内容 Tab 并带上来源过滤(就是现在抽屉的语义),但那会改动内容 Tab 的状态,与「不动内容 Tab」相反。
- 底栏少了播客 / 社交直达:去社交从点一下变成两下(内容 → 顶栏的社交);内容 Tab 记住上次所在的视图能缓解,样页没画。
- 订阅列表把三种形态的订阅合在一张表里,订阅多时很长(现网按容器分开列)。太长的话,可在订阅段加同款视图切换按形态过滤,代价是多一条控件带。
- 第 7 轮:「兴趣」「播客榜」只是 16px 灰字,没有分段的磨砂槽和镜片拇指,第一次进来未必看得出能点(兜底:与内容 Tab 的 播客 / 社交 是同一个组件,兴趣另有早报里的「调整兴趣」深链;认不出再加一次性提示,拍板 31 第 8 条);榜单页头不再写「榜单」两个字(当前项是「文章榜」),Tab 名只在底栏。
- 视图切换左锚定(第 7 轮):360 宽时槽位 56.7px,当前项与下一项隔 13.4px(居中时 18.4),选中「社交」放大后离「只看未读」的磨砂圆 7.4px,再加第四个视图就排不下,要换形态。第 3 轮「离当前两格以外要拖一下或先点邻居」的问题,第 5 轮改成三项固定位后已不存在。
- 「只看未读」只是一枚图标,第一次用的人未必认得;已用开着时当前视图名下写字 + 提示条补,真机目检时留意。
- 手机月历把失败日当「没有」(灰、不可点),桌面月历标红、可点,两端看到的不一样;编排失败的那天在手机上看不到失败原因。
- 翻译从正文底部坞挪进「⋯」菜单,英文文章切换语言多一次点击,第一次用的人要先知道「⋯」里有它。
- 第 1 轮起:backdrop-filter 在低端安卓、华为浏览器、微信 X5 内核上掉帧或不支持(已写降级,Playwright 的 WebKit 截图里磨砂也不生效);TabBar 下滚退场与 iOS Safari 地址栏伸缩叠在一起;底页手势与系统返回、下拉刷新抢手势;早报卡长按是新交互;改动面大(抽屉 → 订阅 Tab、正文去顶栏、镀层与手势都是结构性改动)。
