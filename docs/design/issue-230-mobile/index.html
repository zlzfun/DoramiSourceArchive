夜航

① 条目流

大标题 + 筛选行(全部 | 未读 固定 + 类型横滑)+ 卡片 + 浮动播放坞与 TabBar

  • 修全部 | 未读 移出类型横滑行,固定在筛选行最左;类型胶囊单独横滑(右缘渐隐提示还有)。根因见 README「第 1 轮返修」。
  • 修分段拇指改为按「第几项」定位(--i / --n,等宽格),不再用 JS 量像素;隐藏、切屏、切主题、字体晚到都不会让拇指塌成 0 宽。
  • 留宋体大标题 34px + 来源范围;滚过后收进磨砂顶栏;卡片按下压 0.985,长按抬起。
  • 留TabBar 与播放坞是两枚浮动胶囊,往下读时退场,底部一段渐隐垫底。

② 正文页

无顶栏;左上返回、右上 收藏 · 分享 · 更多;拇指区 上一篇 · 原文 | 中文 · 下一篇

  • 删「听导读」入口撤掉,不留空位(该功能后续可能取消,另开 issue)。
  • 留返回 / 收藏 · 分享 · 更多 是浮在内容上的磨砂钮,往下读时淡出;拇指区坞:上一篇 · 原文 | 中文 · 下一篇。
  • 留正文从被点的那张卡片矩形长出来(容器展开),返回收回原位;进度线在状态栏下沿。

② 读到文末

读到文末时镀层退场(沉浸态),进度线满格,文末「下一篇」大卡

  • 留读到文末:镀层退场(沉浸态),进度线满格;文末「下一篇」大卡,往上一划镀层回来。

③ 来源底页

源抽屉的移动翻译:底页,按住把手下拉即关;过滤器,不是目的地

  • 留左侧抽屉改底部底页(停在屏高约 1/6 处),按住把手往下拖即关;订阅 | 兴趣 在标题右侧;顶部「全部文章」是清除来源过滤的显式出口。

④ 长按

被长按的那一条先抬起成预览卡,动作组按桌面右键菜单的分组

  • 留被长按的卡片先抬起成预览卡,动作组按 items 的分组断成三块,图标在行尾;items 与桌面右键菜单同构。

⑤ 我的

大标题 + 资料卡 + 分组卡;外观三态是镜片拇指分段

  • 留大标题 + 资料卡(头像 60);行首图标住进中性小方块;外观三态是镜片拇指分段(本轮同样改按序号定位)。

⑤ 设置栈

设置一级页:大标题 + 分组卡 + 行尾说明

  • 留设置栈一级页:大标题 + 圆角分组 + 行尾灰色说明;反馈未读是 accent 小胶囊;左上磨砂关闭钮。

⑥ 早报

夜航本色;头条整块可点 + 「全文 ›」;卡上不再放收藏;往期入口按下方「往期方案」切换

  • 删头条卡的实底蓝色「阅读全文」主按钮撤掉:头条整块可点(按下整块压暗一档),摘要下一枚文字级「全文 ›」只作提示。
  • 删卡上收藏(头条的磨砂星与每条的星)撤掉:收藏走长按动作单(早报卡长按 = 新增,复用 buildArticleMenuItems)与正文页右上的星。
  • 删板块条目的英文原标题撤掉(窄屏两行斜体太占地):原标题在正文页标题下;头条保留原标题。
  • 简条目只留 标题 · 两行摘要 · 来源 · 时间 · 分数;整卡可点、可长按。
  • 新看往期时,眉头写清「几月几日 周几 · 第几版」,右侧「重新编排」换成「回到今天」(与桌面同逻辑)。

往期 ① 底页月历

点「往期」从底部升起月历:一屏一个月,多版排在月历下方

  • 新点「往期」从底部升起月历(可拖拽关闭,Esc / 系统返回也关):一屏一个月、周一起、格子 44px;有早报可点、没有灰显、正在看实底、今天一个点、失败标红。
  • 新当天多版:版次排在月历下方(第 2 版 13:05 / 第 1 版 08:12),点了直接载入;单版的日子点了即关底页载入。
  • 留底部一行图例(有早报 / 没有 / 失败 / 今天)回答「点开后是什么状态」;不在今天时右侧「回到今天」。字段全部来自 /reader/briefs 列表。

往期 ② 日期条

眉头下常驻最近两周的日期条,最左「月历」看更早的

  • 新眉头下常驻一条最近两周的日期条(横滑,最右是今天):不用点就知道哪天有早报、哪天失败、哪天多版;点一天就地切换。
  • 新最左「月历」进底页月历看更早的;多版的日子选中后,版次排在日期条下方。字段全部来自 /reader/briefs 列表。

往期 ③ 往期列表

整页列表,按月分组;每期一行头条标题(需后端补字段)

  • 新「往期 ›」推入整页列表(返回 / Esc / 系统返回出栈):按月分组,每行 = 日期块 + 版次 · 编排时刻 · 篇数 + 状态签;多版的日子下面列出旧版。
  • 需后端每期一行头条标题:列表端点现在不带条目(include_items=False),需要后端补 headline 字段;今天那一期的头条来自今日接口,现成。
  • 留篇数 = selection_stats.selected_count,「含 N 条重大事件」= breaking_count,降级 / 失败 = status,都已在列表里。

两台手机都能点:点卡片进正文、长按(或右键)出动作单、点「全部来源」开来源底页、点「往期」看所选方案;Esc 或浏览器返回关最上面那层。顶栏可切页面主题、中性色、动效(完整 / 减少)与机型宽度。
