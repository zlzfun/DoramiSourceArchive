内容 · 文章

  • 修第 1 轮的两条根因在新形态下都不存在:开关在固定的顶栏里,不在任何横滑轨里;它只有 aria-pressed / class 两态,没有要量宽度的拇指。自检照第 1 轮的 10 个步骤复测。
  • 简页头只剩一排(视图切换并进顶栏),列表上方只有类型胶囊一条(只有文章有类型)。大标题下的「全部来源 ⌄」移走,按来源看去「订阅」Tab;顶栏的收藏筛选移到「订阅」Tab 的「收藏」。
  • 删视图上的未读点取消(第 3 轮):转盘上不挂点;条目自身仍靠标题字重与墨色区分已读未读。
  • 留卡片、按压、长按抬起、类型胶囊横滑不变;按类型筛选时收起「全部标读」(与现网同口径)。
