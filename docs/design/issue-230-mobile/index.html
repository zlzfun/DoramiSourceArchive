三个方向

同一组真实数据(9 月 16 日本地库快照)、同一套 index.css token,画出「高级感、简约」的三种走法:纸面、仪器、夜航。每个方向都画了同一组关键屏(条目流 / 正文页 / 源抽屉 / 长按动作单 / 我的与设置 / 个人早报)× 亮暗,方向页里还有一台能点的试玩机。拍板一个,或按页尾的小项组合。

拍板清单

一、方向(选一个,或组合)

  • A一张印好的纸:宋体标题、发丝线、六个字的 TabBar,动效只有翻页与浮现。
  • B一台精密的仪器:44px 栅格、一族带拇指的分段、分数落固定右列,密度最高、改动最小。
  • C一段夜航:内容铺满,磨砂镀层随滚动退场,底页可拖、卡片抬起,弹簧手感最强。
  • 组合例:B 的骨架与密度 + A 的报头与正文页 + C 的底页弹簧
