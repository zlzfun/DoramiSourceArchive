悬浮卡里的按钮

状态:待选(2026-10-29)

用户第 8 轮对旧展开页的意见:「按钮的大小不统一（一些人可能不喜欢）」「1x、缩小、关闭这几个按钮纯文字，太草率，且这三个按钮与上方的圆形按钮对齐性很一般」「前进、后退按钮没注明多少秒」;选定 B 悬浮卡之后,又要求把「悬浮卡展开后的按钮大小和布局重新再设计，探索一些可能的方向」。这里给四个方向,另加现状 B(player 页里 B 的按钮原样)当尺子。拍板 32 / 33 已定、各方向共用的部分不动:卡浮在底栏之上 8px(正文页在安全区之上 8px),底栏照常能点;背后淡压暗,点卡外只收卡、不穿透,展开时背后不滚;坞是一行 60px 浮动胶囊,只留播放 / 暂停;右上 ⌄ 去掉,卡顶中间是抓手(样子同主样页 .c-grab,真按钮「收起播放器」,命中区 120 × 44,上沿伸出卡外 16px);整张卡往下拖(进度条除外)、点卡外、Esc 都能收起。控件不加不减,只用现网已有的能力:播放 / 暂停;后退 15 / 前进 15(箭头里写 15);倍速 1 → 1.25 → 1.5 → 2 循环(钮上写当前档位);停止播放(■,停播并收掉坞,提示条带「撤销」,这是唯一获准的新增);进度条(拖、← → 5 秒、PageUp / PageDown 30 秒、Home / End,显示时间);封面与标题(点标题推入这一期,播放不中断);缓冲、出错重试、AI 生成标识。停止播放一律不放卡的右上角(那是「关闭」位),也不紧贴 ±15,每个方向都量了它离最近主控件多远。四个方向在几条轴上拉开:尺寸档数(1 / 2 / 2 / 2,现状 3)、一行还是两行、形状(圆钮 / 标签键 / 分段控制带 / 封面加胶囊)、卡高与主控件离拇指多近、标题与封面怎么摆。卡里的标题改用宋体 600(夜航的标题字,英文题走 Dorami Latin Serif),现状 B 仍是黑体。每个方向两台手机(亮暗各一套):列表页展开态 / 正文页展开态,都能点;收起态的坞各方向共用,画在现状 B 一节。页顶另有 状态(正常 / 缓冲 / 出错)· 条目(原节目 / AI 导读 / 长标题)两组开关与「重置」。文中尺寸都是 Playwright 实测的手机屏坐标(sat 47 / sab 34,屏高 740),宽 360 / 390 / 430 × Chromium / WebKit。播放器的表面都是封面模糊底(issue #199 拍板,不用 backdrop-filter);Playwright 的 WebKit 不渲染 backdrop-filter,只在底栏、页头小圆钮上看到降级观感,真机 Safari 有模糊。

对照

  • 两行同一套三列栅格,同列偏差 0;停止播放在细线下第 3 列,离 +15 有 26 和一道细线

B1

一排五钮

推荐第 1

最简的一档:倍速 · −15 · 播放 · +15 · 停止播放 五枚一样大(48)的圆钮排成一行。播放不靠尺寸、靠墨色实底;±15 是浅底,倍速与停止是细环,更安静。两道竖细线把「倍速 | 三枚 | 停止」分成三组:倍速左沿、停止右沿对齐进度行两端,三枚居中。「这一期」只用 48 的小封面 + 两行标题,卡最矮(208)。用户的三条意见各自对上:大小统一;没有纯文字钮(倍速钮写 1×、停止是 ■,都在同样大的圆里);±15 的箭头里写 15。

优点

  • 尺寸完全统一:五枚都是 48,用户的第一条意见直接没了;形状也只有圆一种,主次靠填充(实底 > 浅底 > 细环)
  • 卡最矮:208,只占屏高 28%(现状 B 39%),360 宽背后露出 321;五枚在同一行,中心离屏底 150,是四个方向里离拇指最近的一档
  • 一行对齐不用解释:五枚中心在同一水平线、播放居中、两端与进度行对齐,偏差全 0
  • 标题最宽(360 宽 244),长标题两行能放更多字

风险

  • 停止播放与 +15 在同一行:360 宽只隔 22(中间一道竖细线,外观换成细环),390 / 430 宽 37 / 57;手偏一点会停,靠「撤销」兜底
  • 播放与旁边四枚一样大,只多一层墨色实底;习惯「播放最大」的人第一眼可能要找一下
  • 倍速与停止只有「1×」与 ■,不写字;读屏有名字,看的人要认图标(■ 是通用的停止记号)

B2

标签键

推荐第 2

两档、同一套栅格:播放是 64 的墨色圆钮,其余四枚(后退 · 前进 · 倍速 · 停止)全是同一种「图标在上、小字在下」的键(64 × 52,浅底),每枚都写明是什么。两行共用三列栅格:上行 倍速 · 时间 · 停止,下行 后退 · 播放 · 前进。常用的 ±15 与播放在下行、离拇指最近,少用的倍速与停止在上行;进度条两端不再写时间,时间写在上行中列,就在进度条下面。

优点

  • 最好认:后退 / 前进 / 倍速 / 停止都在图标下写字,±15 箭头里写 15,「停止」不会再被当成「关闭」
  • 两档:播放 64 圆钮,其余四枚同一种键、同一尺寸;两行同一套三列栅格,同列与栅格偏差 0(时间也在中列)
  • 常用的在下:±15 与播放在最下一行(中心离屏底 158),倍速与停止在上一行

风险

  • 卡最高:288,比现状 B 还高 2;360 宽背后露出 241
  • 四枚都带字,像一块工具面板,没有 B1 / B3 安静
  • 停止在 +15 正上方,上下隔 18;手往上偏会停,靠「撤销」兜底
  • 进度条两端不写时间、时间挪到栅格中列,和多数播放器的习惯不同

B3

控制带

推荐第 3

把 −15 · 播放 · +15 做成一条连续的分段胶囊:三段等高 56,宽 1 : 1.3 : 1,整条浅底,播放段里嵌一枚墨色实底胶囊(左右各让 4px),±15 两段只有写着 15 的箭头。下面一行是安静的「图标 + 字」:⏲ 倍速 1× 左沿对齐控制带左端,■ 停止播放 右沿对齐右端,离控制带 16。主控件是一整条、最好按(360 宽 ±15 每段 92 宽),倍速与停止写全了字,不会认错。

优点

  • 主控件是一整条:三段等高 56,−15 / +15 每段 92 宽(360 宽)、播放段 120 宽,四个方向里命中区最大;一条胶囊也最有自己的样子,不像哪家播放器
  • 倍速与停止写全了字(「倍速 1×」「停止播放」),停止不会被当成关闭;两端对齐控制带,偏差 0
  • 卡高 268,比现状 B 矮 18

风险

  • 下面一行是不带底的「图标 + 字」,和用户嫌「太草率」的 1× / 缩小 / 关闭 是同一类;有图标、对齐了两端,仍可能被看成字钮(备选:这一行加浅底,见待拍板 6)
  • 停止播放在 +15 段正下方,上下只隔 16,四个方向里最近
  • 控制带横贯整张卡,乍看像一个开关;第一次用的人要看一眼才知道左右两段是 ±15

封面即播放

推荐第 4

信息与控制合一:这一期的封面(96)就是播放 / 暂停钮,正中一枚 44 的墨色实底圆片写着当前动作(❚❚ / ▶;缓冲时外圈细弧,出错时 ↻ 且封面转灰);封面右边是标题,点了推入这一期。进度条下面一排四枚等宽胶囊 ⟲15 后退 · 15⟳ 前进 · ⏲ 1× · ■ 停止,四列栅格,首末两端对齐进度行。停止在最右,和 ±15 之间隔着倍速;卡里没有单独的播放圆钮。

优点

  • 停止播放离主控件最远:中间隔着倍速,边距 83.5(360 宽)/ 91 / 101
  • 封面就是最大的播放目标(96 × 96),认得出是哪一期,也省了一枚播放圆钮;卡 236 高,第二矮
  • 四枚胶囊同宽同高、都写字,四列栅格偏差 0,首末两端对齐进度行

风险

  • 播放在卡的左上:中心离屏底 272(B1 是 150),单手最难够;收起后坞上的播放钮可以补
  • 列表里点封面是「打开这一期」,这里点封面是「暂停」,第一次可能点错(无害,再点一下就回来)
  • 标题最窄(360 宽 194);±15 不在播放两边,而是下面一排的左两枚
