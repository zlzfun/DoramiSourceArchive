用户原话(第 7 轮,对着订阅 Tab):「这个页面头部比较奇怪，用户头像与标题都占据一行的左侧，但右侧/屏幕中心的大片空间又是空着的。是否可以标题与头像同行？早报、榜单也有类似的问题。」「早报、订阅、内容页来回切换的时候，同样是头部的这块标题和头像附近的空间会有一些布局的小变化，显得缺少一致性。」这里给三个方向,另加现状当尺子。三个方向守同一组约束:每个 Tab 只有一行 52px 页头;头像不动(按钮左 8px、中心 30, sat + 26);标题位第一项的字形左沿 62px、与内容 Tab 转盘的当前项同一字样(宋体 600,16px × 1.3 = 20.8px,墨色);右侧动作钮右沿 6px、命中区 44;页头下第一块一律从 sat + 56 开始;Tab 根页不再有大标题,也就没有「大标题收进顶栏」,滚动后顶栏照旧换镀层底。每个方向两台手机(亮暗各一套):整屏能点底栏、头像(推入设置,再点外观进二级页)、转盘与分段、早报日期、只看未读、搜索,也能上下滚;页头一览把 早报 / 内容 / 订阅 / 榜单 / 设置 五条页头叠在一起,画头像中心、标题字形左沿、标题基线三条参考线(以内容那一条为准)。页顶「身份」可切游客。文中尺寸都是 Playwright 实测的手机屏坐标(sat = 47),宽 360 / 390 / 430 × Chromium / WebKit。

B

标题即切换

推荐第 1

标题位就是每个 Tab 的主切换,全部用同一个转盘组件(同字样、同左锚定、三项固定位,当前项以左沿为原点放大 1.3 倍、转墨色,其余 faint):内容 = 文章 / 播客 / 社交;订阅 = 订阅 / 兴趣(宽分段那一行删掉);榜单 = 文章榜 / 播客榜(大标题行的分段删掉,话题 / 产业 / 实体 宽分段照旧在下面);早报没有可切的,标题位只放「早报」一项(当前项字样);设置页 = 返回 · 设置。槽宽随字数(上限 = 字数 × 20.8 + 20px),3 个字的「文章榜」放大后 64.9px,比现行转盘的槽上限 64px 还宽,所以榜单的槽是 84.9px。

优点

  • 四个 Tab 只有一种页头结构、一个标题位组件:切 Tab 时标题位置、字样、基线都不变,变的只是字;五页之间七项偏差全 0(三种宽度 × 两种引擎),往期、只看未读、外观也 0
  • 订阅 / 榜单各省一行:订阅首张分组卡从 204(现状)/ 157(A)上到 103,榜单首张榜卡从 253 上到 203;「订阅」标题与「订阅」分段的重复没了

胶囊页头

推荐第 3

B 的结构,画成两枚浮动磨砂胶囊:左 = 头像(或返回钮)+ 标题位 / 转盘,右 = 动作钮(只有一枚时是一个圆);两枚之间至少 8px(--c-float),呼应底栏胶囊与正文页右上的浮动钮。没有整条镀层底,内容从胶囊底下和两枚胶囊之间滚过,状态栏下只垫一抹渐隐。注意:Playwright 的 WebKit 不渲染 backdrop-filter,那边看到的是没有模糊的降级观感(胶囊底下的字透出来);真机 Safari 有模糊。

优点

  • 页头、底栏、正文页右上的钮都是浮动磨砂件,一个语言;静止时页头只有两枚小胶囊,比整条顶栏轻
  • 结构与 B 完全相同,七项偏差同样全 0;选了 C 以后想退回 B,只是去掉胶囊底

风险

  • 360 宽内容 Tab 最挤:左胶囊 8–214、右胶囊 222–354,两枚之间 8px;转盘槽压到 50.7,当前项与下一项只隔 7.4(B 13.4),选中「社交」离胶囊尾 7.4
  • 全靠 backdrop-filter:没有整条镀层底,滚动时正文从胶囊周围和两枚之间露出来;低端安卓 / 部分内置浏览器不支持时退成 94% 近实色(dir-c 现有降级);Playwright WebKit 截图里胶囊透字就是这种降级观感
  • 读者面多了两块漂浮的形状,滚动时页面更花;返回钮、头像都包在胶囊里,和底栏胶囊在视觉上抢主次
