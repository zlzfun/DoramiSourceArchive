底栏怎么分

状态:已选 A(2026-10-29),已回写主样页

用户原话:「内容列表底栏的五个元素有点拥挤;我在考虑是否将榜单作为订阅的一部分,或者将设置安插到点击用户头像之类的入口。」这里给四个方向,另加一行现状五项当尺子。每个方向画两台整屏手机(亮暗各一套,都能点、能切 Tab):第 1 台是底栏 + 内容 Tab 的第一屏(嫌挤的就是这里);第 2 台是被挪走的那一项现在住在哪、怎么进去;A / C 再加一列「页头一览」,看头像是不是在每个 Tab 的同一位置。页顶「身份」可切游客。文中尺寸都是 Playwright 在 360 宽实测的 bounding box。

方向4 个 + 现状对照每个方向亮暗两套 · 底栏 + 内容 Tab / 挪走的那一项 / 页头一览(A、C)选定后回写主样页底栏(全部屏)、早报 / 订阅 / 榜单 / 设置各屏页头与设置栈;README 拍板 16、19、20、21

总表 360 宽实测:底栏胶囊都是 336 × 62(左右各留 12px);「每格」= 一个 Tab 的宽,「空白」= 相邻两个标签之间的空白

每个方向都按同一份清单处理:360 宽实测、挪走的入口还好不好找、第一次用的人怎么发现、游客、「反馈与建议」的回复角标落在哪、移植会碰到现网哪些部分(MobileReader 的底栏与 tab 状态、MobileSettings、RankingsPage 与 #221 的边界)。

五项

对照

第 5 轮主样页的底栏:早报 · 内容 · 订阅 · 榜单 · 设置,浮动磨砂胶囊 + 镜片拇指;只有内容 Tab 的页头有头像,点了切到设置 Tab。放在这里当尺子,底栏可以点,切到其余四个 Tab 看它们现在的页头。

  • 与第 5 轮主样页、拍板 16 / 17 一致,不用再改

  • 360 宽每格 65.6px:五个 22px 图标 + 五个 12px / 600 的标签挤在 336px 的胶囊里,相邻标签只隔 41.6px——用户说的「有点拥挤」
  • 设置是最低频的目的地,却和天天用的早报、内容占一样大的一格

A

设置进头像

推荐第 1

底栏只留四个内容目的地:早报 · 内容 · 订阅 · 榜单。设置挪到四个 Tab 页头左上的同一个头像后面:点头像,设置整页从右侧推入,盖住底栏与播放坞,返回钮落在头像原位;外观等二级页照旧往里推(设置栈沿用)。

优点

  • 底栏每格 65.6 → 82px,相邻标签空白 41.6 → 58px;四项都还写字,不靠认图标
  • 头像 = 我的 / 设置是最通用的约定;内容 Tab 第 5 轮本来就是头像 → 设置,这里只是推广到每个 Tab
  • 挪走的是最低频的那一项,留下的早报 / 内容 / 订阅 / 榜单都是天天用的内容入口
  • 移植最省:现网设置本来就是整页层(MobileSettings,useLayerHistory 管根页 / 分区 / 预览三层),从头像打开即可

风险

  • 早报、订阅、榜单的页头都要让出头像位;早报原来的单行眉头放不下头像(实测 360 宽超出 27px,390 宽零余量),本稿拆成两行,头条下移 24px
  • 想找齿轮改外观 / 阅读偏好的人,第一次要想到点头像;「添加到主屏幕」也跟着进了头像
  • 反馈回复的角标更深了一层(头像 → 设置 → 反馈与建议),要不要外露见待拍板

B

榜单并入订阅

推荐第 4

底栏 早报 · 内容 · 订阅 · 设置;榜单变成订阅 Tab 的第三段:订阅 | 兴趣 | 榜单。榜单自己还有两组分段(现网 RankingsPage:文章榜 / 播客榜,话题 / 产业 / 实体),进了订阅就叠成三层——本稿如实画出。Tab 名保留「订阅」。

优点

  • 底栏同样四项,每格 82px
  • 与桌面同构:桌面阅读器的榜单入口本来就在源栏里(ReaderTab 的「文章榜 / 播客榜 · 近 7 天标签趋势」);现网发现页的分段也是 源 | 合集 | 兴趣 | 榜单
  • 设置仍占一格,找设置的人不用学新入口

风险

  • 三层分段:订阅的大标题不是「榜单」,文章榜 | 播客榜 没法像榜单 Tab 那样放在大标题右侧,只能另起一排;360 宽首条榜单行从 y 296 落到 395(下移 99px,第一屏少两行)
  • 语义打架:榜单页写着「与个人订阅无关」,却住在「订阅」下;订阅列表里还有一组来源也叫「榜单」(信息角色 leaderboard:HF Papers / HN / GitHub Trending),同一个 Tab 里两个「榜单」
  • 兴趣分面叫 主题 / 行业 / 实体,榜单分类叫 话题 / 产业 / 实体,两套叫法在同一个 Tab 里挨着
  • 取舍方向反了:挪走的是天天看、游客也能看的榜单,留下的是最低频的设置

D

五项不变、只减负

推荐第 2

不搬任何东西,只给底栏减负:图标细一号(22 → 20px、笔画 1.8 → 1.6)、没选中的标签字重 600 → 400、去掉镜片,选中只靠墨色 + 字重。第 2 台是更激进的 D′:只给当前项写字,等宽格不变、不换宽度,没选中的只剩图标、落在中线。

优点

  • 改动最小:信息架构和主样页其余各屏都不动,随时能回退
  • D 五个标签都在,不靠认图标;镜片拿掉后底栏只剩线条与字,轻了一档
  • D′ 一眼只剩五个图标 + 一个字,最安静

风险

  • 格数没变:每格仍是 65.6px,相邻标签空白仍是 41.6px——D 只是轻了,没有松
  • D 去掉镜片后,选中态只剩颜色和字重;页里的分段(订阅 | 兴趣 等)还用镜片,两处不再是同一种语言
  • D′ 四格只剩图标:内容(叠层)、订阅(书架)、榜单(柱图)不是一看就懂,第一次用要挨个点(读屏靠 aria-label,不受影响)
  • D′ 的「只有当前项写字」与 Material 的选中才显示标签、Folo 的当前项带字是一路;本稿等宽格、不换宽度、没有色块,仍要留意观感
