A

栏目

推荐第 1

报纸栏目式的宋体文字页签:当前一栏墨色,其余退成淡字,下面一道细线跟着走;顶栏不动。

优点

  • 最安静:没有任何底色块,和早报刊头、宋体大标题是同一种语言
  • 两个字的栏目名一目了然,不靠图标猜
  • 与类型胶囊质感不同(一个是字,一个是磨砂胶囊),两排叠在一起也分得清层级

风险

  • 宋体页签不太像按钮,第一次用的人可能当成标题;可点的暗示只有细线与间距
  • 占一整排,页头比一排的方向高约 48px

B

转盘

推荐第 2

标题即切换器:顶栏中间是一圈宋体刊名转盘,当前视图放大居中,左右邻居淡出半截;点邻居或横拖切换,省掉一整排。

优点

  • 页头只剩一排,正文多出约 48px
  • 当前位置最醒目(放大的宋体),「我在哪」一眼就知道
  • 横拖切换顺手,弹簧回位有物理感

风险

  • 同时只看得见三个,第四个要拖一下才出来
  • 横拖要避开系统返回的屏幕边缘手势
  • 被左头像、右三钮夹着,转盘中心不在屏幕正中

C

镜片

推荐第 3

与 TabBar 同族的磨砂轨 + 浅色镜片:四格都写字(图标 + 名称),选中是一枚 accent 淡底的镜片,弹簧滑动。

优点

  • 和底栏、订阅 | 兴趣同一种控件,系统感最强,最好认
  • 选中清楚但不重:淡底 + accent 字,不是黑块
  • 图标 + 文字,不必猜

风险

  • 屏上一条磨砂轨、屏下一条底栏,再加类型胶囊,玻璃件偏多、显重
  • 看起来像第二个 TabBar

D

翻页

推荐第 5

内容横滑翻页:列表本身左右滑就换视图,页签下的指示条跟着手指走,滑到两页之间时拉长。

优点

  • 手感最「原生」,很多资讯 App 这样做
  • 指示条跟手,来去方向清楚
  • 页签是黑体文字,轻

风险

  • 横滑和类型胶囊、推文配图、长按、系统返回手势都抢
  • 相邻视图的列表要同时在场:现网 useReaderState 只有一条列表(mode 单值),要么拆成按视图缓存的多列表,要么滑动时只切 mode 再拉取(跟手就成了假的)
