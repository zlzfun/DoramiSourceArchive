方向 A · issue #230 手机端(H5 / 窄屏)视觉方向

纸面

把手机当成一张印好的纸:全壳同一底色,分隔只剩发丝线与留白;标题用宋体放大一档,读起来像报纸的栏目;界面词代替图标——TabBar 是六个字,过滤是一行字;动效只有「翻页」与「浮现」两种。它对应「高级感、简约」里安静、克制、文气的那一面,代价是密度最低。

关键屏6 × 亮暗动效2 种(翻页 / 浮现)新增 token3 个条目密度约 3.5 条 / 屏数据9 月 16 日本地库快照(真实标题 / 摘要 / 分数)

试玩 页面顶部「动效」可切「减少」,看降级后的样子

怎么玩

点条目进正文(翻页),正文里点「下一篇」再翻一页;长按条目(或右键)出动作单;点「文章」下的「全部来源」开源抽屉。右侧按钮做同样的事。

其余一律即时:按下只换底色,选中只换字重与墨线,没有缩放、没有弹簧。

六个关键屏 每屏亮 / 暗;标签:新 = 新增,删 = 删掉,简 = 简化,留 = 沿用

① 条目流

顶栏 + 全部 | 未读 + 内容类型 + 条目(分数 / 来源 / 时间 / 读态)+ TabBar + 播放坞
  • 删顶栏的 ☰、未读分段的槽与拇指、收藏星图标钮;列表面 / 纸面两层底色(全壳一张纸)。
  • 新报头:宋体栏名 26px + 下方「全部来源 ⌄」——源抽屉是过滤器,标题下写出当前过滤值,点它换来源(§4.1.2)。
  • 简过滤一行字:全部 / 未读 · 收藏 │ 论文 教程 …(类型横滑);选中 = 墨色 600 + 一道墨线。
  • 新条目标题改宋体 600 / 17px,署名行挪到摘要下(来源 · 类型 · 时间 …… 分数);宋体没有 400,读态改为墨色退一档(读屏仍报「未读」)。
  • 新TabBar 去图标,只剩六个字;播放坞是贴着 TabBar 的一条纸带,上沿的发丝线就是进度。

② 正文页

眉头 / 标题 / 原标题 / 署名 / 听导读 / 译钮 / AI 速读 / 正文 / 上一篇下一篇 / 顶部动作
  • 简顶栏只剩 返回 · 收藏 · 更多:分享、查看原文、复制链接都进「更多」(与长按同一份动作)。
  • 新译钮下沉:顶栏「译」→ 标题区尾行「原文 中文」两个字,与桌面阅读窗的语言二段同语;译文态仍是 AI 渐变字。
  • 简AI 速读去掉卡片底,改为上下两道发丝线夹住的「编者提要」;分数与评分依据(触屏常显一行)不变。
  • 新标题放大到 27px;阅读进度 = 顶栏下沿 1px 墨线;上一篇 / 下一篇是两行宋体题目,点了就「翻页」。

③ 源抽屉

过滤器,不是目的地:全部文章 / 订阅 | 兴趣 / 信息角色分组 / 有未读 / 暂不可用
  • 新抽屉顶部恢复「全部文章」:清除来源过滤的显式出口(现状只能再点一次 TabBar)。
  • 简订阅 | 兴趣 改成两个字;源行 48px(现状 40,不到触控下限);选中 = 600 + 行尾 ✓;有未读只靠墨色,不画计数(§3)。
  • 删抽屉投影:与列表之间只有遮罩 + 一道发丝线。

④ 长按动作单

桌面右键菜单同构:读态 · 收藏 → 链接 → 该源全部已读
  • 删行首图标:动作单只剩字,行高 50。
  • 新头部用宋体两行写出被长按的那一条 + 来源 · 时间(现状是一行 12px 灰字,看不清对象)。
  • 留items 与桌面右键菜单同构(读态 · 收藏 → 复制链接 · 分享给… · 打开原文 → 该源全部已读)。

⑤ 我的 + 设置栈

「我的」页(亮)与设置栈一级页(暗);试玩里可切游客视角
  • 删卡片与行首图标;分组小字 + 发丝线行,外观三态是三个字。
  • 留用户名宋体;退出登录独立一组、红字。游客:身份行换成「游客 · 登录后可收藏、订阅、设置兴趣 · 登录」(试玩「游客视角」)。
  • 留设置栈一级页同一语法:组名小字 + 行 + 右侧灰色说明;反馈未读是一个 accent 数字。

⑥ 个人早报

夜航版式的手机档:眉头 · 往期 · 重新编排 → 头条 → 评分栏 → 板块
  • 留夜航结构不变:眉头 · 往期 · 重新编排 → 头条 → 评分栏 → 板块 → 本期编排。
  • 新眉头下压一道报头双线;头条宋体 900 / 33px。
  • 删头条背后的 AI 环境光(纸不发光;AI 身份仍由 ✦ 与渐变分数承担)——需拍板。
  • 简主按钮改墨色实底(一屏唯一实心),收藏是一个字钮。

风险

  • 宋体条目标题让列表密度降到约 3.5 条 / 屏(现状约 5 条),扫读效率下降最明显。
  • 读态只剩颜色一条通道(Dorami Serif 只有 600 / 900):要拍板,或采用「纸面 + 黑体条目标题」的组合。
  • 无图标 TabBar 对第一次使用的人略弱(字本身就是语义,风险小)。
  • 条目标题用字面大,首屏要多拉几片宋体分片(实测本页 280 个字的子集约 110KB)。
