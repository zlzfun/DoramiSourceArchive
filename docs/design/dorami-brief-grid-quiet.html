早报板块网格 · 1–8 张卡的版式候选

列数

板块内条目已按分数降序(重大事件恒前 → 兴趣 → 质量)。同一张数下结果相同的策略合并显示,只看差异;每帧右上角是行模式简写。三列对应生产 1120 宽报纸面(内容 1032,每小卡 335);两列对应窗口收窄。整报头版通栏与板块策略正交,只在最后一块画板里出现。

F 参数改了即时重排全页;板块内一律按分数降序(F 的前提,也是 issue #74 板块重排时顺手定的口径)
A现状

auto-fill,余数留白。第一板块首张通栏、板块 1 张通栏,其余全小卡。

B尾行拉伸

整行排满,末行余 1 通栏、余 2 各半。余数在尾,读者读到最后才见宽卡。

C首行拉伸

余数放板块开头。头卡恒是板块最高分,横跨有含义,与整报头版同一语法。

D均分行

余 1 时向上一行借一张,末两行各 2。板块内只有整 / 半两种宽,永不通栏。

E错落

余数用 ⅔ + ⅓ 配对,余 1 再镜像一行。三种宽度,节奏最活,也最不安静。

F分值驱动

≥ T 独占一行;并排两卡分差 ≥ Δ 用 ⅔ + ⅓,否则各半;余 1 时头卡够高才通栏,否则 2 + 2。

F · 同一张数换分数规则对分数的反应;每帧上方一行是它做每个决定的理由

四条规则,两个数:T(绝对通栏线,默认 9.0,与「9+ 完整渐变」同档——见渐变即值得看,通栏也是同一个信号)与 Δ(「显著高于」的分差,默认 1.0,一个整数档;评分复评本身有 ±0.5 摆动,1.0 以下的差异不该驱动版式)。

每一处横跨都有理由:通栏 = 过线或比第二张高一档;⅔ = 比同行那张高一档;各半 = 咬得紧。没有「因为余数」而变宽的卡。

代价:板块内顺序必须是分数降序(现状是 兴趣通道 → 质量通道 再各按分数,命中的 6.6 会排在 8.0 前面);同一天重编后分数快照不变,版式稳定;跨天则随分数自然变化——这是想要的「灵活」,不是抖动。

两列容器:⅓ 只有 246 宽,放不下衬线标题,故只保留 通栏 / 各半 两种,余 1 通栏落板块头。

整页节奏同一份早报换策略看整体;第一板块 = 头版通栏 + 策略(N−1)
策略
分布

典型日:2 条重大事件 + 10 篇精选,落成 5 个板块(2 / 4 / 3 / 1 / 2)。清淡日:无重大事件,8 篇落 4 个板块(1 / 4 / 2 / 1)。忙日:2 + 10 落 3 个板块(2 / 7 / 3)——板块少而长,余数问题最显。

看什么:一页里通栏卡出现几次、在哪;板块之间的节奏是否重复(每个板块都以通栏开头会变成「标题 + 大卡」的固定套路);半宽卡与小卡混排时视线是否跳。

头版:现状 = 第一板块首张;板块固定顺序后它恒落「重大事件」或「模型发布」。是否改成「全报最高分那张」另议,本页按现状画。
