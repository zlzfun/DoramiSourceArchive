# 动效样页 · 方向规格(给实现各方向的人)

底稿是 #279 的可点原型。`assets/app.js` 把每个交互交给 `M.run(kind, ctx, mutate)`,方向文件 `assets/dir-<x>.{css,js}` 决定怎么动。
公共工具在 `assets/motion-core.js`(文件头有接口说明),对照基线在 `assets/dir-0.*`。

## 一、接口

| kind | ctx | mutate 做什么 |
|---|---|---|
| `boot` | `view` | 第一次画出整个界面(`#app` 此前是空的) |
| `nav` | `from` `to` `dy`(导轨上的位置差,正 = 往下) `el` | 整页重画 |
| `open` | `id` `from`(`list` / `go` / `brief` / `rank` / `event` / `discover`) `prev` `el` `sel` `inQa` | `list` / `go`:只换选中行的类名 + 重画阅读窗;其余:整页重画 |
| `back` | `to`(`brief` / `rank`) `id` | 整页重画 |
| `event` | `open` `id` `el` | 整页重画(榜单 ⇄ 事件页) |
| `fold` | `fold` | 没有浮层时只切 `.feed.fold` 类名;否则重画工作区 |
| `pop` | `name`(`cal` / `menu` / `srcpop`) `open` `el` `sel` | 重画工作区(`menu` 只重画阅读窗) |
| `qa` | `open` `el`(导轨上的问答钮) `sel` | 只重画问答槽 |
| `qaask` | — | 只换 `.qa-b` 的内容 |
| `why` | `open` `sel` | 重画阅读窗(保留滚动) |
| `filter` | `group`(`unread` `kind` `scope` `src` `favonly` `podtab` `ranktab` `rankwin` `disctab` `discshape`) `value` `el` | 重画工作区 |
| `fav` / `sub` / `markall` / `unread` | `id` `on` `el` `sel` `undo` | 重画工作区;**紧接着会有一次 `toast`** |
| `toast` | `phase`(`in` / `out`) `replace` `sel` | 只换提示槽 |
| `theme` | `to` `el` | 整页重画 |
| `search` / `unclip` / `dock` | — | 不在本轮范围,别接(播放条是现网已有的具名例外) |

- `ctx.key === true`:键盘触发(回车、j / k、Esc)。**一律不做动效**,直接 `mutate()`。
- `ctx.rect`:触发元素在重画前的位置;重画后用 `M.refind(ctx)` 找回同一个元素。
- 重画是 `innerHTML` 整段替换:旧元素会消失,挂在元素上的监听与内联样式都会丢。常驻的东西用文档级事件委托,或在 `rendered(scope)` 里重新挂。
- `fav` / `sub` / `markall` / `unread` 后面紧跟 `toast`,所以这几类和 `toast` 都**不要用 View Transitions**(后一个会把前一个直接打到终态),用 `M.exit` / `M.animate` / `M.flip`。
- 悬停样式写 `:is(:hover, .m-hover)`,按下样式写 `:is(:active, .m-press)`——对照页的假光标靠这两个类演示。
- 假光标脚本(`M.scenes`)按选择器找元素:不要改底稿的 DOM 结构与类名,可以加元素。

## 二、所有方向都要守的

1. 只动 `transform` / `opacity` / `clip-path`,`filter` 只用在有边界的小区域或 ≤ 300ms;不动 `width` / `height` / `top` / `left`(来源栏的列宽过渡是底稿已有的例外)。
2. 不从 `scale(0)` 出场;离场比入场快;从哪边来回哪边去。
3. 高频路径不拖:常规交互 ≤ 300ms,界面一出现就能点;签名时刻可以长,但不挡操作。
4. 错峰不等距、不超过 5 件、常规界面里总长 ≤ 300ms;一个容器只有一层入场(容器进场了,里面的东西就不再各自进场)。
5. 连点、反复开合、动画中途切视图都不能坏:自己连点试过再交。
6. 亮暗两套都要对;暗色是主场。
7. 样式全部挂在 `[data-dir="<x>"]` 下,keyframes 与 view-transition 名字带方向前缀;`dispose()` 把自己加的东西清干净。
8. 文件头用 CSS 变量写出本方向的 token(时长、曲线、弹簧参数),并在 `M.register` 里给 `tokens: [{ name, value, use }]` 与 `notes`(14 个场景各一行参数,不超过 28 个字,写数值不写口号)。
9. 弹簧 `M.spring({ duration, bounce })`:bounce 0.2 ≈ 过冲 1.5%,0.35 ≈ 6%,0.5 ≈ 16%。

## 三、十四个场景(对照页逐行并排比较,每个方向都要有答案;「保持不动」也是答案,写进 notes)

`press` 悬停与按下 · `ind` 指示器与筛选 · `pop` 浮层开合 · `open` 打开一篇文章 · `nav` 切换视图 · `fold` 来源栏收起与展开 ·
`qa` 问答面板 · `brief` 早报到场 · `ai` AI 速读卡 · `toast` 收藏、标读与提示 · `theme` 明暗切换 · `scroll` 阅读时滚动 ·
`event` 榜单进事件页 · `sub` 订阅一个来源

## 四、四个方向

### A 精密 —— 界面是一台调校过的仪器
件有质量与阻尼,动作短、准、可打断;不加入场编排。学的是 Emil Kowalski / Linear / Raycast 一路。
材料:弹簧(临界阻尼为主)、滑动的指示器、对准触发点的缩放。

- token 起点:`ease-out cubic-bezier(0.23, 1, 0.32, 1)`、`ease-in-out cubic-bezier(0.77, 0, 0.175, 1)`、`drawer cubic-bezier(0.32, 0.72, 0, 1)`;按下 120 / 快 150 / 常 200 / 面板 280;弹簧 `snappy(.28, 0)` `glide(.32, .12)` `pop(.35, .35)`。
- `press`:所有可按的件按下缩到 0.97(整行 / 整卡 0.985,导轨只缩图标),松手弹回;悬停变底「进快出慢」(100 / 180ms);提示第一次等 350ms,刚看过一个之后的 600ms 内下一个立刻出。
- `ind`:分段拇指、页签下划线、类型签、导轨选中块、来源栏选中、列表选中行,全部用 `M.glide` 滑过去(弹簧)。筛选后列表行用 `M.flip`:留下的滑到新位置,新来的淡入,走的淡出。
- `pop`:以触发钮为原点 0.96 → 1 + 淡入 150ms;关 100ms;Esc 直接关。
- `open`:选中块滑到新行;阅读窗标题区淡入 + 上移 6px(160ms),其余一起淡入(120ms)。j / k 不动。
- `nav`:内容直接换 + 100ms 淡入;导轨选中块滑动。
- `fold`:列宽 280ms(drawer 曲线)。
- `qa`:从右滑入 24px + 淡入 280ms,出 180ms;回答按段出现(每段 160ms 淡入,段间 90ms,模拟流式),来源一起出。
- `brief`:整页 180ms 淡入;头条分数逐位滚到位(≈ 600ms)。没有别的。
- `ai`:分数逐位滚动(取代 2.2s 里程表,≈ 600ms,右边一位先动);卡体淡入;「依据」展开用行高过渡 220ms。
- `toast`:自下弹入(弹簧),换提示时旧的缩到 0.94 退后;收藏星标填色 + 弹一下;全部标读时标题粗细 / 颜色 200ms 过渡。
- `theme`:整页 180ms 交叉淡化。
- `scroll`:标题滚出后,吸顶栏左侧由来源名换成文章标题(160ms),栏底出细线。
- `event`:淡入 + 上移 6px(160ms);返回 100ms 淡入。
- `sub`:按钮按下缩放,新字淡入,对勾画出来(220ms)。

### B 连续 —— 东西不凭空出现
每个界面从上一个界面里长出来,关掉时回到来处。空间有方向:导轨是纵轴,列表到正文是横轴,浮层从触发它的钮里长出来。学的是 Apple Fluid Interfaces / Material 容器变形 / Arc。
材料:共享元素(View Transitions)、容器变形(clip-path)、有方向的位移、FLIP。

- token 起点:位移弹簧 `move(.42, .12)`、大变形 `settle(.5, .18)`、明度类 180ms ease-out(位移与明度分开两族,同 Material 3 的 spatial / effects)。
- `press`:同 A 的按下语法。
- `ind`:指示器滑动时先朝目标拉长再收拢(三帧 keyframes);筛选用 FLIP,走的行淡出。
- `pop`:浮层从触发钮的矩形长出来(clip-path 从钮的位置展开,内容晚 60ms 淡入),关时收回钮里。
- `open`(列表):行标题 → 正文大标题、行分数 → 页边 / 卡头分数、来源 → 吸顶栏来源,三件共享元素过渡(≈ 380ms),正文在下面升起。从早报 / 榜单进来:标题同样共享,旧页向左退、新页从右来(前进 = 向左)。`back` 反向。j / k 不动。
- `nav`:沿导轨方向——往下切,新视图自下方 28px 升入,旧的向上退;往上切反之(≈ 320ms);导轨选中块同向同拍。导轨本身不参与位移。
- `fold`:来源栏整块向左滑到导轨下面(不是被挤扁);从「固定为来源栏」展开时,浮层变形成来源栏(共享元素)。
- `qa`:面板从导轨的问答钮长出来(clip-path 自钮心展开 ≈ 380ms),关时收回去;点建议问题,那一条飞上去变成提问气泡,回答在下面升起。
- `brief`:三拍(头条主体 / 头条页边 / 以下),间隔递减,每拍 ≈ 420ms 上升 16px。
- `ai`:分数是从行里飞来的那一个(open 的一部分);「依据」从分数钮向下展开。
- `toast`:自下弹入弹簧,原路退出;撤销「全部已读」时各行状态原位恢复。
- `theme`:以主题钮为圆心的圆形展开(≈ 520ms)。
- `scroll`:大标题滚出时「停靠」进吸顶栏——栏内小标题随滚动位置连续升入(scroll-driven,可逆)。
- `event`:榜单卡的标题 → 事件页大标题共享,卡面展开成页;返回时收回卡里。
- `sub`:来源徽标沿弧线飞到导轨上对应形态的图标(文章 / 播客 / 社交),落点轻弹一下(≈ 520ms);撤销不飞。

### C 光 —— 夜航的屏在暗处
东西不位移(≤ 4px),而是亮起、对上焦、熄灭。光可以慢一点,因为它不挡路。学的是 visionOS / Liquid Glass / Linear 与 Vercel 站点的光材质。
材料:焦点(模糊 ⇄ 清晰)、辉光与光标照明、极光(`--grad-ai` 沿边游走)、明度。

- token 起点:对焦 260ms `cubic-bezier(.2, .8, .2, 1)`、模糊半径 6–10px;光类 400–900ms;循环氛围至多一处,不可见时停。
- `press`:光标照明——行 / 卡 / 钮上跟随指针的一小团柔光(文档级 pointermove 写 `--mx` / `--my` 到悬停元素上)与朝向光标的一线亮边;按下 = 明度一沉。
- `ind`:指示器是一条光,滑动时带拖影(拉长 + 透明度);筛选后列表整体 200ms 交叉淡化,不做位移。
- `pop`:淡入 + 由虚到实(blur 6px → 0)+ 0.985 → 1,200ms;浮层下的页面压暗 4%;关 140ms。
- `open`:对焦——阅读窗由虚到实(blur 10px → 0,280ms),标题先、卡与正文晚 60ms;选中行左缘亮起一条光,上一行的光 400ms 余晖熄灭。j / k 不动。
- `nav`:旧视图 120ms 暗下去并略虚,新视图 220ms 清晰起来;新视图的导轨图标泛一次光晕(600ms)。
- `fold`:列宽 300ms,栏内内容淡出。
- `qa`(签名):玻璃面板(backdrop-filter + 半透明面);出现时由虚到实 260ms,极光沿面板边框走一圈(≈ 1.2s);工作区压暗。提问后先是一行流光的「正在检索」(≈ 900ms),回答逐段由虚到实(每段 220ms,段间 140ms),引用角标依次亮起、对应来源条跟着亮。
- `brief`(签名「破晓」):头条背后的光晕从暗处绽开(≈ 1.4s),眉题的点先亮,标题逐行由虚到实(行间 90ms),分数点亮;目录与各节 700ms 内一起亮起(不逐条)。之后光晕极慢地呼吸(16s 一周,不可见时停)。
- `ai`:卡片到场时极光沿边框扫一圈(≈ 1.1s,全站唯一的 AI 身份触点);各句依次由虚到实(句间 70ms,总长 ≤ 500ms);分数点亮(一次辉光,不滚动)。
- `toast`:深色玻璃胶囊,淡入 + 上移 4px 200ms,字上扫过一道光(600ms);收藏时星标点亮并荡开一圈光环(450ms);全部标读时各行自上而下依次暗下去(每行 30ms,至多 10 行)。
- `theme`(签名「晨昏线」):一条带羽化边的斜线扫过整屏,线后是新主题(≈ 700ms)。
- `scroll`:内容滚到吸顶栏下面时栏变玻璃;进度线是一条发光的细线。
- `event`:事件页由虚到实;时间线的节点自上而下依次点亮(每点 40ms,至多 8 点)——像跑道灯。
- `sub`:订阅成功时来源卡的边框走一圈极光,对勾亮起。

### D 刊物 —— 一份每天出版的报
动的是排印:字行从版线后面升上来,细线从左画到右,数字像航班牌一样翻。大块内容硬切,不淡入。学的是报刊排印与翻牌显示屏(夜航 + 航班牌)。
材料:行遮罩(`M.splitLines`)、画线(scaleX)、翻牌(数字与日期)、硬切。

- token 起点:揭示曲线 `cubic-bezier(0.16, 1, 0.3, 1)`;行揭示 520ms、行间 70ms;画线 600ms;翻牌每翻 70–90ms、翻 3–6 次。
- `press`:悬停标题时下划线从左画到右(220ms);按钮里的箭头前挪 3px;按下 = 下沉 1px(铅字)。
- `ind`:页签下划线先拉长盖住两格再收到新格;分段拇指用擦除;筛选后列表硬切,新行自上而下快速逐行擦出(每行 160ms、行间 18ms、至多 8 行)。
- `pop`:从上沿向下展开(clip-path,200ms),关时向上卷回(120ms)。
- `open`:大标题逐行从遮罩后升起(行间 70ms、每行 520ms),眉题前的短线先画出;署名晚 200ms 淡入;卡与正文在 120ms 处切入。j / k 不动。
- `nav`:页头大字遮罩换字,页头细线从左重画(500ms);内容硬切(80ms 淡入);导轨选中记号是一根竖的墨条,滑动。
- `fold`:栏带着一条细线滑动,260ms。
- `qa`:面板像页边批注从右滑入,左缘的线自上而下画出;回答逐行排出(行间 28ms),角标像盖章一样落下(1.4 → 1)。
- `brief`(签名「开版」):报头「早报」升起,日期与「08:30 编排」翻牌到位,报头细线画出;头条逐行升起(行间 90ms、每行 700ms);头条分数翻牌;页边与目录的细线画出;各节 300ms 处切入。全程 ≈ 1.2s,界面一出现就能点。
- `ai`:分数翻牌(取代里程表,≈ 450ms,十分位晚 120ms);速读各句自左向右擦出(每句 260ms、句间 60ms);卡顶细线画出。
- `toast`:提示条自中线向两侧展开(220ms),字从遮罩后升起;收藏星标「盖章」(1.5 → 1,带 2° 回正);全部标读自上而下逐行擦过。
- `theme`(签名「翻页」):新主题自上而下像滚筒一样压过整屏,压线处一条细影(≈ 560ms)。
- `scroll`:标题滚出后小标题从遮罩后升入吸顶栏;早报各节的节题细线在进入视口时画出(一次);列表吸顶日期变了就翻牌。
- `event`:名次翻牌,事件标题逐行升起,时间线上的钟点依次翻出(至多 6 个);返回硬切。
- `sub`:按钮上的字翻牌成「已订阅」,对勾画出。
