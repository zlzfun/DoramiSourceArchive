## 入口

样页是开发服务器上的独立页面,生产构建入口仍只有 `frontend/index.html`(不打包、不进 dist):

```bash
cd frontend && npm run dev
# 打开 http://localhost:5173/r2-preview.html(端口被占时以 Vite 输出为准;不需要后端)
```

页面顶部的反色条「R2 交互样页 · 数据与翻译进度均为模拟，未接入后台」常驻;右侧「演示控制」打开样页外的非模态面板。
宽度 ≤ 1024px 自动换成手机单列;宽屏可在演示控制里切「手机框」。

## 样页里能看到什么

1. **标题**:列表、阅读窗、上一篇 / 下一篇、手机页统一走 `displayTitleOf`。有有效译名时显示中文,阅读页在中文标题下保留原标题(沿用现网译文态 `.reader-pane-title-orig`);译名未就绪(Tom Rivera 那篇)、中文原题(量子位)、版本号(tinyserve v0.9.0)原样显示,无骨架、无报错、无标题翻译按钮。
2. **设置**:「设置 → 阅读 → 默认显示中文标题」,默认开;切换后列表与阅读页即时同步,刷新保持(`localStorage` 键 `dorami-r2-preview:zh-title`,不碰现网键)。桌面是设置柜(复用 `Modal closeOnOverlay`),手机是「我的 → 设置 → 阅读」页面栈,行样式同现网「减少动效」。
3. **正文 · 逐段占位(默认,已选定)**:默认原文;「原语言 | ✦ 译为中文」照旧手动。点「译为中文」后,中文视图里每个未完成片都在**原位置**显示一组骨架,形状对应这一片原文的块结构:段落按篇幅估行数,标题一行,列表带列表点和缩进,引文带左线,代码是细线框里按行长排的条,表格保留行列与边线,块级公式是居中的一条。后台并发落片,**哪一片完成就把它自己那组骨架换成中文**,后面的片可以先出现,位置和顺序都不重排:默认 3→1→2 时先出现第 3 片,其次第 1 片,最后第 2 片。
4. **正文 · 连续展示(对照,未选)**:演示控制切到「连续展示」后,中文视图只接上从第 1 片起连续完成的部分,其后一块固定 4 行的推进边界骨架;后片先完成只缓存,前面补齐时一次接上。两种方式共用同一个后台任务,随时切换,进度不重置。
5. **没有进度文字**:两种方式都没有状态行、段数或工具条进度,完成也不提示(骨架消失即完成)。唯一的进度表达是「中文」档上的小圈圈(手机是顶栏「译」钮):后台任务排队或进行中就转,不论当前看原文还是中文;完成、失败、暂停、取消即停。进行中正文里没有任何可见文字或按钮(选定时去掉了「取消翻译」)。
6. **原文随时可看**:切「原语言」= 全文原文,后台继续,新片完成不把视图抢回中文。重新打开页面(演示控制「模拟重新打开本页」)保留后台进度,正文仍按默认原文显示。
7. **失败 / 暂停**:圈圈停,已完成的片全部保留,未完成片的骨架停走(与减少动效下的静止骨架同一外观)。原因与动作整篇只出现一次(逐段占位跟在第一个未完成片下面,连续展示跟在推进边界下面)——「翻译失败 · 重试」「翻译中断 · 继续翻译」;额度用尽只写「今日 AI 翻译次数已用完，明天可继续」,不给立即重试,演示控制「模拟：次日额度恢复」后变为「翻译已暂停 · 继续翻译」。「翻译已取消 · 继续翻译」的文案保留给旧客户端遗留的取消任务,样页不再有进入它的入口。出错时不在中文视图里展开原文,要看原文切「原语言」。续译只补缺的片,已完成的片原样复用:论文一篇预置「中断暂停、第 1、3 片已完成」,逐段占位里第 1、3 片是中文、第 2 片(含公式)是静止骨架,连续展示里只显示第 1 片;点「继续翻译」后补上第 2 片。
8. **格式**:推测解码一篇含代码块、链接、表格、列表、引文;论文含行内与块级公式;都随所在片整组出现。
9. **论文 / 播客 / 社交**:论文全文、播客节目简介都是手动翻译、同一套中文视图;社交卡没有标题区,推文与引用推仍是逐卡「✦ 译为中文」,不自动展开。
10. **阅读位置**:前方骨架换成中文、后片先出现、新片接上时,读者所在的片在视口里不动,也不自动滚到新内容。视口顶部落在骨架里、而视口内已能看到真实内容时,锁住的是那段可见的真实内容(骨架没有可读内容,高度还会随停止态原因行挪进来、估行变化而变);视口内只有骨架、所在骨架完成时,按片内比例落到中文的同一位置。原文 → 中文:所在片在中文视图里存在(已译或占位)就对齐同一片;连续展示里还没显示就落到推进边界(视口约 40% 处,文末不足时停在底部)。中文 → 原文:在中文里没动过就回到离开原文时的位置,已在中文里读到某片则原文对齐同一片。切显示方式时所在片若不再显示(逐段 → 连续),同样落到推进边界。
11. **读屏与动效**:骨架对读屏隐藏,不逐块、不逐片播报;进行中只在第一个未完成片处有一句不播报、不占版面的隐藏文字。只有在这篇打开期间亲眼看着任务结束时,才由隐藏 status 区播一次「中文译文已就绪」/「翻译失败」/「今日 AI 翻译次数已用完」/「翻译已暂停」,6 秒后清空,不与可见原因行重复;打开时已结束的不补播。用键盘点「继续翻译」「重试」后,焦点交给变化后的这一行(进行中即那句隐藏文字),不丢回页首。减少动效走 `<html data-motion="reduce">`:骨架静止、新片不淡入、圈圈按全站兜底停帧。

## 演示控制

| 控件 | 作用 |
|---|---|
| 显示方式 | 逐段占位(默认,已选定)/ 连续展示(对照);只是样页对照,不是产品设置;切换不重置任务 |
| 落片节奏 自动 / 手动 | 自动 = 首片 2.4 秒、之后每 1.8 秒落下一片;手动 = 只在点「模拟：落下一片」时推进 |
| 完成顺序 | 并发 3→1→2(默认,末片先回)/ 首片最慢 2→3→1 / 顺序 1→2→3;都是并发返回的先后,不是串行请求 |
| 开始前排队 | 开始或继续时先排队 1.5 秒 |
| 后台各片 | 只在演示控制可见:每片「可显示 / 已缓存，待接上(仅连续展示)/ 未完成」与后台任务状态;产品界面刻意不显示这些 |
| 模拟：下一片失败 / 额度用尽 / 次日额度恢复 | 外部条件;额度用尽后产品不给继续,「次日额度恢复」才出现「继续翻译」 |
| 重置本篇任务 | 本篇任务回到初始(论文回到预置的中断暂停),并退出中文视图 |
| 本篇译名 已就绪 / 未就绪 | 模拟下一次获取列表 / 详情时标题译名的有无 |
| 版式 / 主题 / 减少动效 | 桌面 ⇄ 手机框;亮 / 暗 / 跟随系统(样页独立键);只改本页 `data-motion` |
| 模拟重新打开本页 / 重置演示 | 前者保留后台进度、正文回到原文;后者任务与阅读状态回到初始(显示方式、主题等观看选项不变) |

## R2 新增的产品样式(都在 `r2-preview.css` 第 ③ 段)

- `.r2-slot` 与 `.r2-slot-line` / `.r2-slot-dot` / `.r2-slot-pre` / `.r2-slot-math` / `.r2-slot-image`:逐段占位。块元素沿用 p / h2 / h3 / ul / blockquote / pre / table,外边距、行高、缩进、表格边线由现网 `.markdown-body` 规则给出;每行占一个正文行高(`1lh`,不支持时回退 `1.85em`),条高 0.8em,条用现网 `.skeleton`。代码块把 pre 的浅底换成细线框,因为浅底上的骨架条看不清。
- `.r2-frontier` / `.r2-frontier-foot`:连续展示的推进边界(`.skeleton` + `h-4` + `mt-3` 固定 4 行,同 `PaneBodySkeleton`)与两种方式共用的停止态原因行;整块骨架都套 `.skeleton-delay`(150 毫秒内完成不闪)。
- `.r2-slot.is-stopped .skeleton`、`.r2-frontier.is-stopped .skeleton`:失败 / 暂停 / 取消时骨架停走,亮色用 `--dorami-soft` 静止底,与减少动效下的现网骨架一致;骨架本身几何不变,停止时只在第一个未完成片下多出那一行原因。
- `.r2-seg-body.is-fresh`:新出现的片一次 `--motion-slow` 淡入,`data-motion="reduce"` 下直接出现。
- 片多包了两层,首片首块上边距按现网 `.markdown-body > :first-child` 归零。

## 模拟与未做的边界(样页)

- 落片、失败、暂停、额度、排队、标题译名就绪都由本地状态机与「演示控制」驱动,样页本身不接任何接口。
- **片 ≠ 段落,块映射是样页做法**:样页 fixture 的片界都在完整顶层块之间,所以「一片 = 若干完整块」。真实接口片约 3,500 字符、可能切在段落中间;生产改由服务端预览直接给「完整 Markdown 块」(见下),前端不把接口片当段落。
- 骨架尺寸是估算:段落按原文字符数乘以每字约 0.5em、再除以实测栏宽估行数;代码按行长(`ch`),表格按单元格字数,公式按源码长度。不读译文,也不追求像素级预测,换成中文后高度会有差异,由阅读锚点吸收。
- 连续展示的严格单一边界:第 1 片反复失败而后片已完成时,中文视图不破例展示后片(对照模式,未选)。
- 阅读锚点是样页内的最小实现,样页为它关掉了浏览器原生滚动锚定(样页无图片);生产保留原生锚定(见下)。
- 没有接口的入口一律不画:早报、榜单、发现、分享、问哆啦美、收听入口 / 播放条、播客逐字稿面板、文章搜索、移动端源抽屉与长按动作单;示例数据不带原文链接,所以没有「查看原文」。
- 示例来源只用本地已有品牌图标(`public/source-logos`)或字母徽标;人物与内容均为虚构,数字仅作示意。
- 样页外壳的说明条与演示控制刻意用反色,与产品界面区分;它们不是产品设计的一部分。
