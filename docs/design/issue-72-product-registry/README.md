## 定稿:泳道 + 右侧抽屉

一行一个流程,列头是 取材 → 加工 → 产出 | 定时 | 生成。行高固定 64,每一格的内容都以行的中线为准(控件压在中线上,两行的文字块跨在两侧,只有一句的就只有一句)。行上能直接动的只有开关和立即生成;cron 在行上只读。点一行从右侧打开这个流程的抽屉:一个「配置」框(取材、定时、旋钮、游标,一行一个参数,输入框同宽、字居中;保存)和一个「往期」框;题条里另有一个立即生成。抽屉是现网的 `.ledger-scrim` / `.ledger-drawer`,宽度也是现网的 470。比较过的:加宽到 640、配置两列(`details/config.html`);另外两种容器弹窗、独立页(`r5/`)。各列最小宽度之和 1106px,放得进 1280 窗口。要落地的新类是 `.gf-*`(`assets/lane.css` 上半)与共用的几个 `.pf-*` 小块(`assets/proto.css`)。

为什么不在原地展开(第四轮,`r4/`):细节必须挤在各自那一列下面,第一列下面永远是空的;行一变高别的行被推走,内容超高时滚动条出现还会把各列挤窄。

## 第三轮的六个方向(存档)

| | 这一页的主角 | 往期 | 配置 |
|---|---|---|---|
| **C1 往期收起** | 所选流程的三段(第二轮的 B2) | 折叠的列表;平时显示最新一期的内容 | 常驻 |
| **C2 泳道** | 全部流程,一行一个;列头是 取材 → 加工 → 产出 | 点开一行才有 | 点开一行 |
| **C3 台账** | 全部流程的逐日结果(一格一天)+ 选中的那一期 | 日期格子,不再有列表 | 右侧配置栏,点了才出来 |
| **G1 刊席**(Gemini) | 每个流程最新一期的成稿,一个流程一栏 | 每栏 ‹ 日期 › 翻期;目录点了才拉下来 | 这一栏原地翻成表单 |
| **G2 时序**(Gemini) | 今天的 24 小时:此刻以上是已跑的,以下是待跑的 | 近 7 日的日期胶囊;全部归档点了才拉下来 | 待跑那一行下面展开 |
| **G3 机匣**(Gemini) | 每个流程一只小匣 | 两个流程合成一条「近期产出」,平时只露最近三期 | 匣子向下伸 |

## 做法

1. **底稿是现网**。在隔离栈(主干 b4836bac,开发库副本)里用 Playwright 依次打开「AI 日报」「任务与运行」「源管理 · 系统」,抓整页 DOM 与 `document.styleSheets` 导出的样式。`app.html?dir=now` 时除了导轨能点,什么都不改。
2. **新增部分沿用现有形制**。往期行、取材口径、分页是现网节点;名册左栏是 `.timetable`,表格是 `.flow-table` + `.run-row`,参数行是 `.inspector-param`,阶段条是 `.ledger-pipeline`,结果记号是 `.tt-last` / `.tt-dots`。新起的类:`.pf-*`(第二轮)、`.lane-*`(泳道)、`.pm-*`(台账)、`.gx-*`(Gemini)。起名前查过与现网不撞(`.pl-*` 撞了同步页的类,所以泳道没有用它)。
3. **数据**。日报的逐期是开发库副本里的真实记录;自定名单里的来源名与篇数取自副本库里篇数最多的公共源(勾选是示意;现网每行末尾还写默认类型,泳道那一列窄,只留了篇数);副本的数据停在 2026-07 到 09 月,抓之前把运行记录、源状态、日报与榜单的日期平移到了今天附近,样页里的「今天」是 2026-11-26。精读这个流程还不存在:期数、每天的结果、入库时间是示意,每一期的内容只列仓库名和灰色占位,没有代写正文。精读「跳过」的原因写的是「没有新榜单」:日榜条目按 UTC 日期记(北京时间早上采到的是前一天那条),所以精读取最新一条还没写过精读的日榜,不按日期对。
4. **抓底页时改写了两处接口响应**:模型状态改成已配置、日报开关改成开启。副本库为了不产生付费调用,删了模型与 X 的密钥、关了分析与自动翻译、关了日报定时。
5. **Gemini 的三个方向怎么来的**。用本机 Antigravity 的 `agentapi new-conversation --model=gemini-4-carbon-high` 新开会话。第一次让它自己读任务书、写文件(`gemini/BRIEF.md`),会话没有工作区,读文件那一步停在 Antigravity 界面里等授权,没有走通。第二次把全部上下文写进一条提示词(`gemini/BRIEF-inline.md`):背景、用户原话、要放得下的东西、审美要求、现网的变量与组件、底页脚本的用法,要求不调用任何工具、按 `=== FILE: 名字 ===` 分段在回复里交付,并请它避开 Claude 在做的三个想法。它用了 41 分钟(输出约 7.5 万 token),给出 `g.css`(23KB)、`g.js`(63KB)和 `NOTES.md`。我按标记切分落盘,**没有改它的代码**;`g1–g3.html` 三个页面壳与 `assets/shell.js` 是我备的。落盘前查过它的脚本没有网络请求、样式没有十六进制颜色、字号都在现有刻度里。
6. **自查**(2026-11-27):`tools/shots.py` 的 91 个状态(现网;第二轮回归 4 个;C1 8 个;第四轮泳道 15 个;定稿 17 个——泳道 6 个、抽屉 11 个,含生成中、失败与跳过、新流程、自定名单、暗色、1280 宽、640 高,以及比较用的 640 · 两列;复杂流程的演示 7 个;第五轮存档里的三种容器 8 个;台账 9 个;Gemini 三个方向各 5 个;总览、三份存档、三张细节页)零控制台报错、零失败请求、无横向溢出(泳道的滚动容器另查了只竖着滚)、纸不超出视口、浮层不伸出视口;另外实测了泳道每一格内容的中心相对行中线的偏差(六格同为 0.5px);Gemini 各方向的 `?view=` 状态另外逐个打开看过。总览页里引用的尺寸是实测的。
