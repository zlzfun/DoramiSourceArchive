2 · 三个方向

从六种里挑出三个各自成立的搭配。每个方向左边选中日报,右边选中精读。

B1 · 左栏名册 + 两栏

与「任务与运行」同一副骨架:名册在左,一行三层(名称与上次结果、期数与 cron、近 7 日与距下次)。

B2 · 顶部磁贴 + 三段

名册横过来放在纸的顶上,选中的那块底边一道;下面整幅宽度按 取材 → 加工 → 产出 排。阶段条平时就在「加工」里,生成时它就是进度。

B3 · 顶部表格 + 两栏

流程一行一个。定时列里直接改 cron、拨开关,生成列里点生成,所以下面没有题条;选中一行,下面是它的配置与产出。

6 · 样页的边界

日报的历史行、cron 与各项取值来自开发库副本,日期平移到了今天;每一期的生成时刻、精读这个流程的全部数字是示意。

原型里能点的是:导轨上的三个页签、名册里的两个流程、产出源 id 与取材的源名(去源管理)。开关、cron、保存、立即生成都不会改动任何数据;历史行不能展开。

没有画的:读者面、新流程第一次打开时的空态、日报「自定名单」展开后的样子(现网是一组可增删的源)、手机壳(管理面不在手机壳里)。
