我的看法

把详情挪出去是合适的。上一稿的三处问题里,左下角空白和漂移是原地展开这个结构带来的:细节必须挤在各自那一列下面,行一变高别的东西就被推动。挪出去之后泳道只做两件事——看状态、两个即时操作——这些问题不用一处处补。它还顺带消掉两个待定项:cron 不必在行上单独存(进配置,随「保存配置」提交,与现网相同);自定名单的行不用为了窄列删掉默认类型。

代价有一个:原地展开时,取材、旋钮、往期各自落在同名的列头下面,列头与细节是对得上的。挪出去之后这层对应没有了,详情里是「配置」「往期」两个框。

三种里我建议右侧抽屉:

  1. 管理面里「表格点一行」已经都是抽屉,不引入新的习惯。
  2. 泳道还在眼前,关掉就回到原处,不多一层导航。
  3. 弹窗更宽,但把整页盖住;现网的弹窗都是填一次就走的表单,这里要翻往期、读正文,停留的时间长。
  4. 独立页最宽,但管理面目前没有下钻页:要加返回,地址多一段,题条里还要把开关和生成再放一份。

抽屉的短处是窄。现网日报页的往期一栏在 1440 窗口下有 1027 宽,点开一期读正文很舒服;470 的抽屉里一行只有 404。如果你常在这一页读正文,要么把这只抽屉加宽到 640(现网没有先例,上面第四个画框),要么选独立页。日报本身也是阅读器里的一个源,在那里读是完整的版式。

4 · 每样东西怎么生效

东西在哪怎么生效与现网

立即生成行末;详情的题条里也有一个点了就跑;进度在行上「加工」一格的阶段条上,详情开着时也出现在往期的顶上现网的阶段条只在生成时出现;这里行上平时就是各阶段的名字,生成时逐段点亮

6 · 样页的边界

底页是隔离栈里抓的现网 DOM 与样式(主干 b4836bac,早于推送绑定 #350 合入;导轨与页头此后没有变)。抽屉、弹窗的外壳用的是现网的类(.ledger-scrim / .ledger-drawer、.modal-overlay / .modal-panel);详情里的两个框用的是 #350 加的 .acq-panel,底页的样式导出早于它,那几条规则是照主干抄进样页的。

日报的逐期(日期、生成时刻、条数、模型)是开发库副本里的真实记录,日期平移到了今天;样页里的「今天」是 2026-11-26。自定名单里的来源名、篇数、默认类型取自副本库里篇数最多的公共源,勾选是示意。精读这个流程还不存在:期数、每天的结果、入库时间都是示意。

能点的是:点一行打开详情,关闭(关闭钮、遮罩、Esc、返回)。开关、保存、立即生成、重置、删除都不会改动任何数据;往期的一行在样页里点不开(现网点开是那一期的正文)。抽屉、弹窗进出的动效没有做。

没有画的:读者面(发现页里多出来的这一个源,形制与日报那个相同);源管理里那两行改成「生成」的样子;往期的一行展开后正文在抽屉里的样子;手机壳(管理面不在手机壳里)。
