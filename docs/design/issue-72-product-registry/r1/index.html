3 · 管理面:三个方向

三个方向对「流程是什么」的回答不一样:A、B 把它当成一个有自己页面的东西;C 把它当成源的一种获取方式(与抓取、推送并列),再加任务名册里的一行。

A · 一物一卡B · 名册C · 并入源与任务
流程是什么一张卡名册里的一行源的获取方式「生成」+ 任务名册里的一行
在哪管「AI 产出」一页,全部摊开「AI 产出」一页,一次看一个没有专页。定时与运行在「任务与运行」,旋钮在「源管理」的检视器

日报原有的东西原样留在卡里:历史、展开读正文、删除、取材口径、自定名单。开关、cron、立即生成三样挪进题条旋钮进检视器(345px 宽);历史、读正文、删除改去「知识台账」(现在台账不列日报,要放开);取材口径没有位置

5 · 样页的边界

日报的历史行是开发库副本里的真实记录,日期平移到了今天;精读这个流程还不存在,它的期数、近 7 日、运行行都是示意。模型状态与日报开关在抓底页时改成了「已配置」「开启」——副本库为了不产生付费调用,把密钥删了、定时关了。

原型里能点的是:导轨上的三个页签、方向 B 名册里的两行、方向 C 源管理的两行与任务名册的两行。开关、cron、保存、立即生成都不会改动任何数据。

没有画的:读者面(发现页与阅读窗里多出来的这个源)、「知识台账」在方向 C 下放开日报之后的样子、新流程第一次打开时的空态、手机壳(管理面不在手机壳里)。
