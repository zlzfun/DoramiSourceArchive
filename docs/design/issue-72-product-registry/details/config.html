我当时建议 640 · 两列;定的是 470 · 一列。当时的理由:空旷是「一行一个参数」放进宽抽屉造成的,排成两列之后每格的宽度与源管理检视器里的参数行差不多;配置框矮了三成,往期不用滚动就能看全一页;往期一行仍有 574 宽。回到 470 的好处是不新开宽度,代价是往期的一行只有 404,自定名单开着时往期只露两期。

2 · 输入框

数字停在偏右的地方,是因为现网参数输入框的类是右对齐的,而数字框右边还留着浏览器自带的增减钮的位置。现在:输入框同宽(112),字居中,数字框去掉增减钮。cron 也是同一副框。

参数的顺序是 取材 → 定时 → 旋钮 → 增量游标。日报的「取材」下面可能带名单,所以它总是占整行——切到自定名单时别的格子不会换位置。
