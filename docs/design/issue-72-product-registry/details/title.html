细节:这一页叫什么、管什么

方向定了 C2 泳道。两个问题连在一起:外部 Agent 推来的内容不在这一页,所以「AI 产出」这个名字就偏大了。

2026-11-27 定了:页面叫「生成流程」,导轨短名「生成」。下面是当时并排的六个叫法。

回总览

1 · 这一页管什么

内容进平台有三条路,按「谁在跑」分;三条路在源管理里是同一格「获取方式」。

获取方式谁在跑平台管得到什么在哪管
抓取平台的抓取器参数、定时、每次运行的结果源管理;任务与运行
推送别处的 Agent、bot(不在本服务里)来源(登记、列入 / 下架、读者可见、分析开关)与令牌(绑定、日额度、吊销)。它几点跑、怎么写的、失败没有,平台看不到,只知道最近一批什么时候到源管理 · 登记来源;运维 · 收录令牌
生成平台自己的流程取材、旋钮、定时、开关、立即生成、进度、每一期这一页

所以外部 Agent 自己写了文章再提交,走收录推送就行,不进这一页:这一页上的每一列(取材、加工、定时、生成)对它都是空的。现在的推送接口有两处是照着「转来别处已有的内容」做的,Agent 自己写的内容用起来要知道:

现在的行为对 Agent 自己写的内容意味着什么
要链接kind=article 没有 url 就拒收(「文章需要链接」);条目身份也按链接算Agent 得给每一篇一个稳定的地址(自己托管,或约定一个固定格式的地址)
当普通文章入库即 web_article:照常评分,可以进榜单;列入后可以进公共日报候选;被订阅后可以进个人早报如果推来的是对站内已有内容的二次加工(汇编、点评),会回流成素材。现在能挡的只有来源上的两个开关:关掉本机分析(没有分数,日报、早报、榜单都进不了),或者不列入(只挡公共日报候选与发现页)

2 · 这一页叫什么

每个画框是泳道页的左上角:导轨(短名平时不显示,鼠标移上导轨才出来,这里让它一直显示)、页面标题、第一列的列头。

叫法导轨短名字面上排除了推来的内容吗与现有叫法别的
AI 产出产出没有。外部 Agent 推来的也是 AI 的产出沿着原来的「AI 日报」;别的页签都不带「AI」「产出」又是泳道第四列的列头
生成流程生成排除了。生成是平台自己的动作对得上源管理的获取方式(抓取 / 推送 / 生成)、行上的「立即生成」、往期的「已生成」;页面里列的就是流程平实,不出彩
定时生成生成排除了同上也能手动生成;开关关了就不定时,名字说窄了
自产内容自产排除了。与抓来的、推来的相对,意思最准没有先例偏口语
栏目栏目看不出来与「期」「往期」成一套,读起来像刊物同一个东西在读者那边叫源、在这里叫栏目,多一个概念;也看不出是平台生成的
哆啦美出品出品排除了源目录里这些源的出品方本来就写着 dorami品牌口吻;别的页签都是直白的名词

定的是「生成流程」,导轨短名「生成」,第一列的列头「流程」不变。这样源管理里这些源的获取方式也顺着写「生成」(总览页 §5 第 6 项,还没定)。
