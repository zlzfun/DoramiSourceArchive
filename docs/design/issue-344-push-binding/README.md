## 做法

1. **底稿是现网**。在隔离栈(主干 46cc0c5d,空库,自带 `admin/admin`)里签发三个收录令牌、用现有的推送接口推几条虚构账号的帖子与一篇文章,再用 Playwright 抓「运维 → 自定源与收录」与「源管理 · 社交」的 DOM,以及 `document.styleSheets` 导出的样式。原型里没改过的地方就是现网本身。
2. **新增部分沿用现有形制**。令牌表的列与行(`.acct-table`)、抽屉外壳(节点同步页的 `SyncDrawerShell` 标记)、检视器的分节(`.inspector-section` + `.micro-label`)、行上的徽标(`.tier-pill`)、开关(`.ledger-switch`)、分段选择(`.segmented-control`)都照现网标记写。新起名字的只有获取方式的静默态(`.acq-none`)与抓取器名(`.acq-fetcher`)、绑定清单(`.bind-list` / `.bind-row` / `.bind-add`)、令牌表的来源格(`.tok-sources`)和登记表单的排布(`.reg-*`)。
3. **数据是示意**。三个令牌与四个收录源是播种出来的虚构账号;「Grok 推荐」这一行、各处的「最近一批」时间与累计条数由 `proto.js` 写上去。
4. **自查**(2026-11-25):`tools/shots.py` 的 15 个状态(令牌表 现网 / 样页 / 抽屉 / 含自助登记 / 暗色,源管理 现网 / 样页 / 暗色 / 又抓又推,登记来源四种,带开关条,总览页)零控制台报错、零失败请求;截图逐张看过。

## 样页里定的做法

- **收录令牌**:表里加「来源」列(名称一行排开,排不下省略;没有绑定显示「–」);点一行开抽屉,列出这个令牌的来源(名称、源 id、最近一批、解绑),下面一行加来源。
- **源管理**(第二轮):每一行写明获取方式——原来写内容形态的那一格(与页签重复)改成「抓取 / 推送 / 抓取 · 推送」,两样都没有的写「无抓取」;名字后面的「无采集」徽标拿掉。只推送的源最后一列显示最近一批推送的时间与累计条数。检视器按同样的两样分成两个框(第三轮):「抓取」框(原「运行参数」区,题条右侧写抓取器;框里是参数、运行动作,「近期运行」是框内小节、标题降一档)与「推送」框(在推它的令牌:调用方、令牌尾号、最近一批、解绑,下面一行加令牌);「源审查」在框外,标题与两个框同级。「没有采集绑定」改成「没有抓取器」;运行、试抓、采集任务这些动作的叫法不动。
- **登记来源**:源管理页头的按钮,开抽屉。类型(推文 / 文章 / 播客)、出处(一个账号或站点 / 不限)、名称、账号或站点或源 id、头像、令牌、进发现页。
- **读者面**:转推卡片顶上那一行取转推者本人的名字。

逐项的结论见总览页 §5。
