# 方向 D · 透镜(Lens)

## 1. 一句话概念

满屏失焦的产品能力短句排成一页细密的「印刷品」,一枚液态玻璃透镜悬在纸面上,把底下的字折射、放大、对上焦——**替你看清**。
透镜 = 哆啦美右眼那枚全息目镜 = 产品里的 AI:信息很多,它替你读完,把重点放到眼前。整页不需要任何数据就把产品价值讲完。

## 2. 视觉系统

- **底**:珍珠灰 `#eceef1`(阅读器「瓷」中性色 `#f4f6f9` 同族、压暗半档);着色器里叠三团极淡的珠母虹彩(左上暖粉 / 右下薄荷 / 表单侧淡紫)+ 设备像素级颗粒防色带。
- **墨**:`#161922`(= `--dorami-ink`);次要 `#555a64`(珍珠底 6.2:1);占位 `#686c76`(白底 5.3:1);错误 `#b42330`(5.6:1)。
- **品牌靛只点睛三处**:登录按钮 `#5252c5`、焦点环、题词里「看清」二字 `#4745b3`;文字场的荧光记号 = 靛 15% 底 + `#4745b3` 字。
- **透镜边缘**的色散与轮廓色偏蓝→紫,借阅读器「见渐变即 AI」身份色 `#3f7bf6 → #8b52f4`;透镜停在彩蛋上时换成哆啦美目镜的紫 / 青全息色。
- **字体**:Dorami Serif **只用 600 一档**(题词、文字场标题、「欢迎回来」、角标——去掉 900 省一半字体流量,也更贴珍珠 / 玻璃的克制);Dorami Latin Serif 400 斜体(英文短句);系统黑体 400 / 600(细字、表单)。
- **版式**:左题词「信息如潮，/ 替你看清。」+ 斜体副题;右表单(静止时没有卡片,直接排在纸面上);中间空地是透镜的家。文字场是 5–8 栏瀑布流:卡片(衬线标题 + 斜体英文 + 两端对齐细字)/ 点线目录 / 斜体引语 / 段落 / 极淡水印大字,中西文间距、标点悬挂、撑开过大时齐左。
- **吉祥物**:角标用原图做 App 图标;密码聚焦时换捂眼图(保留品牌记忆);文字场里藏一枚「钞票凹版」线刻小像(见 §6)——模糊时只是一团淡灰椭圆,透镜扫过才看清是哆啦美,旁边细字「你找到我了」+ 今天的真实日期。

## 3. 动效分镜

**开场**(全档;ms 自字体就绪起;任意点击 / 按键跳过,`LoginSample.replay()` 重播)

| ms | 事件 |
|---|---|
| 0–1100 | 文字场从重度失焦(8px 档)显影到常态失焦(3.5px 档) |
| 380 | 一滴玻璃在题词「看清」上凝结:半径弹簧 0→R,带回弹;边缘色散此时最强 |
| 640–1500 | 透镜里的字对上焦(focus pull);700 起透镜边读边慢漂 |
| 900–1950 | 题词淡入;1650 起角标 / 表单 / 时间行逐个「对焦」入场(淡入 + 上浮 10px + 模糊 7→0,错峰 70ms) |
| 2050 | 桌面:透镜滑到题词与表单之间,吸附到最近一个荧光词(1440 下正好是「哆啦美替你看清」);手机:沉到表单身后变成玻璃板 |
| 3400 | 开场结束,交给指针 |

**常驻**:静止时不渲染(实测静置 3 s 的 rAF 调用为 0)。7 s 无操作开始「巡读」:透镜依次滑到荧光词 / 彩蛋各停 5 s,只在滑动时出帧。

**交互**
- 指针:透镜弹簧跟随(k170 / ζ0.7);速度 → 果冻形变(沿速度拉长、垂直压扁、等面积,ζ0.3 让它停下时晃两下);高光随指针相对位置偏转。
- 靠近表单(进 12px / 出 40px 迟滞)或聚焦:透镜**磁吸**到表单身后,圆 → 圆角板约 400 ms 液态形变;板是平板玻璃不再聚焦,只在圆角斜面折射字场,表单像嵌在玻璃里。
- 输入:每敲一个字,玻璃轻颤一下。
- **密码隐私动作**:玻璃「起雾」——自下而上、噪声边缘的雾化 0.45 s,雾面上一颗颗细小水珠(各自清出一个小洞、左上一点高光);角标同时换捂眼图;离开时 0.75 s 散雾。
- 错误:玻璃与表单一起果冻抖动(11px · 5.4 Hz · 约 1 s 衰减),边缘泛暖红后留一层淡余辉;错误槽固定 20px。
- 登录中:玻璃里焦散光流转(扭曲正弦网 + 每 1.6 s 一条斜向光带,带蓝→紫 AI 色),按钮「登录中」+ 小圈。
- 成功(约 1.4 s):表单失焦淡出 → 玻璃收成圆 → 圆以 ease-in 极速放大吞没全屏,里面的字放大到 2.5× 像穿过透镜 → 白化到阅读器底色 `#f4f6f9`,角落「样页到此 · 实际会进入阅读器」。

## 4. 减弱档与手机

- **减弱档**:同一构图的静止完成态——透镜静止在「哆啦美替你看清」上;聚焦时玻璃板瞬时就位;起雾 0.14 s 淡入;错误 = 静止暖红边 + 文案(不抖);登录中 = 焦散光定格;成功 = 0.45 s 交叉淡到阅读器底色。无开场、无巡读、不跟随指针。
- **手机**:无悬停 → 透镜默认吸附在表单身后当玻璃板;开场仍先在「看清」上凝结读一遍再沉下去;点按文字场可把透镜叫过去看一眼,3.6 s 后自己回去;Android 陀螺仪让高光与板轻微偏转(iOS 要权限弹窗,不做);自走 30 fps 上限;键盘弹起只改高度时不重排文字场。手机上题词与表单占满屏,**没有彩蛋**。

## 5. 技术实现与代价

- **文字场 / 题词**:Canvas 2D 自排版(中西混排、两端对齐、标点悬挂);清晰版按 DPR × 放大率渲染(总像素 ≤ 9M,并按 `MAX_TEXTURE_SIZE` 截断)上传为纹理;半分辨率版 GPU 两遍高斯得 3.5px 档,再降四分之一得 8px 档,按屏幕位置混合两档成景深。题词画进画布,透镜才能折射它(DOM 里留视觉隐藏的 `h1`)。
- **透镜**:一个全屏片元着色器——圆角矩形 SDF(圆与板同一公式)、等面积果冻矩阵、中心放大 + 斜面法线折射、色散只挂在斜面弯折上(∝ rim³)、菲涅尔 / 窄高光 / 左上 softbox 反光 / 上沿亮线与下沿出光、投影 + 焦散斑;起雾、水珠、焦散光、错误余辉、成功白化同在一个 shader。按需渲染:只在动时跑 rAF,`document.hidden` 停。透镜内墨色 ×1.32,「看清」的反差更足。
- **降级**:拿不到硬件 WebGL(`failIfMajorPerformanceCaveat`)→ DOM 透镜:圆角裁切 + 放大的清晰副本 + CSS 玻璃边,同一套弹簧(无斜面折射、无果冻);`?gl=0` 或控制条「降级预览」可看。
- **体量**:`lens.js` 72 KB(gzip 25 KB)+ `index.html` 14 KB;新增素材 `assets/dorami-engraving.png` 61 KB;字体不新增,首访加载 Dorami Serif 600 的 11 个分片 + Latin 斜体 ≈ 540 KB(与阅读器共享缓存);无第三方库;显存约 45 MB(1440×900 @2x)。
- **落 React**:约 2–3 人日。`<LensStage>`(排版引擎 + WebGL 渲染器,排版为纯函数可单测)+ 表单把 rect / 聚焦 / 状态经回调交给它。风险:Canvas 排版必须等 `document.fonts.load`;iOS 低电量模式 rAF 降频;少数 GPU 走降级路径。
- 样页附加按钮:「找彩蛋」(透镜直接滑到线刻小像)、「降级预览」。

## 7. Windows 理论确认

- Chrome / Edge 的 WebGL 走 ANGLE → D3D11:着色器只用 GLSL ES 1.0 + `highp`、无扩展、单 pass;纹理尺寸受控;关了硬件加速时 `failIfMajorPerformanceCaveat` 直接转 DOM 降级。
- 分数 DPR(1.25 / 1.5 / 1.75):画布 backing = round(CSS × DPR),颗粒按设备像素取整,文字纹理按 DPR × 放大率渲染,误差 < 0.5px。
- 字体:Dorami Serif / Latin 自托管 woff2;画布细字走系统黑体栈,Windows 落 Segoe UI Variable / 微软雅黑 UI,不会落到没有粗体的中易宋体。Canvas 不用 `letterSpacing`(手工字距),`roundRect` 有兜底,正则用 `\p{Script=Han}`(Chromium / Firefox 均支持)。
- 合成:DOM 只动 opacity / transform / `filter: blur`(开场 7 个元素各一次),不用 backdrop-filter。

## 8. 已知不足 / 待拍板

1. **题词画在画布里**(为了让透镜折射它)。可改为「题词放 DOM、透镜只折射文字场」:更好维护,但少了透镜扫过「看清」的那一下。
2. **玻璃板静帧像「玻璃卡片」**:它只在交互时出现、由透镜形变而来、边缘真折射;若仍嫌接近现行玻璃卡,可改为「透镜只吸附到当前输入框身后」的小板。
3. **字体首访 540 KB**:若文字场标题改用系统黑体、只给题词 / 标题用 Dorami Serif,可降到约 200 KB,代价是透镜下少了宋体印刷感。
4. **巡读**(7 s 无操作后透镜自己去读荧光词)要不要保留、间隔多久。
5. **边缘彩边强度**是口味问题,当前取「看得出、不炫」。
6. 手机没有彩蛋;无 WebGL 的降级路径没有斜面折射与果冻。
