# E · 天色(Sky)— 样页说明

## 1. 一句话概念

**「每一次登录,天色都不一样。」** 登录页是一扇看向读者此刻天空的窗:用客户端本地时间算出太阳 / 月亮的位置、真实月相与天色,问候语随之而变;开场是约 3.4 秒的延时摄影,天色从前一个时段流到此刻。

为什么适合哆啦美:核心产品是「早报 / 日报」这种与时间绑定的阅读。登录页每天第一眼就把「此刻」交给读者,副句顺带点出该时段适合的能力(早报 · 播客 · 长文 · 日报 · 问答)。画面上的一切都来自本地时间 / 日期 / 时区,没有任何未登录可读的数据。

## 2. 视觉系统

- **构图**:一条地平线把画面分成「天」与「海」——天是画面(问候、日月、云、星),海是页面(表单、脚注)。桌面地平线在 `min(70vh, 100vh − 236px)`,问候压在左下、日月弧线在右侧 0.36–0.97 宽之间,不和题字打架;手机地平线 52svh,问候在天顶区、日月在中段、表单在海面。取法 Sugimoto《海景》式的极简地平线,再加一层电影海报式的题字。
- **天色**:按太阳高度角插值的两套关键帧(上午 = 拂晓玫瑰金,傍晚 = 黄昏紫橙),每帧 7 色:天顶 / 中段 / 地平 / 日侧辉光 / 海 / 云亮面 / 云暗面。代表值(地平 · 中段 · 天顶):
  拂晓 `#ffd2bc · #a0a2c8 · #3e5e9c`;正午 `#dbebf7 · #94c2ea · #5893d4`;黄昏 `#ffaa6c · #9c76a8 · #355290`;深夜 `#141a48 · #080c2c · #04061c`。日落前后(+3° ~ −10°)对侧加「维纳斯带」粉带与地影。
- **与品牌靛**:「天色是变量,墨靛是常量」——登录按钮恒为 `#6f6bd7 → #5252c5` 渐变、焦点环 `#bdb9ff`;深夜天顶就是品牌靛的极暗端。整页唯一不随时间变的颜色是靛。
- **墨色自动选**:问候区的深 / 浅墨由 JS 在文字块上取 12 个天色样本,比较两种墨的最差对比度后二选一(深墨 = `#0a1122` 混 16% 天顶色,浅墨 `#f7f3ea`,不做中间灰);对比不足时 shader 在文字块背后做一块看不出形状的减淡 / 加深(dodge & burn),再叠柔光 text-shadow。顶栏同理。海面上的 UI 恒为浅墨 `#f5f1e8`。
- **字体**:问候 Dorami Serif 900(桌面 `clamp(66px, 8.1vw, 150px)`,手机 46–58px);副句、品牌字、日历行 Dorami Serif 600;英文眉题 Dorami Latin Serif 400 斜体;表单与脚注系统黑体 12–16px。无新增字体。
- **右上「日历」**:时段名 + 时刻、中文日期 + 星期、农历(浏览器 `Intl` 的 chinese 历法)+ 月相名——全是本地计算的真实值。右下是本地时区名。
- **吉祥物**:① 副句末尾一枚 28px「印章」(题字 + 落款),密码聚焦时换成捂眼图;② 夜里天上藏一颗 7×7 像素星(取 logo 里的青 / 紫星点色),随星野转动。都不抢天色的戏。
- **胶片颗粒**:一次生成的 160px 噪点贴图,overlay 7.5%,CSS `steps()` 约 9fps 抖动(只在 UI 之下、天空之上)。

## 3. 动效分镜

**开场**(完整档;任意点击 / 按键约 0.5s 收束到落幅,忽略控制条;`LoginSample.replay()` 重播)

| ms | 发生 |
|---|---|
| 0 | 模拟时钟 = 此刻 − 3.5h;黑场 1s 淡出。右上时钟从一开始就可见,作延时摄影的走字时间码 |
| 0–3400 | easeInOutSine 延时摄影:日 / 月沿各自弧线移动(月龄、月出月落按本地日期算),天色关键帧流转,星星随太阳高度淡入淡出并绕南天极转,云速 = 基础风速 + 模拟时间流速 × 5.5,云团同时变形 |
| 650 / 950 | 品牌字与时段名 / 日期行显影(上移 10px + 模糊 4px → 清晰) |
| 1500 | 英文眉题显影 |
| 1720 | 问候大字逐字显影:opacity + 模糊 20px→0 + 缩放 1.05→1,错峰 170ms、单字约 2s——像暗房里的相纸 |
| 2550–3450 | 副句 → 账号 / 密码 / 登录依次浮起(2750 / 2850 / 2950)→ 3350 印章盖下(1.4→1 回弹)→ 3450 脚注 |

**常驻环境**:云层漂移并缓慢变形,海面波纹与日 / 月光路闪烁,星星微闪;指针带来极轻视差(云层按深度、日月星 ±5px、题字反向 ±6px)。空闲 24fps(胶片帧率),60s 无操作降到 12fps,`document.hidden` 停帧。

**交互反馈**
- 聚焦:输入框底线变亮 + 一圈靛色微光,标签提亮。
- **密码隐私**:聚焦 → 一团低云从上风处(左)飘来停在日 / 月前(约 1.2s),只透出一团漫射的光与银边,海面光路随之熄灭;印章换成捂眼图。失焦 → 云团顺风继续飘走(约 1.2s)。日月都不在天上时,云团停在星空里。
- 错误:曝光 1→0.84→0.92「天色微暗」,一片云影 1.9s 自左向右掠过海面;文案进固定 20px 的错误槽(`aria-live`),一输入就恢复。
- 登录中:云流 0.45s 内加速到 8 倍;按钮「登录中」+ 小轨道转点(宽度不变),输入只读。
- **成功 · 白天**:UI 0.6s 淡出下沉 → 日光晕 1.75s 内铺满画面成暖白 → 1.55s 起淡到阅读器亮色底 `#f4f6f9` → 2.65s 角落小字「样页到此 · 实际会进入阅读器」。
- **成功 · 夜里**:云散 → 星野拖成同心星轨(2.3s 长曝光),月光晕开、画面压暗 → 2.05s 起淡到阅读器暗色底 `#0d0f13` → 2.95s 角落小字。

## 4. 减弱档与手机

- **减弱档**:没有黑场与延时摄影,直接是此刻的完成态;天空只在状态变化时重绘一帧(实测空闲 0 帧),颗粒与像素星静止;密码聚焦直接切到「云已遮住日 / 月」的那一帧,错误只微暗不掠影,成功直接淡到底色。完整档的落幅就是这一帧,所以完成度一致。
- **手机**:竖屏,地平线 52svh;问候在天顶区(墨色同样自动选),日月弧压在问候与地平线之间;表单单列、按钮 50px 通栏;画布分辨率降一档(DPR 封顶 1.5 × 0.75),无指针视差,时刻拨盘隐藏(用控制条里的时段按钮或 `?hour=`)。键盘弹起(`visualViewport` 变矮)时 `html.kb` 把天空压到 26svh、只留大字,并把聚焦框滚到视口中部(未真机验证)。

## 5. 技术实现与代价

- 一张全屏 **WebGL1 画布 + 单个片元着色器**(约 340 行 GLSL),无第三方库:
  三段渐变天空 + 日侧辉光 + 维纳斯带;透视云平面上的域扭曲 fBm 两层(积云 + 高空卷云,向光采样做明暗,近日 / 月处加银边与透光);极坐标网格星野(同一函数画星点与星轨);月面贴图 × 球面受光 = 当晚真实月相 + 地照;海面 = 反射天空(含云)+ 菲涅耳衰减 + 噪声法线 + 日 / 月光路;隐私云团单独一层;文字背后的 dodge & burn。
- 画布分辨率 = CSS 尺寸 × clamp(DPR × 0.62, 0.85, 1.25);演出期 60fps 封顶(120Hz 屏也只画 60),空闲 24fps;演出期连续掉帧自动降一档分辨率(最多两档)。没有 WebGL 时退回 Canvas 2D 的静态渐变版。
- 体量:`index.html` 17KB / `sky.js` 30KB / `app.js` 29KB(gzip 合计约 26KB);`assets/moon.jpg` 15.6KB;无新增字体(Dorami Serif 按页面用字拉分片,首屏约 16 片)。
- 落到 React:`sky.js` 与框架无关,可原样包成 `useSky(canvasRef, scene, fx)`(约 0.5 天);文案 / 状态机 / 开场时序约 1–1.5 天。风险:① 低端集显 / 老手机的 GPU 成本(有降档兜底,需真机过一遍);② 天色关键帧要在真屏上把 24 小时都看一遍;③ 太阳位置用纬度 32°N + 时区钟点近似(见 §8)。
- 样页工具:控制条 `extraControls` 有「拂晓 / 正午 / 黄昏 / 深夜 / 此刻」(1.5–2.5s 的短延时摄影过去);桌面顶部居中有 `data-sample-kit` 时刻拨盘(按分钟拖动);URL 支持 `?hour=6.5`、`?seed=3`(固定云)。`shoot_hours.py` 补拍 `shots/hour-06/12/17/23.jpg`(+ `-mobile`)。

## 6. 素材来源

- `assets/moon.jpg`:codex(gpt-6-astra 内置 image_gen)生成。prompt 摘要:「写实满月正面照,月海分布准确(雨海、澄海、静海、危海、风暴洋,『玉兔』可辨),天文摄影质感,灰度,圆盘贴满画面、纯黑背景、无星无光晕无文字」。原图 1254px,裁成圆盘后压到 256px 灰度 JPEG。shader 按本地日期计算月相,在贴图上叠受光与地照。
- 其余全部程序化:天空、云、海、星、日轮、颗粒都没有位图素材。
- 参考:Hiroshi Sugimoto《Seascapes》(https://mweditions.com/books/hiroshi-sugimoto-seascapes/)的地平线构图;Inigo Quilez 的动态云与域扭曲(https://iquilezles.org/articles/dynclouds/ 、https://iquilezles.org/articles/warp/);iOS「天气」的时段动态背景(时间感知天空的产品先例)。

## 7. Windows 理论确认

- 引擎:Chrome / Edge 在 Windows 上 WebGL 走 ANGLE → D3D11。本页只用 WebGL1 + highp(带 mediump 回退)、`LUMINANCE` 纹理与 mipmap,不依赖任何扩展或浮点纹理;编译失败退回 2D,不白屏。
- 合成:UI 只动 opacity / transform / filter;颗粒层 `mix-blend-mode: overlay` 需要整屏混合,弱集显上约多 1–2ms,真实实现可把颗粒挪进 shader。
- 字体回退:两套衬线都同源自托管;中文回退链 Songti SC → STSong → Noto Serif CJK SC → serif,Windows 未加载时落到系统宋体,版式不变;黑体走 Segoe UI / Microsoft YaHei UI。
- DPR 取整:125% / 150% 缩放下画布按 CSS 尺寸 × 缩放取整,shader 内一律换算回 CSS 像素(`uDpr`),星点不小于 0.7 画布像素;地平线读 DOM 的 `getBoundingClientRect`,不依赖整数像素。
- 减弱档只读 `<html data-motion>`,不受系统「动画效果」开关影响。

## 8. 已知不足 / 待拍板

1. **地理近似**:太阳轨迹假定纬度 32°N,季节昼长按日期算;不请求定位,所以西部时区(如乌鲁木齐,太阳正午约 14:00)与南半球读者的天色会和窗外有偏差。是否接受?可选「按时区粗估经度修正正午」。
2. **云的随机性**:云层每次登录随机(字面上的「每一次都不一样」);若想同一天看到同一片云,可改为按日期取种子。
3. **文案**:七个时段的问候与副句(早报 / 播客 / 长文 / 日报 / 问答)需要你过一遍口吻;副句用了全角逗号。
4. **交棒落幅**按时段选亮 / 暗阅读器底色(白天亮、夜里暗);真实实现应跟随用户主题设置,再相应选日光晕或星轨。
5. **对比度**:按最暗 / 最亮背景像素、不计文字柔光的保守口径,黄昏 17:36 英文眉题约 4.1、手机拂晓副句约 4.2,其余文字均 ≥ 4.5;实际有 dodge & burn + 柔光衬底,读起来无碍。若要严格达标,可把眉题提到 24px(大字口径)。
6. **GPU**:全屏 fBm 在 M 系列 Mac 上很轻;老 Intel 集显与中低端安卓未实测(有自动降档兜底)。手机键盘态逻辑未真机验证。
7. **截图体量**:颗粒噪点让 PNG 难压缩,`shots/` 约 23MB(含 8 张时段补拍)。
