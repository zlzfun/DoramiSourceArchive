# 方向 A · 晨刊(Broadsheet)

## 1. 一句话概念

**登录 = 翻开今天的头版。** 整页是一张两色印刷的报纸头版,登录表单是版面里的一栏「读者回执」;登录成功,日戳骑缝盖下,头版翻过去,露出阅读器。
哆啦美的主产品就是个人早报 / 公共日报——登录页先用一张「安静、筛选过」的报纸兑现这个承诺。它与现行「深空剧场」正好相反:浅色、纸、铅字与网点,而不是暗场、星座和玻璃。

## 2. 视觉系统

- **配色(两色印刷)**:新闻纸 `#f3eee3`(回执纸面 `#f8f5ee`,纸纹 + 轻暗角)· 墨版 `#1b1a17` / 正文 `#3a3833` / 次要 `#5d5950` / 占位 `#6a665d` · **第二色版 = 品牌墨靛 `#5252c5`**(靛色文字用深端 `#4745b3`)· 落幅 = 阅读器瓷底 `#f4f6f9`。
  对比度(对新闻纸):正文 10.1、次要 6.0、占位 4.9、靛字 6.6;按钮白字对 `#5252c5` 5.8。
- **品牌靛只当「专色」用在少数关键处**:报头(像人民日报的红报头,这里是靛报头)、肖像中间调网点、回执按钮、眉题小方块、校对圈、日戳、套准十字。其余全是墨。
- **字体**:报头 / 大标题 / 回执标题 Dorami Serif 900;正文、眉题、日期行 Dorami Serif 600;时钟、`Dorami` 斜体 Dorami Latin Serif;栏目说明、输入框、图注用系统黑体。字号下限 12px。
- **版式**:文武线 → 报眼(左「本报宜忌」、右「本地时间」)夹着居中巨型报头 → 日期行(公历中文数字 + 星期 + 农历)→ 四栏栅格:本报各栏 | 社论(两行大标题 + 两栏正文 + 首字下沉)| 点刻肖像 | 读者回执(虚线剪裁 + 点线骑缝存根 + 「日戳」占位圈)→ 页脚。版边有裁切线、套准十字、色标(纯装饰)。
- **吉祥物**:codex 生成的 hedcut 点刻像作墨版,Canvas 由同一张图算出靛版网点(15° 网角)叠印 = 双色铜版肖像。品牌像素原图的网点版保留为对比开关(样页控制条「肖像:点刻版 / 像素网点版」)。
- **真实数据只用客户端本地的**:日期、星期、农历(`Intl` 中国历,今天 = 丙午年九月十三,已核对重阳 10-18 = 九月初九)、本地时间(每分钟走一次)、时区(东八区)、按钟点变的版次(清晨版…晚间版…)、日戳上的日期时间。没有期号、标题、计数。

## 3. 动效分镜

**开场**(字体就位后开演,任意点击 / 按键跳过,`LoginSample.replay()` 重播;ms):

| 时刻 | 发生 |
|---|---|
| 0–900 | 顶部文武线自左向右拉出;版边记号淡入 |
| 220 / 380 / 540 | 报头三字逐字**压印**(各 680ms):放大模糊落下 → 0.96 过冲 → 回弹;落下瞬间描边加粗再收回 = 油墨被压开 |
| 520–1580 | 报头下细线、日期行文武线拉出;760–1080 报眼、标语、日期行「上墨」(模糊 → 清晰) |
| 900–2150 | 三道栏线自上而下拉出 |
| 1050–2300 | 一道「墨辊」自上而下滚过正文栅格(mask 显影) |
| 1450–2650 | 肖像**网点由粗到细显影**(网格 26px → 4.2px);约 2050–2330 点刻位图接替网点浮现 |
| 0–2480 → 2950 | 整块**靛色版错位** (7,−4)px,收尾套准(过冲 −1.2/+0.7 再归零):报头、肖像靛版、按钮底版(对墨色勾边)、套准十字同步 |
| ≈3000 | 落定;桌面精确指针下光标交给账号框 |

**常驻**:只有本地时间每分钟一跳;鼠标悬停肖像时出现「印刷放大镜」(细圈 + 十字刻度,1.9×,镜下的点刻像露出它其实是网点),移开淡出。其余全部静止,没有常驻 rAF。

**交互**:
- 聚焦:输入行底线变 2px 靛色、页边出现靛色校对竖标、淡靛底;按钮 `:focus-visible` 墨色外框。
- **密码隐私**:点刻像先化成报纸网点(170ms)→ 一道「过版带」自上而下把网点重排成捂眼像(430ms)→ 收回成点刻位图(230ms);图注同时换成「输入密码时,本报编辑自觉回避。」失焦反向。两张图除眼 / 手外逐像素一致,所以只有眼睛那一块在「重新排版」。
- **错误**:按校对符号「改正号」的意思,手绘圆角方圈描出出错的栏(空了哪栏圈哪栏、账号密码不对圈两栏,520ms),再拉一道引线落到页边说明「账号或密码错误」/「请输入账号和密码」;错误槽固定高度不跳版,一改字就淡去。文案只陈述、不责怪。
- **登录中**:按钮「登录中」+ 一道墨辊在按钮靛版上循环滚过;肖像靛版上一道网点加粗的带子自上而下走(印刷机在转)。
- **成功离场**:日戳(真实日期 + 时间「已核验」)**骑缝**落在回执与存根之间、正好盖进「日戳」虚线圈(420ms,放大落下 + 过冲,印泥飞白)→ 停一拍 → 整张头版从右下角掀起翻过(1180ms,折线由斜渐正;**纸背有正面的反字透印**:反写的报头、肖像、栏线和一行行字影)→ 露出阅读器瓷底,角落小字「样页到此 · 实际会进入阅读器」。

## 4. 减弱档与手机

- **减弱档**:直接给完成态(线、报头、肖像、套准全部在位),无 CSS 动画、无 rAF、无放大镜;密码聚焦即刻换成捂眼像 + 图注;校对圈直接画好;登录中只有文字;成功 = 日戳静态出现 → 0.7s 后整页淡出到阅读器底色。与完整档同一版面,不是半成品。
- **手机(390×844)**:报纸收成窄栏单页——报头约 26vw 仍压满一行,报眼收起,日期行一行;头条一行 → **读者回执在第一屏内完整可用**(右上角一枚迷你点刻像,聚焦密码同样会捂眼)→ 社论单栏 → 肖像 → 各栏 → 页脚。无悬停故无放大镜;版边记号隐藏;翻页仍保留(单层 Canvas,开销低)。
- **其它桌面尺寸**:1440×900、1920×1080、1280×800、1280×720 均一屏放下(矮屏依次隐去副题 / 声明 / 各栏说明 / 末段);≤1179px 降为三栏,单栏正文。

## 5. 技术实现与代价

- 纯原生 HTML / CSS / Canvas 2D,**无第三方库**。开场全是 CSS keyframes(transform / opacity / filter / mask-position),档位只认 `html[data-motion]`,未写系统级减弱动效媒体查询。
- 肖像:墨版位图 multiply 叠印 + 靛版网点(每帧一次 path 批量 fill,约 4k 点,<2ms);有动画才开 rAF,落定即停;`document.hidden` 暂停;DPR 封顶 2。
- 翻页:头版本身逐帧 `clip-path` 多边形裁切,纸背 / 投影 / 透印画在一层全屏 Canvas 上(透印 = 把正面要素按折线做反射变换再画一遍)。
- **新增素材**:`hedcut-a.png` 59 KB(首屏唯一图片)、`hedcut-b.png` 59 KB(紧随其后后台取)、`portrait-pair.png` 20 KB(只在切到像素版时取)、3 个 SVG 纹理共 2 KB;`broadsheet.js` 41 KB / `broadsheet.css` 28 KB(未压缩、注释多;gzip 后 13 KB / 8 KB)。
- **字体**:没有新字体。但本页正文也用 Dorami Serif,首次访问会拉约 32 个 unicode-range 分片、约 1.4 MB(平台字体,进阅读器后本来就要用、之后命中缓存)。落地建议:登录页文案固定,构建期单独子集化(600 / 900 两档估计合计 100–150 KB),或正文改系统宋体。
- **React 落地工作量**:版面静态 JSX + CSS 约 1 天;`Portrait` 类搬成 hook + canvas ref 约 1 天;翻页 / 透印 / 校对圈 / 日戳各是独立函数,约 1 天;合计 3–4 天。风险:①字体体量(见上);②逐帧 `clip-path` 裁整页在低端机上的开销(可退化为整页 transform 翻转 + 淡出);③hedcut 是 AI 生成图,正式启用前请确认素材口径。

## 6. 素材来源

- **codex 生成(gpt-6-astra · image_gen)**:先 `view_image` 两张品牌图,prompt 摘要——「把角色画成《华尔街日报》式 hedcut 点刻肖像:只用纯黑墨点与细密排线、纯白底、无文字无边框无星点;构图与参考一致(正面胸像、蝴蝶结完整、下沿到项圈铃铛),保留蝴蝶结 / 头罩 / 右眼目镜 / 铃铛;第二张同画风同构图,双手捂眼,并以第一张为参考」。一次成功,原图 1254² RGB 各约 2.6 MB(未入库);`tools/prep_hedcut.py` 裁到墨迹框、缩到 600×686、量化为 4 级灰 2-bit PNG(肉眼无损,WebP / AVIF 同体量会把点抹糊)→ `assets/hedcut-a.png` / `hedcut-b.png`。**效果很好,作为主方案采用。**
- **像素网点版**:`tools/prep_portrait.py` 从 `dorami-logo-512.png` / `dorami-logo-cover-eyes-256.jpg` 抠出角色(亮紫描边泛洪 + 最大连通块),按黄头罩外框对齐两张图,裁到并集外框 → `assets/portrait-pair.png`。
- **参考**(未逛设计画廊;手法来自印刷常识):
  - Hedcut(WSJ 点刻肖像):https://en.wikipedia.org/wiki/Hedcut
  - 网点与网角(套色网角错开防龟纹):https://en.wikipedia.org/wiki/Halftone
  - GB/T 14706《校对符号及其用法》中的「改正号」(圈出错处 + 引线到页边写说明)
  - 中文报纸版式惯例:文武线、报眼、眉题、专色报头、骑缝章

## 7. Windows 理论确认

- **引擎**:Edge / Chrome 与验收用 Chromium 同核;Firefox 也支持 `mask-image`、`-webkit-text-stroke`、Canvas `multiply`、`Intl` 中国历(若某环境不给 `yearName`,农历段自动隐藏)。`text-wrap: pretty`、`hanging-punctuation` 不支持时静默忽略。
- **合成属性**:开场只动 transform / opacity / filter / mask-position;翻页逐帧改 `clip-path` 走主线程重绘,1080p 可承受。
- **字体回退**:报头、标题、正文均为同源自托管 woff2,Windows 与 Mac 一致;小字走 Segoe UI Variable / 微软雅黑 UI;不会落到无粗体的中易宋体。ClearType 下 900 宋体边缘略硬,可接受。
- **DPR 取整**:常见 1.25 / 1.5;Canvas 宽高取 `round(css × dpr)`,网点是矢量圆点不受影响;1px 栏线由浏览器对齐像素。
- **系统「动画效果」开关**:按约定以应用内 `data-motion` 为准。

## 8. 已知不足 / 待拍板

1. **肖像二选一**:点刻版(codex,更像报纸、更有质感)vs 像素网点版(品牌原图、零新素材、与现有 logo 一致)——控制条可切换对比。
2. **报头颜色**:靛色专色(现方案,品牌感强)还是墨黑(更像西式大报、更克制)?
3. **字体体量**:正文是否改系统宋体,或为登录页做专用子集(见 §5)。
4. **翻页时长** 1.2s(连同日戳约 2s 才见到阅读器):天天登录的人会不会嫌长?可压到 0.8s,或第二次起只盖戳 + 淡出。
5. **文案锋芒**:「本报宜忌」(忌 刷屏 · 焦虑 · 标题党)、「不贩卖你的注意力」带一点社论的锋芒,是否保留?
6. **版次随本地时间变**:晚上打开显示「晚间版」;方向名叫「晨刊」,要不要固定写「晨刊」?
7. **「日戳」占位圈**:空态预告「登录后这里会盖章」;嫌多可只在成功时出现日戳。
- 已知:靛版网点在轮廓外有约一格的「晕」(模拟网点扩大,有意保留);≤1179px 的平板只做了基本适配;开场与翻页的帧观感用 Playwright 录屏逐帧核过,未在真实 Windows 机器上实测。
