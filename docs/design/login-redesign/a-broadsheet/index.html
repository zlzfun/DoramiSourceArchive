社论

世界很吵，
早报很静。

哆啦美替你读完订阅的每一个来源，按你的兴趣，把值得一读的排成一份只属于你的报纸。

清清晨醒来，先迎上来的往往不是消息，而是噪音：重复的转载，夸张的标题，同一件事的无数种说法。哆啦美做的事情很朴素——替你先读一遍。

只排值得一读的

每一篇报道，它都会掂量分量，写下提要，再按你的兴趣排定版面。外文的，替你译成中文；冗长的，先给你要点；读到想追问处，直接问它，回答逐条注明出处。

它不催促，不刷屏，不推送你不需要的热闹。你只需在早晨翻开它，像翻开一份为你一人付印的报纸。

本报声明不刊广告，不贩卖你的注意力；每一个版面，只对你一人负责。
