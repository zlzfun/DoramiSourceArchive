# C · 像素(Pixel)— 设计说明

## 1. 概念

**「哆啦美从夜城背后升起」**:把吉祥物本身的像素画风升格为整套视觉语言——全场只有一个像素单位,Bayer 抖动的夜空、逐格亮起的星与窗、一只在城市上空守夜的像素哆啦美;登录成功时,她把夜色化回像素,替你推开清晨(阅读器)的门。

为什么适合哆啦美:吉祥物本来就是像素画,这个方向让她当主角,把「蒙眼」品牌记忆做成一等交互;「夜里守着资讯、清晨给你早报」的叙事正好对应产品(早报 / 翻译 / 问答 / 播客),不需要任何数据或内部词。

## 2. 视觉系统

- **网格**:全场一个单位 U = 整数设备像素 ÷ DPR。1440×900 → 5px(289×181 格),1280×800 → 4px,1920×1080 → 6px,390×844@2x → 4.5px。场景是一张低分辨率 Canvas,CSS `image-rendering: pixelated` 整数倍放大;吉祥物、星、城市、水面同一网格,不混像素尺寸。
- **配色**:夜空 11 阶 `#05041a → #433a95`(品牌墨靛 `#5252c5` 同色相的暗部,最亮两阶只给吉祥物身后的光晕);远城 `#17143f` / 近城 `#0c0a29`;窗光暖 `#f2c46c` `#ffe3a3`、冷 `#a19df7`;航标 `#ff5d73`;水面 `#0c0a2b → #05041a`,岸线 `#2a246b`;吉祥物一格月色描边 `#3f3896`。
- **界面色**:主文字 `#f3f1ff`、次 `#bfbcec`、弱 `#9895d2`(对底 ≥ 7:1);输入底 `#0b0a26` / 线 `#3a3688` / 焦点 `#b9b5ff`;按键 `#5252c5`(白字 6.2:1)/ 侧面 `#2b2984`;错误 `#ffa6b0`。品牌靛是唯一的界面实色(按键),其余靛都是它的暗部;头罩黄 `#ffd36e` → 光标与「账号星」,目镜冰蓝 `#c9f6ff` → 「密码星」与目镜进度。
- **字体**:标题 Dorami Serif 900(76 / 手机 44px,字距 .14em),标语 Dorami Serif 600 17px;标签、输入、按键走系统黑体;左上 DORAMI 与右上本地时间是 Canvas 自绘 5×7 点阵(每点 2px,手机 1.5px)。不新增字体。
- **版式**:居中的「游戏标题画面」。吉祥物从天际线后升起(城市在她胸前压成连续低墙、两侧山谷形抬高,露出项圈与铃铛);岸线以下的水面上是标题、标语与横排登录条(账号 228 / 密码 228 / 按键 156);右下「早报 · 翻译 · 问答 · 播客」。与现行「左题词 + 右玻璃卡 + 点云」完全不同。
- **吉祥物**:73×90 格、32 色、5 帧图集(待机 / 眨眼 / 开心 / 捂眼 / 为难),帧间除变化区外逐格一致。

## 3. 动效分镜

**开场**(≈3.5s;任意点击 / 按键跳过,忽略样页控制条;`LoginSample.replay()` 重播)

| ms | 镜头 |
|---|---|
| 0–900 | 夜空按 8×8 Bayer 阈值逐级显影(有序抖动溶解) |
| 220–1120 | 星点逐颗点亮:先一格,再闪出十字 |
| 480–1380 | 远景、近景城市逐格升起,水面抖动显影 |
| 1000–2250 | 吉祥物从天际线后升起 44 格(量化到整格)并按阈值「成形」;身后光晕 24 级一环环亮起 |
| 1900–2330 | 标题「像素对焦」:栅格化到 Canvas,块 6u → 1u 逐级变细,最后换回矢量字 |
| 2350–2900 | 标语、账号、密码、按键依次抖动显影(遮罩与场景同格对齐) |
| 2900–3300 | 角标点阵逐字打出,能力行显影;3350 第一次眨眼,3500 完成 |

**常驻**(10fps 步进,像素画节奏):星 3–4 级闪烁 + 4 颗十字主星换帧;眨眼 2.6–6.8s 一次(18% 连眨);目镜斜光 7–10s 扫一次;蝴蝶结每 6.5–12s 向上一翘(140ms);8% 窗格明灭、航标 2.6s 一闪;水面月光带 320ms 重排、倒影 640ms 错一格;流星 14–26s 一颗;时钟冒号 1Hz。

**交互**
- 聚焦:方角双线焦点环(墨色间隙 + `#b9b5ff`),金色光标。
- 输入:每个字符在天上一个固定种子位点亮一颗星(账号金 / 密码冰蓝),4 帧闪出后收成柔光十字;删字即熄灭。
- 密码隐私:聚焦 → 4 级抖动交叉溶解(170ms)到「黄爪捂眼」;失焦放下。
- 错误:「> <」为难帧 + 摇头(项圈以上逐格 ±2 / ±1,6×58ms);输入框描边转珊瑚;文案在固定 20px 槽内抖动显影(role=alert);2.6s 后回到捂眼 / 待机。
- 登录中:她放下手,目镜玻璃从左到右被冰蓝光一格格充满(白色前沿);按键「登录中」+ 5 格像素进度(宽度固定不跳版);输入只读、aria-busy。
- 成功(≈1.7s):开心帧 + 小跳 + 目镜满格 → 200ms 标题反向像素对焦、其余抖动退场(她独自在城市上空笑一拍)→ 700ms 场景逐级马赛克(2 → 24 格均色)→ 1000ms 阅读器底色 `#f4f6f9` 从她脸上以「距离 + Bayer」前沿铺开 → 1700ms 落幅,右下「样页到此 · 实际会进入阅读器」。
- 样页按钮:捂眼 / 眨眼 / 蝴蝶结 / 目镜扫光 / 流星(不用等随机时刻)。

## 4. 减弱档与手机

- **减弱档**:同一构图的完成态定格(星不闪,无扫光、粼光、流星);状态切换改为瞬时换帧、不摇头;成功为 240ms 淡到落幅。`shots/desktop-reduce.jpg` 与完整档终帧同等完成度。
- **手机**:单列,吉祥物居上(U≈4.5px,约 330px 宽)、表单在下;主星减为 2 颗、天际线压低。键盘弹起(visualViewport 变矮)或视口高 < 640px 进入紧凑档:重算 U 让吉祥物缩成小像(390×500 实测约 90px 高),隐藏标语与能力行,标题 32px,构图钉在可视视口上。

## 5. 技术实现与代价

- **原生 Canvas 2D**:一块 Uint32Array 低分辨率帧缓冲,每帧合成(夜空 → 星 → 精灵 → 城市 → 水面 → 离场效果)后 `putImageData`,由 CSS 整数倍放大;零依赖。Playwright 实测单帧合成 0.2–0.5ms;空闲 10fps、过渡 30fps,`document.hidden` 停帧。动效档位只读 `<html data-motion>` 并监听 `sample:motion`,未写 `prefers-reduced-motion`。
- **DOM 层**:Bayer 4×4 遮罩(17 级 data URL)做抖动显影 / 退场;标题像素对焦用临时 Canvas。文字始终是真 DOM(可读、可选、读屏完整)。
- **体量**:精灵图集 8.5KB;`pixel.js` 56KB(gzip 18KB,含注释);`index.html` 10KB;不新增字体。`assets/codex-sources.jpg`(117KB)只是素材出处存档,页面不加载。
- **落到 React**:引擎拆成纯模块(布局 / 世界生成 / 帧合成 / 情绪状态机)+ `<PixelScene>` 组件 + `useDither` 钩子,表单沿用现有 LoginScreen;估 2–3 人日。风险:①精灵需像素画师精修;②mask-image 在低端机的重绘;③成功落幅要在登录前知道阅读器亮 / 暗主题。

## 6. 素材来源

codex(gpt-6-astra · 内置 image_gen),均先 `view_image` 品牌图 `frontend/public/brand/dorami-logo-512.png` 再生成:
- `codex-idle.png`:同角色像素半身像,正面待机;要求严格像素网格、约 20 色、深紫 1 像素描边、纯绿底、下沿裁在口袋 → **母版**。

## 7. Windows 理论确认

- 像素格按**设备像素**取整:Canvas CSS 尺寸 = 格数 × 整数设备像素 ÷ DPR,125% / 150% 缩放下每格仍落在整数设备像素(不出现宽窄不一的格);DPR 变化(换屏、改缩放)经 `matchMedia(resolution)` 重算。
- `image-rendering: pixelated`(Chromium / Edge;Firefox ≥ 93),前置 `crisp-edges` 兜底;Canvas 2D + CSS 缩放走 GPU 合成,不依赖 WebGL。
- `mask-image`(Chromium ≥ 120 无前缀,另写 `-webkit-`)、`:has()`(按键按下 / 焦点环)Edge 现行均支持。
- 字体:Dorami Serif 自托管;黑体回退 Segoe UI Variable / Microsoft YaHei UI。Canvas `letterSpacing` 只用于 0.4s 标题对焦过渡,不支持时过渡期可能偏几像素,终态是 DOM 字不受影响。点阵角标点径取整到设备像素。

## 8. 已知不足 / 待拍板

1. 吉祥物是 AI 生成 + 程序整理,目镜全息区与眼部仍有少量杂色格;若选本方向,建议像素画师精修 5 帧(可再加「看向表单」帧,让目光随输入移动)。
2. 「捂眼」用黄爪(与现行蒙眼图一致)而非白色圆手——请确认。
3. 标语「夜里她替你读资讯，清晨给你一份早报。」是提案文案(用「她」指代吉祥物)。
4. 只有夜景:为避免与 E「天色」撞车,不随时刻变天;白天登录也是夜城。
5. 成功落幅取阅读器亮色 `#f4f6f9`;暗色主题用户应落到暗底,需登录前读本地主题偏好。
6. 桌面横排登录条较少见(更像标题画面的菜单);若偏好竖排,可在同一构图里改为水面上的竖排窄卡。
7. 窗灯、倒影、星都是纯装饰,不代表任何数据;时间只取本地时钟。
