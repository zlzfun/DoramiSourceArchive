# 方向 B · 信号(Signal)

## 1. 概念

**从噪声里，听见信号。** 全屏是数十条层叠脊线(后排被前排遮挡,脉冲星记录式的峰群),鼠标是一枚「调谐器」:它经过之处噪声被抚平、尖峰对齐成干净的列。哆啦美每天替读者从信息噪声里挑出真正重要的——这正是页面在做的事;而当信号调准时,脊线会隆起成哆啦美本人的浮雕:**她就是那个信号**。

## 2. 视觉系统

- **配色**:底 `#06070a`(微冷近黑);线 `rgb(230,233,242)` 冷白,后排 α0.56 → 前排 α0.96 给出纵深;正文 `#eef0f6` / 次 `#b3b7c5` / 弱 `#8b90a3`。
- **品牌靛点睛**:登录按钮 `#5252c5`(悬停 `#6f6bd7`、按下 / 登录中 `#4745b3`);聚焦下划线与标签 `#9c99f5`;线条的调谐染色、按键脉冲拖尾 `rgb(168,164,255)`。靛只出现在「被调准 / 被选中」的东西上。
- **信号色**:`#ff5148`,取自吉祥物的红蝴蝶结 / 红鼻子,语义是「ON AIR」直播灯。只用在右上状态点和错误小波形符(各约 6–16px),全页面积 < 0.01%。错误文字另用 `#ff958c`。
- **对比度**:输入与大字 17.7:1、lede 10.1:1、标签 / 顶栏 6.4:1、错误 9.5:1、按钮白字 6.2:1、落幅说明 5.4:1。
- **字体**:「哆啦美」Dorami Serif 900(68–132px 自适应),副题「从噪声里，听见信号。」600;界面系统黑体(输入 17px、标签 13px),顶栏读数系统等宽 12px。只用 400 / 600 / 900,无新增字体。
- **版式**:左栏(330–420px)放品牌块与下划线式表单,右侧整片交给信号场,峰群中心在场宽 54% 处。**账号、密码的下划线就是两条信号线**:行距按两条下划线的间距反算,两条线恰好落在脊线行上,从输入框一路延伸进信号场,叫它们「频道线」。顶栏左「DORAMI」,右边是本地日期时间(客户端真值)+ 状态词。场底一条细刻度,靛色指针跟随调谐器。
- **吉祥物**:品牌块里 44px 像素 logo;密码聚焦时换成捂眼图。另有用 codex 深度图驱动的脊线浮雕(见 §3)。

## 3. 动效分镜(完整档)

**开场**(任意点击 / 按键跳过,控制条除外;`LoginSample.replay()` 重播):

| 时间 (ms) | 画面 |
|---|---|
| 0–120 | 全黑 |
| 120–1490 | 约 57 条线由上到下错峰「写入」(每条 950ms,带光点束头),内容是沸腾的静电 |
| 920–2520 | 一根竖直扫描针(1px 亮线 + 靛色辉光)从屏幕最左扫到最右:身后依次显影 logo、品牌字、副题、表单、按钮、顶栏(36px 羽化遮罩);进入信号场后,针后的静电落定成脉冲星峰群,针前仍是静电 |
| 1900–3400 | 信号轻微过冲(1.16×)后回稳 |
| 2400–5000 | **浮现**:峰群退去,脊线隆起成哆啦美头部浮雕(蝴蝶结、头罩、脸、目镜;升 600、停 1150、散 850),然后溶回峰群 |

开场在 3100ms 计为结束,浮雕作为环境事件自然走完。表单从约 1.5s 起即可用。

**常驻环境**:约 20fps;尖峰缓慢漂移(±2–7px,0.08–0.34Hz)、幅度呼吸 ±24%、噪声晶格缓慢演化。40s 无交互则在 2.5s 内缓停并停在最后一帧;`document.hidden` 时暂停。

**调谐器**:
- **镜头**:椭圆镜头跟随光标,弹簧 τ110ms,横向半径约为视口宽的 12.5%。镜头内:噪声归零;尖峰变宽、变圆,并吸附到各自分量的中心列,行行对齐,有序就从这里显出来;游离尖峰淡出;线条染靛。
- **余迹**:清晰度快升(70ms)慢落(950ms),快速划过会留下一道平滑的余迹,再慢慢被噪声吞回。
- **拨弦**:纵向快速穿过行时,会轻拨经过的行(4Hz 衰减振荡,约 0.5s)。
- **彩蛋**:在峰群正中停 1.8s,也会浮现吉祥物(冷却 9s,离开中心后才重新上膛)。

**交互反馈**:
- **聚焦账号**:下划线 500ms 由左画出 2px 靛线,标签变靛;这条频道线在整片信号场里变靛,表示「已选中频道」。
- **账号输入**:每次按键从光标处发出一个脉冲:亮头 + 190px 靛色拖尾,以 1050px/s 沿下划线冲进信号场;相邻两行以 42% 强度、35ms 延迟回响。
- **密码聚焦(隐私动作)**:
  - logo 320ms 交叉淡入捂眼图。
  - 信号静默从密码那一行开始,逐行向外扩散(11ms/行),全场压平到 3.5% 幅度、亮度降到约 26%,只剩密码频道留一条暗靛线;状态变「静默」。
  - 密码按键不向场内广播,只在密码下划线上跑一道 620ms 的小靛光。
- **登录中**:噪声 7%、信号 6%,所有行同相的相干波以约 400px/s 向右传播(静默解除,即使焦点仍在密码框);按钮「正在登录」+ 滚动正弦;状态「同步中」(靛点)。
- **出错**:
  - 70ms 内爆出全场高频静电(行随机横向错位 ±13px、亮度闪烁,每 60ms 换一次),τ550ms 回落。
  - 两条频道线保持珊瑚色的抖动(沿 x 方向 240px 内衰减),下划线也保持珊瑚色,直到重新输入。
  - 错误文案在固定 22px 槽内出现;状态「干扰」1.3s。
- **成功离场**:
  - 0–320ms:峰群压平。
  - 300–920ms:各行由内向外依次加速吸入中线(不交叉),同时表单和顶栏淡出;每并入一行,中线就更亮一分。
  - 500–1000ms:中线向两侧展开成贯穿全宽的亮线。
  - 860–1620ms:靛色辉光一闪。
  - 1000–1600ms:亮线张开成带羽化边的光幕(白芯 → 阅读器底色 `#f4f6f9`)。
  - 1620ms:落幅停在阅读器底色,右下一行「样页到此 · 实际会进入阅读器」;画布在 2.1s 停表。

## 4. 减弱档与手机

- **减弱档**:无开场、无环境动画、调谐器关闭。用同一模型、固定时刻,渲染一帧精致的静态峰群(含刻度,指针居中)。状态切换只重绘静态帧:
  - 密码 → 静默帧 + 捂眼 logo
  - 登录中 → 冻结的相干波 + 静态波形符
  - 出错 → 略带静电的帧 + 珊瑚色频道线
  - 成功 → 直接落幅

  所有 CSS 过渡改为 0s。
- **手机(390×844)**:
  - 版式:单列,品牌 → 信号带(clamp(170px, 27svh, 280px))→ 表单。约 25 行、9px 行距(桌面约 57 行),无频道线和刻度。
  - 调谐器:沿慢速利萨如曲线自走,触摸时接管,松手 1.6s 后恢复自走。
  - 反馈:按键脉冲走最底一行;静默从底行向上扩散。
  - 布局与性能:画布绝对定位在可滚动的 body 内(不 fixed),键盘弹起时页面可滚、不遮挡;环境 20fps,同样会缓停。

## 5. 技术实现与代价

- **技术**:纯 Canvas 2D,无任何库。
  - 每行 = 分量小丘 + 1–3 根高斯尖峰 + 三层值噪声(向上偏置,乘性叠在峰上让峰顶毛糙)。
  - 遮挡:由后往前画,每行先用底色填充曲线下方,再描线。
  - 横向渐隐用线性渐变描边;调谐、脉冲、频道染色都是同一行的局部二次描边;状态参数都做指数平滑。
- **体量**:
  - `signal.js` 48.7KB / gzip 15.7KB(未压缩、带注释),`index.html` 14KB。
  - 浮雕高度图 `assets/mascot-height.png` 5.8KB(112×122 灰度,运行时读入)。
  - 字体只用已有的 Dorami Serif 分片。
- **实测**(Playwright,Apple Silicon,1440×900):交互态 JS 约 1.9ms/帧;环境态 20fps、约 3.3ms/帧,主线程占用 6–7%;DPR 1 与 2 相近,DPR 封顶 2。
- **落 React**:`<SignalField state focus onKeyPulse />` 包一个约 600 行的 TS 画布引擎,表单保持普通 DOM。约 1.5–2 人日(含调参)。风险:
  - 频道线依赖输入框的几何位置(ResizeObserver 加字体加载后重排已处理);
  - 4K 和低端 GPU 下可把采样步长 3→4px、行数打 8 折;
  - 高度图可内联成 base64。

## 7. Windows 理论确认

- **渲染**:Chromium / Edge 的 Canvas 2D 走 Skia + ANGLE(D3D11),与 macOS 同一套代码路径,不依赖 WebGL。
- **非整数 DPR(1.25 / 1.5)**:画布底板是 `round(W·dpr)`,线宽按 CSS px 计,线会略软但可接受;刻度的 +0.5 对齐只在 DPR 1 / 2 下锐利。
- **合成属性**:开场遮罩用 `mask-image`(带 -webkit- 前缀,Chromium、Firefox 都支持),其余只用 opacity / transform。
- **字体回退**:等宽回退到 Consolas / Cascadia Mono,黑体回退到 Segoe UI Variable / 微软雅黑 UI;Dorami Serif 自托管 woff2 不受影响。
- **计时**:Windows 上 Chrome 的 `setTimeout` 粒度约 4ms,20fps 节流不受影响。
- **强制色模式**:画布不受影响,表单仍可用;正式实现时可补 `forced-colors` 微调。

## 8. 已知不足 / 待拍板

1. **浮雕频率**:每次开场都在 2.4–5.0s 浮现吉祥物。选项:保持 / 只在当天首次登录出现 / 只留「停在峰群中心」彩蛋。
2. **致敬的显性程度**:脊线语言明确致敬《Unknown Pleasures》。波形是自生成的,不用原始数据也不用封面,但联想很强,请确认可以接受。
3. **两处可删的仪器细节**:状态词(调谐中 / 静默 / 同步中 / 干扰 / 已锁定)和场底刻度,都是为调谐器叙事服务的。若想更极简,两者都可以删。
4. **落幅底色**:成功落幅按浅色阅读器底 `#f4f6f9` 做。登录前不知道用户的主题,正式实现可以读本地已存的主题偏好,深色用 `#0d0f13`。
5. **浮雕的五官**:浮雕来自 AI 深度图,五官是「雕塑化」的近似。正式版可以请人出一张标准深度图,或从矢量稿生成。
6. **键盘用户**:只用键盘的用户看不到调谐器,只有按键脉冲和状态反馈。这是有意的,以表单可用为先。
