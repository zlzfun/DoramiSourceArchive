## 怎么看

在仓库根（本 worktree）起一个静态服务，再打开总览页：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/docs/design/issue-279-frontend-refactor/index.html
```

字体与品牌图直接引用 `frontend/public/` 里的自托管文件，所以要从仓库根起服务；不请求任何外部域名。

样式、脚本和截图的地址都带 `?v=` 版本号。`http.server` 不发缓存头，浏览器普通刷新只重新取页面本身、不重新取这些文件，所以每次返修都要把三张页面里的版本号一起改掉。

## 这一轮的做法

1. **先量**：同一个普查脚本分别跑现网（游客，1440 × 900，七屏）与样页，统计视口里实际出现的字号、行高、字距、圆角、控件高度、图标尺寸与对比度。脚本与原始结果在会话临时目录，没有入库；结论表在 `index.html`「实测」一节。
2. **对规范**：逐节对照 `docs/frontend/conventions.md`，把样页的每处改动归到「沿用 / 修订 / 新增」。修订项都是用户拍过板的条目，落地前要逐条确认。
3. **再改**：改动以并档为主（字号 17 级 → 10 级、图标 8 种尺寸 → 3 种、同级控件圆角与高度收口），结构上只动版框、页头、阅读窗的速读卡与页边。
