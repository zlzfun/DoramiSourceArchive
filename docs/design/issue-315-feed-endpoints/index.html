现网与两个方向

A
五个接口的真实路径一屏看全,每组带自己的范围签;点开一行,是这个接口的调用示例和它认的参数。写的路径与管理面账户抽屉里「接口调用」那几行是同一套名字。
B
文章、热点事件各占一行,行尾的分段选格式(JSON / Markdown / Atom)或取哪一份(榜单 / 单个事件),地址、示例、参数跟着换——与隔壁「MCP 接入」切配置格式是同一种做法。五个里有三个的地址要点一下才看得到。

顺带查到的

  • 现网「接口参数」写的是「limit 上限 500」,只对 JSON 成立;Markdown 的上限是 200,也不认 include_content。样页按接口分别写。
  • Atom 接口在契约文档与端点清单里同样没有记,这一波的文档一并补上。
  • 实现时加一条测试:页面列出的接口与后端 /api/public/feed/ 下的路由逐条对账,以后新增接口而页面没跟上会红。

样页的边界

  • 底页是在隔离栈里抓的现网设置弹窗(DOM 与样式),新增部分只用现有的类与取值。抓的是 issue #312 分支(PR #316,待合入),所以令牌下面已有「最近调用」那一行。
  • 弹窗后面的页面没有放——现网那里是被遮罩压暗、虚化的阅读器。
  • 域名、令牌尾号、调用次数是示意;示例里的事件编号 128 也是。
  • 「MCP 接入」「显示」「重新生成」「签发令牌」点了没有反应;复制只给对勾,不保证真的进了剪贴板。
  • 手机上的设置不列「接入集成」(issue #230),这张卡只有桌面。没有在 Windows 上看过。
