# issue #315 设置 · 聚合接口列全令牌接口 · 样页(2026-11)

> 状态:归档。2026-11-20 由 Claude Code(Fable 5.2)做的第一轮样页;同日用户「全按推荐」——方向 A 分组列全、打开时全收起、行尾标返回格式、卡头加「MCP 接入」链接、Atom 示例把令牌写在地址里、单订阅令牌的接口不列,已照此实现。页面里的「待拍板」「推荐」是当时的写法,保留原样。方案见 [`docs/archive/issue-315-feed-endpoints.md`](../../archive/issue-315-feed-endpoints.md),issue [#315](https://github.com/zlzfun/DoramiSourceArchive/issues/315)。

要回答的是一件事:读者在设置 → 聚合接口怎么看全这枚令牌能调的接口。现网 5 个接口只列了 2 个。

## 怎么看

在仓库根(本 worktree)起一个静态服务,再打开总览页:

```bash
python3 -m http.server 8766 --bind 127.0.0.1
# http://127.0.0.1:8766/docs/design/issue-315-feed-endpoints/index.html
```

字体引用 `frontend/public/`,所以要从仓库根起服务;不请求任何外部域名。样式与脚本的地址都带 `?v=`,返修时把 `index.html`、`app.html`(由 `tools/build.py` 的 `VERSION` 生成)与 `assets/index.js` 里的版本号一起改掉——`http.server` 不发缓存头,浏览器普通刷新不会重新取这些文件。

| 文件 | 内容 |
|---|---|
| `index.html` | 总览:现网 / A / B 并排、各自的展开与切换、身份与令牌状态、列了什么、六项待拍板、样页的边界 |
| `app.html` | 可点原型。底部深色条是样页开关(方向 / 身份 / 令牌 / 卡头链接 / 明暗),不属于产品界面。地址参数见 `assets/proto.js` 文首 |
| `assets/app.css` | 应用样式的原样导出(`document.styleSheets`),只去掉登录页专用的 `@font-face` |
| `assets/proto.css` | 新增部分的样式。上半是要落地的(`.ep-group` `.ep` `.ep-body` `.ep-code` `.ep-params` `.endpoint-fmt`,取值只用现有 token),下半 `.px-*` 是样页开关 |
| `assets/proto.js` | 接口清单(路径、范围、示例、逐接口的参数)+ 两个方向的渲染 + 样页开关 |
| `assets/index.{css,js}` | 总览页自己的样式,以及把原型裁切、缩放进画框的脚本 |
| `tools/build.py` | 把沙箱抓到的现网弹窗整理成 `app.html`(沙箱地址、令牌尾号、调用次数换成示意值) |
| `tools/shots.py` | 自查:逐个状态打开原型截图、量行高与滚动高度,收集控制台报错与失败请求 |

## 两个方向

- **A 分组列全**(推荐):文章、热点事件两组,每组带自己的范围签;五个接口一行一个,写真实路径,行尾标返回格式。点开一行是这个接口的用法——调用示例加它认的参数;同时只开一行。默认全收起,五行一屏看全,不用滚。
- **B 一组一行**:每组一行地址,行尾一枚分段选格式(JSON / Markdown / Atom)或取哪一份(榜单 / 单个事件),地址、示例、「接口参数」跟着换。与「MCP 接入」切配置格式是同一种做法;五个里有三个的地址要点一下才看得到。

两个方向共有的:范围签从卡头挪到每组(文章按订阅裁剪,热点事件是全站口径——issue #310 当时卡住的就是这一点);卡头右侧一条通往「MCP 接入」的链接(那边已有一条通回来的);参数按接口分别写。

## 做法

1. **底页是现网**。在隔离栈(开发库副本,代码 = issue #312 分支,PR #316 待合入)用 Playwright 打开设置 → 聚合接口,取遮罩与弹窗的 DOM 和全部样式表,`tools/build.py` 整理成 `app.html`。弹窗后面的页面没有放。
2. **新增部分沿用现有形制**。接口行就是现网的 `.endpoint`(行高 42px 未变),范围签是 `.target-chip`,B 的分段是 `.mini-seg`,示例是 `.codeblock` 的字与色,参数行是「接口参数」折叠里那种写法,小三角与折叠标题前的是同一枚。新起名字的只有上表 `proto.css` 那六个类。
3. **内容照后端现状**。五个接口、各自的范围、上限与参数,对着 `src/api/routers/subscriptions.py`、`events.py` 逐条写的;Atom 的示例用地址里带令牌的写法(RSS 工具带不了请求头,契约里记为安全性较低的退路)。
4. **自查**(2026-11-20):`tools/shots.py` 的 21 个状态零控制台报错、零失败请求;接口行行高全部 42px;A 默认状态正文高度 515px,等于可视高度,不出滚动条;没有被截断的地址。截图逐张看过。

## 边界

- 域名、令牌尾号、调用次数、示例里的事件编号是示意。
- 「MCP 接入」「显示」「重新生成」「签发令牌」点了没有反应;复制只给对勾。
- 手机上的设置不列「接入集成」(issue #230),这张卡只有桌面。没有在 Windows 上看过。
- 页面清单与后端路由对账的守卫测试是实现期的事,样页里看不出来。
