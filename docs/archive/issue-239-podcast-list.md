# Issue #239 播客列表精简：方案与集成记录

> 状态：2026-10-30 用户验收采用并授权提交；实现已完成，集成与交叉检视尚未完成。本记录保留方案与验收依据，现行呈现约定见 [前端约定](../frontend/conventions.md)。

## 问题与选择

[Issue #239](https://github.com/zlzfun/DoramiSourceArchive/issues/239) 要求减少播客列表标签负担并保留「优质播客」。四个独立候选基于 `8e025fd` 实现；用户认为 Codex 用图标表达部分属性最直观，确认采用，其余方案保留比较、不再修改。

采用方案将节目来源、时间和分数放顶行，标题独立；时长与优质徽标同排，导读能力用图标和「中文导读 / 有声导读 / 导读生成中…」轻提示。无导读不显示默认态标签，评分依据留在分数说明和详情。额外修复已发布音轨的同源根路径被旧播放器拒绝的问题；入口、列表、音轨和会话恢复共用地址判定。
