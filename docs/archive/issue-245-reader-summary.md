# Issue #245：播客标签、导读筛选与回归用例

> 状态:归档（2026-11-03）。实现与用户目检已完成，用户明确授权提交代码和 PR；交叉检视进行中，未合入或上线。呈现规范已回流 `docs/frontend/conventions.md`。

## 已确认的呈现

- 保留「优质播客」，按后端全文评分判定；不根据导读有无推导优质。
- 没有导读不挂标签，不加「暂无中文导读」或「仅提供原节目」。
- 保留「中文导读 / 有声导读」文字：文字可读显示书本，音频可听显示耳机；两者都可用显示两个图标。读屏补充两种能力。
- 短摘要叫「AI 速读」，只有评分理由时叫「评分参考」。评分依据简写为「基于整期内容 / 仅基于节目简介」，内部处理与失败诊断留管理台。
- 有文字时，不因音频生成、重试或失败而撤掉可读提示；等待自动重试继续显示生成反馈并轮询，不能重新显示点播按钮让请求像消失了一样。
- 播客搜索展开后提供「全部 / 有中文导读 / 可听 / 可看」单选筛选。任一已发布导读命中「有中文导读」；只有原稿、摘要、口播稿、排队或失败均不算可用导读。
- 筛选与关键词、来源、订阅、收藏、未读相交，在数据库分页前生效；关闭搜索、切容器或来源清除筛选，空结果仍能取消筛选。桌面和手机共用查询与控件。

## 单元和 API 用例

| 编号 | 输入或操作 | 预期 |
|---|---|---|
| U01 | 无导读、排队、重试、失败、仅文字、文字+合成中、文字+失败、仅音频、双就绪、假完成，分别叠加优质/非优质 | 20 组真实列表组件渲染；徽标独立；图标与真实能力对应；空态无标签 |

| U03 | 有摘要、只有评分理由、无结果、普通文章 | 卡片标题与内容一致，普通文章不混入播客语义 |

| U05 | 三种导读筛选叠加搜索、来源、收藏、未读；切到文章 | 参数交集正确；文章请求不带播客筛选；筛选窗口成员变化触发整窗校准 |
| A01 | 55 期合成播客，已发布文字/音频、撤稿、没有评分/只有简介评分 | 三种查询结果与公开投影一致，优质判定不受导读状态影响 |
| A02 | 每页 7 条翻完整结果，关键词 both、指定来源、无匹配来源 | 总数、去重、分页和关键词交集正确 |

| A04 | 收藏为空、标读一条、元数据伪称导读就绪 | 收藏/未读仍有效；仅信已发布产物，不信任务状态或 URL 字符串 |

`e2e/podcast_reader.py` 接入正式 runner 的 `podcasts` 流程，播种在其它流程完成后执行，避免改变原有来源数量断言。使用新建 SQLite、迁移、真实 FastAPI、正式前端构建与已发布合成文字/静音 WAV。业务 API 不替换响应；游客默认来源的远程 favicon 使用本地空图，所有其它外部请求拒绝。无 LLM/ASR/TTS 配置或真实生成。

| E03 | 搜索栏依次选有中文导读、可听、可看 | 控件选中态、真实 API 参数、总数与结果一致 |
| E04 | 桌面筛选结果滚动越过 30 条 | 后续页仍保留筛选，无重复或漏项 |
