# 读者后台翻译与分段恢复（#202）

> **归档于 2026-10-21(文档整理波 issue #210)**:对应波次已落地;现状以 `docs/architecture/`、`AGENTS.md` 与代码为准,文中路径与状态为当时记录。


## 行为

阅读器桌面与手机端均提交持久任务，HTTP 立即返回；正文继续可读。展示已完成/总片段数、失败原因、继续与取消入口。换页仅停止查询，服务端继续执行；刷新或重新打开文章时按文章查询进度，不依赖浏览器内存。完整译文仍只在所有片段及标题通过检查后发布到文章缓存。

## 持久化与执行

新增本地 `translation_jobs`、`translation_chunks`、`translation_calls`，迁移 `b202a7e41c63` 与 SQLModel 同步，不参与 Archive Sync。任务身份包含文章 ID、来源、正文与标题指纹、简体中文目标、翻译版本、分段版本与长度、有效模型配置摘要（端点、模型、温度、输出上限、思考配置与凭据摘要；不保存明文凭据）。超时与并发配置可调整而不使已验证片段失效。

占位符命名空间取输入摘要，使同一计划重建后能验证旧片段。每段仅在既有 JSON 单元、公式/代码/链接、表格结构与数值校验通过后提交检查点；发布时再次校验全部片段，并在同一 SQLite 写事务中合并当前文章元数据、删除任务与检查点。原文、配置或权限变化，以及取消，都在发布前再次核对。

`lifespan` 在 reader/all 角色启动并收束 worker，2 秒查询一次，独立于采集调度。SQLite `BEGIN IMMEDIATE` 将入队去重、领取、预留、取消和发布串行化。全站一次持有一个任务租约，任务内部并发为模型配置值（1–8）；5 秒续租，租约至少 180 秒且覆盖模型超时。租约过期才能由另一个进程接管，旧持有者无法再预留或提交。正常退出取消本地在途协程，检查点保留；硬退出等租约到期后恢复。活着的旧持有者发现自身租约已过期时，在 token/status/expiry 围栏内返回 queued 自动恢复，不会把输入未变的任务误标 stale。

同一输入的并发请求共享任务，创建者承担调用用量且只有创建者可取消。失败/取消后，任何仍有该文章 AI 权限的用户可主动恢复，后续调用归恢复者。每个未完成片段自动最多尝试 3 次，次数持久化；手动继续只重置未完成片段的尝试次数。存量正文译文有效而缺译名时立即可读，任务只补标题；正文缓存摘要加入任务身份，防止执行中正文缓存被替换；标题缓存不加入身份，早报独立补写标题不使在途正文任务失效。标题分片布局按任务已保存的总数重建，尚未发起的标题分片可直接复用现有译名。已发布缓存只按原文指纹与翻译版本判定，不受模型配置或凭据轮换影响，不向文章扩展字段写入配置摘要。额度与权限类失败不自动循环重试。

## 成本与容量

每次真实模型调用前，在同一事务中检查每日翻译次数（50，按底层模型调用计，含标题；超过限额的长文需要隔天继续）和全站读者 token 预算，并创建一个调用预留；预留输入按完整提示 UTF-8 字节数 + 协议余量估算，输出按 max_tokens 预留。可能保守地提前暂停，已完成片段保留；缓存命中与纯字面量片段不占调用额度。客户端响应到达时，以本次调用专用 recorder 收集回执，在检查点写入前经线程执行原子计量与核销；finally 幂等兜底，不改全局 recorder、不双计。空响应或截断响应仍记录返回的用量。

明确的 4xx 拒绝（408 除外）释放预留；不可重试的拒绝会停止派发后续分片，429 有限重试。错误响应带 usage 时先核销，重试另建预留。无 usage 的 5xx、408、断连、超时、取消等结果不明请求保留当日保守预留，不伪称零成本；返回无 usage 的响应仍计一次调用。外部模型不提供幂等事务，本机可能在“服务端已生成、尚未提交检查点”的窗口崩溃，因此不能承诺这一窗口绝不重复付费。再次执行只跳过已落库且通过验证的片段。传输层自动重试设为 1，由任务层管理有限尝试；端点不支持 JSON/思考参数时的 400 兼容降级继续保留。

此处原子预留覆盖后台文章翻译。既有问答/速读/播客及兼容短文接口仍采用原有软准入（已计入这些翻译预留），不宣称整个应用所有 AI 用途形成统一硬预算。原 `/ai/translate` 保留短文同步兼容；超过 3500 字符时转后台响应。阅读器 UI 全部走新后台入口。

最多 500 个未完任务，每用户最多 3 个 queued/running 或已有检查点的暂停任务；加入他人正在运行的任务不占自己的名额。新任务需要名额时仅清理本用户最早的无有效租约的终态进度，并通过响应和页面提示；若 3 个任务都在运行则拒绝，保留全部在途任务。全局容量压力下先清理没有检查点的终态空任务。单篇正文 2 MB/1000 片段、检查点全局 64 MiB/每片 128 KiB。成功在发布事务内立即删除任务与片段，仅文章缓存保留最终译文；未更新且无有效租约的任务 7 天后清理，调用记录保留 30 天、聚合计量沿用既有留存策略。文章删除级联清任务与片段，调用计量保留。数据库页/WAL/备份体积不等于这些文本容量，未执行生产负载压测。

## 接口

- `POST /api/reader/ai/translation-jobs`：`{article_id}`；缓存 200，否则返回 202 与任务快照。
- `GET /api/reader/ai/translation-jobs?article_id=...`：只查进度/缓存，绝不创建任务。
- `POST /api/reader/ai/translation-jobs/{id}/resume`：显式恢复；输入变化 409，需重新发起。
- `POST /api/reader/ai/translation-jobs/{id}/cancel`：创建者取消，AI 总闸关闭后仍可取消。

快照只含任务 ID、文章 ID、状态、完成/总数、脱敏错误和当前用户可用操作，不向其他读者显示创建者或用量详情。每次读取、恢复、实际模型调用和发布重新检查账号启用/AI 门控、隐藏来源、私有订阅与外送政策。
