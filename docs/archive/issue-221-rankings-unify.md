## 1. 三段的分工(2026-11-03 拍板)

| | 回答的问题 | 时间窗 | 单位 | 排序依据 | 与个人订阅 |
|---|---|---|---|---|---|

用户问「读者真的需要这么多榜单吗」后,把读者面 13 个列表(文章榜 / 播客榜各 6 个:话题 / 产业 / 实体三轴表、标签详情(高分内容 + 30 日趋势)、全局高分榜、必读 / 必听;加热点 1 个)收成 3 个:

- **深度阅读**:近 7 天论文 / 教程 / 观点 / 汇编按内容价值前 10(门槛 7.0,与早报同名分区同口径,拍板 11),同事件只留一篇,热点事件榜里已有的事件不出现。原「必读」与标签高分内容改口径后并入。

- **撤出读者面**:三轴标签表与 30 日趋势(不留风向签);榜单快照与接口保留,去处另议。**取消**:全局高分榜(文章 / 播客)。
- 页内组织:同页分段;手机页头标题即转盘(热点事件 · 深度阅读 · 播客精选),没有第二个「榜单」标题(#230 审计 M-21);桌面源栏轨底一个「榜单」入口,副标题随段变化〔2026-11-04 目检改为:入口挪到视图轨、排在「发现」之前,见 §4 第 12 项⑩〕。

- 分段 **热点 · 文章 · 播客**;文章段 = 「近 7 天值得读」:按新闻价值取前 10、同事件只留一篇(卡上写「另 N 家报道」);播客段同理「近 7 天值得听」。

### 方向 C「一页总览」——不分段

- 一页从上到下:热点前 5 件 → 本周好文前 5 → 话题风向(三轴各前 5,只列升降)→ 本周好听前 3;每块「全部 →」进入该块的完整列表(列表即方向 B 的段)。
- 桌面双栏:左栏热点 + 好文,右栏风向 + 好听;手机按顺序堆叠。
- 适合「打开榜单先扫一眼全貌」;代价是页面长、每块只露一部分。

## 3. 共用卡片语法(三段同一套)

- **名次列**:宋体齐线数字(与手机榜单、早报同一种身份线),变化写在下方(↑2 绿 / ↓1 红 / 「新」签 / 「进榜」),没有对比数据时留空。
- **主体**:标题(两行内)→ 一行摘要或代表内容 → 一行元信息(最新一篇 / 来源 / 时间)。
- **右栏**:一个带单位的度量(N 家报道 / N 次出现 / 评分),上方叠来源徽标。
- **详情**:桌面右侧抽屉、手机底部层(#230 层原语);事件 = 代表报道 + 按发布主体分组的来源 + 报道时间线 + 最新进展(+ 接前报,待定)〔2026-11-04 目检改为:桌面原地事件页;代表报道 → 最新进展卡 → 时间线,来源节取消,见 §4 第 12 项〕;标签 = 30 日趋势 + 高分内容;文章 / 单集直接进阅读窗。
- 空态与薄榜:空榜一句话(「近 48 小时还没有被两家以上报道的事件」);只有 3 件时不补位、不拉伸。
