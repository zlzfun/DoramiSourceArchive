# 兴趣即透镜波(issue #27 第一波,v3.51.0)

> 状态:**已实现**(2026-09-09)。本文是方案与决策记录;样页 `docs/design/dorami-interest-lens-quiet.html`
> (四稿,含三次被否方案的注记)。后续波次的候选见文末「明确不做 / 后续」。

## 题

v3.47(#23)把「我的兴趣」做成了整幅页面,但消费方仍只有个人早报选篇一处——一整页只承载一份
「关注 / 屏蔽」开关清单,页面分量与它能产生的效果不成比例。issue #27 立项把兴趣接到更多消费方。

## 设计过程与拍板(2026-09-09,同日完成)

| 稿 | 方案 | 结论 |
|---|---|---|
| 一稿 | 兴趣页做成「关注动态(篇数 + 热度折线)+ 主题流」的阅读面 | **否**。①篇数不是明智方向——数字催人比较、又依赖分析覆盖率并不可靠(与撤源栏未读数字、社交流不展示互动数同一取向);②兴趣页混读各形态,重犯「今日」混合流被取缔的错(标签几乎只落在文章上,动态零星、社交为零) |
| 二稿 | 兴趣是透镜不是地方:源栏加「兴趣」组列标签,发现页第三段承接编辑面 | 部分采纳。标签混进来源清单让「我的订阅」栏头名不副实;拆「兴趣 / 我的订阅」两节只是转移别扭 |
| 三稿 | 源栏「只看关注」与「全部 / 只看收藏」并列 + 作用域推翻(阅读器 = 订阅 ∪ 关注) | 宏观讨论后**不做隐式并集**:并集让「文章为什么出现」有两个隐式解释;兴趣先做透镜,渠道等数据 |
| 四稿 | **左栏 = 过滤面板,三谓词多选联合**(用户 idea) | **采纳**,见下 |

宏观拍板(是否值得引入兴趣维度):作为透镜是好设计——可完全忽略,零认知税;作为进货渠道有保留——
用户对「为什么这篇出现」需要两个解释,系统每个既有概念都要多答一道「兴趣管不管这里」的永久税。
关注对象以**实体**为主更自然(「跟 DeepSeek」比「关注 AI 智能体」);上线后看数据(设兴趣的用户占比 /
兴趣开关使用 / 早报兴趣命中率)再决定要不要更多。

口径:维度 / 开关 / 列头 / 发现页段名统一叫**「兴趣」**;兴趣页里对单个标签的动作仍叫关注 / 屏蔽。

## 模型

- **左栏是过滤面板**。标题 = 容器名(文章 / 播客 / 动态 / 社交媒体);栏里只有一种东西——过滤条件:
  三枚可多选开关 **订阅 / 兴趣 / 收藏**(按源 / 按标签 / 按篇,两两正交,AND 联合),其下「来源」=
  已订阅源分组,是第四个轴,与三谓词联合。选中态 = wash 底 + 勾(多选语义),与单选源行的
  浮白 + 弱高程分家。
- **三者全关 = 全站可见源**(隐藏源与私有自定源照旧排除)。**初始状态订阅开着**,按用户按容器记住
  (localStorage `dorami-reader-scope:{user}:{mode}`)——日常体验与今天的「全部文章」同义,
  关掉订阅是显式动作,全站在原地展开(发现页「预览」顺势归位)。
- **源栏只列已订阅源**,不列全站(否则成第二个发现页)。点未订源(发现页预览 / 深链)时订阅谓词**临时**
  关掉不落盘(「订阅 ∧ 未订源」是空集),离开该源即恢复记住的状态;停在未订源上开「订阅」= 回到聚合。
- **列头回显激活集**是模型的安全网:标题 = 激活谓词「订阅 · 兴趣」(顺序固定,不按点击先后);
  全关 = 「全部」+ faint「全站」;被源收窄时标题 = 源名,副文案 = 其余谓词。
- **屏蔽不是开关,是全局透镜**:任何组合都生效,条目折成「已屏蔽 · 机器人技术、具身智能 · 展开」一行
  (写屏蔽了什么,不写几篇),点开就地摊开(条目降调)。早报的硬排除口径不变。
- **命中胶囊也是透镜**:顶行源名后一枚 accent wash 小胶囊,只写命中的那个兴趣标签,与开关无关;
  与分析主签同名时顶替它。未打标条目零变化——「未知」不是「不命中」。
- **订阅外文章直接出现**(订阅关着时):源名后 faint「未订阅」,悬停翻「+ 订阅」;阅读窗眉头挂
  「+ 订阅 源名」胶囊。桥自行消解,发现页标签卡的「主要来源」脚部降为可选(本波未做)。
- **兴趣的编辑面并入发现页第三段**「源 · 合集 · 兴趣」:挑源、挑合集、挑标签都是「挑」,同一个目录页;
  读东西全在容器;早报是唯一的「我的」页。视图轨撤掉「兴趣」钮。首登引导 = 发现页兴趣段顶部一条横幅
  (不锁页),完成即落早报;发现钮挂点直到完成或跳过。兴趣页卡片脚部的篇数撤除。
- **未读**仍是 seg(读态不是范围);订阅关着时订阅外的源没有水位,按逐篇读态判定(没读过即未读)。
- **交付面不动**:早报冻结订阅源 + 兴趣标签;feed / MCP 仍是订阅域。

## 实现

- 后端 `services/reader_interests.py`:`interest_filter_condition`(兴趣谓词,exists 子查询)/
  `favorite_filter_condition` / `annotate_interest`(逐条 `interest_hits` / `interest_muted`);
  `GET /api/articles` 加 `interest_scope` / `favorite_scope`(off|only)与 `with_interest`,谓词成对进
  query / count_query;`reader_state.unread_filter_condition(include_uncursored=True)` 让全站范围的
  未读按逐篇读态判定。**准入门槛** `INTEREST_MATCH_MIN_RELEVANCE = 0.8`:兴趣谓词与命中胶囊只认
  主标签或相关度 ≥ 0.8 的指派(它决定全站范围内「放什么进来」;开发库分布 ≥0.8 占六成,主标签每篇恰一个);
  屏蔽相反,任一指派即算命中。
- 前端 `hooks/useReaderState.js`:`scope`(三谓词)顶替 `favOnly` 成为作用域维度,`buildListFilters`
  是列表首拉与分析轮询共用的单一拼装点;`listTitle` / `listSubtitle` 回显;`toggleScope` / `applyMode`
  (切容器同批读回记住的面板)/ `refreshInterests`;`favOnly` 保留为 `scope.favorite` 别名给
  SocialFlow 等消费方。`utils/listPlan.js` 把命中屏蔽的条目按日期组折进组尾一行。
  `ReaderTab`:`ScopeToggles`(桌面源栏与移动抽屉共用)/ `MutedFoldRow` / 条目 `interestHit`
  `unsubscribed` `muted` 三 prop / 阅读窗 `.reader-pane-sub`;`DiscoverPage` 段位受控 + `interestsPanel`;
  `InterestPage` `embedded` 变体(横幅 + 我的关注 chip 行 + 三面目录)。
- 测试 `tests/test_reader_interests.py` 5 项(谓词组合 / 无兴趣显式空集 / 收藏与 total 成对 /
  命中与屏蔽标注 / 全站未读逐篇读态);`test_reader_unread` 一条对齐新口径。隔离栈 Playwright
  桌面 + 移动两路径,pageerror=0。

## 明确不做 / 后续

- 列头下的**标签 chip 行**(逐标签收窄):2026-09-09 拍板暂缓,按兴趣的进一步设计后续独立考虑。
- 发现页标签卡脚部**「主要来源」**(不带数字的桥):作用域可关掉订阅之后它是可选项,留待拍板。
- 兴趣渠道**准入门槛**(是否再加新闻价值分下限)、**早报兴趣半取全站**、**feed / MCP 屏蔽**(改交付契约)、
  **问答先验**、**隐式建议关注**(从阅读 / 收藏反推,只建议不落库):均为后续候选,先看数据。
- 收藏不再按收藏时间另排(三谓词面板下列表统一按到货序);原 `GET /api/reader/favorites` 端点保留。
