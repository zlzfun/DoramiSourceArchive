# 管理面:用户明细仅根管理员可见 + 账户增长曲线(issue #31,v3.55.0)

> 状态:**已落地**(2026-09-14)。上接 v3.19 多管理员平权与 v3.41 账户管理 V2;
> 负责人 2026-09-14 收窄范围为两点:①精确到个人用户的信息只有 admin 能接触(隐私);②用户量从一个数字改成增长曲线。
> issue 原文的「关键节点标注」「其它指标对齐」本波不做,记 backlog。

## 0. 问题

- 运维管理 → 用户 子页的账户名单、逐账户设置/启停/改角色、单用户活动抽屉、活跃用户榜、AI 用量「按用户」维度,
  任何 admin 账号都能看能改。上量到 150 人后这些是读者隐私,不该对每个运营管理员敞开。
- 用户量只有「账户 N」一个数字,`users.created_at` 从未被消费,看不出增长。

## 1. 拍板:根管理员

**多管理员平权(v3.19)之上唯一的例外**:用户级明细只有「根管理员」可见可操作,其它 admin 只见聚合数字。

- **判据**(`accounts.root_admin_username`):活跃管理员里名为 `admin`(首启播种的根管理员)者;
  若该账户不存在或已不是活跃管理员(本版之前的库可能已把它删除/降级),**回落为创建最早的活跃管理员**。
  一条索引查询,任何库都恰有一名根管理员,用户级明细面永不失联。不设权限列、不做迁移——负责人拍板「仅 admin」的
  最简形态;将来要转让/多根,再升级成账户列,判据入口只有这一处。
- **守卫**(`_guard_root_admin`):根管理员不可降级/停用/删除(单账户与批量两条路,批量拒绝是原子的),
  先于末位活跃管理员保护命中。根管理员在时末位保护实际不会触发(它恒是一名活跃管理员),该保护保留给没有
  `admin` 用户的库。
- **门控**(`app.root_admin_required`,中间件,与 `account_admin_required` 同层):`/api/accounts/*`(账户名单与逐账户管理)
  与 `/api/admin/accounts/*`(运维账户列表 + 单用户活动抽屉)非根管理员一律 403「仅限根管理员」。
  按会话**剥字段**而非整体拒绝的两处:`/api/admin/ai-usage` 的 `by_user`/`by_day_user` 置空(总量与按用途照常),
  `/api/admin/overview` 的 `recent_logins` 置空。
- **能力位**:`/api/runtime` 透出 `root_admin`;前端 `AdminOpsTab` 据此:非根管理员的用户子页只渲染
  四格聚合 KPI(账户/管理员/读者/停用,取自增长端点)+ 账户增长 + 操作审计;账户表、新建账户、活跃榜、
  活动抽屉整块不渲染,不发 `/api/admin/accounts` 请求;AI 子页的两张用量图只留「按用途」档。

### 有意保留给全体管理员的面(不属读者隐私)

- **操作审计**:记录的是管理员的管理写操作,v3.19 设它的目的就是管理员互查。
- **反馈收件箱**(带提交者名):是工单面,处理反馈需要知道是谁提的。
- **用户自定源治理**的「创建者」列:溯源用,且源本身是读者主动登记到平台的资产。
- **内容看板**各源收藏/订阅排行:按源聚合,不含用户名。

## 2. 账户增长曲线

- 端点 `GET /api/admin/account-growth`(全体管理员):`{totals:{accounts,admins,readers,disabled}, series:[{day,new}]}`,
  SQL 端 `GROUP BY substr(created_at,1,10)`,行数与账户数同阶。**口径 = 现存账户**:已删除账户不在 `users` 表里,
  曲线画的是「今天还在的账户何时加入」,不是历史开户总数(删号有审计日志)。
- 前端 `components/admin/AccountGrowth.jsx`:两张单系列图并列——累计账户(面积)与新增账户(柱)。
  两个量级差一个数量级,合画一张要么双轴(dataviz 禁)要么柱被压平。粒度 seg 日/周/月:
  日 = 近 30 天、周 = 近 26 周(周一起)、月 = 自首个账户起;桶在前端折算(含空桶),累计从全量序列前缀和推出,
  视野之前的账户算进起点,末端恒等于现存总数。区头 hint「近 30 天 · 新增 N」。品牌主色单系列、无图例、
  hover 浮层沿 `ThemedTooltip` 视觉。
- 放在用户子页 KPI 条之下、活跃榜之上,两种管理员都看得到;随子页刷新时机(M15)重取。
