## 陷阱档案(自自动记忆沉淀,2026-10-21)

- **滚动窗 + 固定日期 = 时间炸弹**:凡断言依赖 `now()-N 天` 的窗口,造数据一律用相对时间(`now-1d` / `now-45d`);2026-09-22 `test_taxonomy_ledger_unifies_tags_and_candidates` 写死 2026-09-14,日历翻过后整仓 CI 全红(PR #135 热修)。CI 忽然红且失败用例与改动无关时,先在 main 上跑同一条用例判是不是时间炸弹。
- **fake-ip 代理掩盖 DNS 依赖**:开发机代理把一切域名解析到 198.18.0.0/15(SSRF 守卫豁免段),`demo.test` 之类占位域名本机恒过、GitHub runner 解析失败即 `SSRFError`。涉及 `ensure_public_host` / `_resolve_host_ips` 的用例一律打桩;本地全绿 ≠ CI 全绿。
- **不依赖 git 历史深度**:`actions/checkout` 默认浅克隆,`git show <老提交>:<路径>` 在 CI 取不到;历史版本固化为 `tests/fixtures/` 文件(如 `deploy_scripts_pre_issue_*`),别用 `fetch-depth: 0` 掩盖。
- **测试命令不走管道**:`pytest … | tail` 会吞退出码(zsh 用 `$pipestatus[1]`);一律 `cmd > log 2>&1; rc=$?` 再判,PR #37 / #80 都曾因此带红用例推送。
- **xdist 下沙箱按 worker 分开**:`tests/conftest.py` 以 `DORAMI_TEST_SANDBOX=1` 标记自铸沙箱,worker 见标记即另铸;新测试不写固定路径、不绑固定端口、不依赖执行顺序。
- **E2E 基线**:`scripts/check_mobile_reader_e2e.py` 支持 `--flows mobile,pwa,focus` 子集;`mobile` 流程曾在干净 `origin/main` 上就失败(`net::ERR_ABORTED`,2026-09-16),把它当成自己分支的回归前先跑基线。新守卫要做一次反向对照证明它会咬人。
- **守卫类测试收进突变脚本**:写「守卫」(如 `tests/test_ci_workflow.py`)时把检视方用来证明首版守卫放行的突变(挪 `always()`、换 echo、glob 改 `--ignore`、追加 `-n 0`)直接收进仓库当反向对照。
