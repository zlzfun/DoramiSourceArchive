## 本地跑什么、CI 跑什么(issue #288,2026-11-16)

- **本地**:受影响的测试文件 + 快守卫(`scripts/check_docs.py`;改 `ci.yml` 时 `tests/test_ci_workflow.py` `tests/test_ci_scope.py`)。全量交给 CI 跑一次,不在推送前本地再跑一遍。例外:改部署脚本 / 迁移 → 本地跑 deploy 侧(bash 3.2 只有 macOS 本机测得到);改公共夹具、`conftest.py`、`models/db.py` 这类说不清影响面的 → 本地先跑全量(本机约 3.5 分钟,比 CI 红一次的往返便宜)。
- **CI 按改动面选 job**:`changes` job 跑 `scripts/ci_scope.py`。PR 的**全部**改动路径都在 `frontend/` `docs/` `docs-site/` 与仓根 `*.md` 之内 → 跳过 `backend-unit` / `backend-deploy`,只跑 `backend-light`(`ci_scope.LIGHT_TESTS`);其余、看不准、push 到 main → 全量。汇总门 `backend (pytest)` 只在判定成功且明确 `backend=false` 时接受重型 job 的 skipped。
- **后端测试读 `frontend/` `docs/` `docs-site/` 或仓根 `*.md` 的,必须登记**:把所在测试文件加进 `scripts/ci_scope.py` 的 `LIGHT_TESTS`,并同步 `ci.yml` 里 `backend-light` 的命令(`tests/test_ci_workflow.py` 比对两者逐字一致)。不登记的话,纯前端 / 纯文档 PR 不会运行它。这条由 `tests/conftest.py` 的**读取审计**强制:进程级审计钩子记下落在这些路径上的 `open` / `listdir` / `scandir`,所在测试文件不在 `LIGHT_TESTS` 里就把那一阶段判失败(模块顶层的读取判收集失败)。审计看不见子进程里的读取——用例起脚本去读真实仓的这些路径时同样要登记。给白名单加目录之前,先证明没有后端测试读它。
- **CI 分片(issue #289)**:`backend-unit` 拆 3 片、`backend-deploy` 拆 2 片,各占一台 runner 并行,命令只差 `--shard I/N`。`tests/conftest.py` 按**用例函数 nodeid 的 CRC32** 定片——纯函数,每条用例恰好落在一片里;同一个测试函数的全部参数化落在同一片。片数写在 `ci.yml` 的两处——矩阵 `shard: [1, …, N]` 与命令分母 `/N`,`tests/test_ci_workflow.py` 守「矩阵恰是 1..N、分母等于 N、分子必须是矩阵变量、strategy 块只有受控的三行」(少一片 = 那一片的用例谁都不跑而 CI 仍绿);调整片数只改这两处,测试不用跟着改。检查分片的用例自己不能只待在被分片的 job 里,所以 `tests/test_ci_workflow.py` 与 `tests/test_ci_scope.py`(`ci_scope.GUARD_TESTS`)另由不分片的 `backend-guards` job 单独跑一遍。写新测试不需要做任何事,只是别依赖「同文件的另一条用例先跑过」——分片后它们可能不在同一个 job 里(xdist 下本来也不保证)。本地复现某一片:在全量命令后加 `--shard 2/3`。
- **断言日志用 `captured_log` 夹具,不用 `caplog`**(issue #318):`with captured_log("dorami.xxx") as records`,它把收集器直接挂在目标记录器上。`caplog` 挂在根记录器上,`dorami.*` 不向根传播;更隐蔽的是 alembic 的 `fileConfig` 会把当时已存在的记录器一律置为 `disabled`——同一进程里只要前面有用例跑过迁移,后面的日志断言就一条记录都看不到,结果取决于用例顺序与分片(本地全绿、CI 某一片红)。
- **测试里的密码哈希是 1000 轮**(issue #289):会话夹具 `fast_password_hashing` 把 PBKDF2 缺省轮数从生产的 20 万调低(一轮 unit 要哈希 / 校验约 2400 次);要测真轮数的用例显式传 `iterations=`。夹具同时断言生产常量不低于 20 万。

`pyproject.toml` does not configure pytest, so discovery uses pytest defaults; pass an explicit path/`-k` filter when targeting a subset.

## 陷阱档案(自自动记忆沉淀,2026-10-21)

- **滚动窗 + 固定日期 = 时间炸弹**:凡断言依赖 `now()-N 天` 的窗口,造数据一律用相对时间(`now-1d` / `now-45d`);2026-09-22 `test_taxonomy_ledger_unifies_tags_and_candidates` 写死 2026-09-14,日历翻过后整仓 CI 全红(PR #135 热修)。CI 忽然红且失败用例与改动无关时,先在 main 上跑同一条用例判是不是时间炸弹。
- **fake-ip 代理掩盖 DNS 依赖**:开发机代理把一切域名解析到 198.18.0.0/15(SSRF 守卫豁免段),`demo.test` 之类占位域名本机恒过、GitHub runner 解析失败即 `SSRFError`。涉及 `ensure_public_host` / `_resolve_host_ips` 的用例一律打桩;本地全绿 ≠ CI 全绿。
- **不依赖 git 历史深度**:`actions/checkout` 默认浅克隆,`git show <老提交>:<路径>` 在 CI 取不到;历史版本固化为 `tests/fixtures/` 文件(如 `deploy_scripts_pre_issue_*`),别用 `fetch-depth: 0` 掩盖。
- **测试命令不走管道**:`pytest … | tail` 会吞退出码(zsh 用 `$pipestatus[1]`);一律 `cmd > log 2>&1; rc=$?` 再判,PR #37 / #80 都曾因此带红用例推送。
- **xdist 下沙箱按 worker 分开**:`tests/conftest.py` 以 `DORAMI_TEST_SANDBOX=1` 标记自铸沙箱,worker 见标记即另铸;新测试不写固定路径、不绑固定端口、不依赖执行顺序。
- **E2E 基线**:`scripts/check_mobile_reader_e2e.py` 支持 `--flows mobile,pwa,focus` 子集;`mobile` 流程曾在干净 `origin/main` 上就失败(`net::ERR_ABORTED`,2026-09-16),把它当成自己分支的回归前先跑基线。新守卫要做一次反向对照证明它会咬人。
- **守卫类测试收进突变脚本**:写「守卫」(如 `tests/test_ci_workflow.py`)时把检视方用来证明首版守卫放行的突变(挪 `always()`、换 echo、glob 改 `--ignore`、追加 `-n 0`)直接收进仓库当反向对照。
- **进程时序用例不用固定 sleep 对齐**(issue #203,2026-11-09):`test_launcher_final_rc_comes_from_the_same_snapshot` 曾让假 worker 在写出本轮快照 0.3 s 后覆写,launcher 在 CI runner 上的进程起动 + python3 冷启动常错过窗口(rc=5 / rc=6 两种形态)。改为**读取触发**:被测脚本经 PATH 读文件的,前置一个解释器垫片,在那一次读取返回后再改状态——「前 / 后」成为确定事件;并收进两条「恢复旧错误必败」的反向对照([方案](../archive/issue-203-launcher-snapshot-test.md))。
- **预算 / 超时类用例:预算窗口里不留真实读写**(issue #339,2026-11-25):早报标题翻译的 `test_budget_timeout_falls_back_without_blocking`(0.3 s 预算内要走完三次 SQLite 写事务)与图片解读的 `test_budget_exhaustion_returns_cache_and_finishes_in_background`(0.5 s 截止前要取完图)在 CI 上偶发失败——4 个 xdist worker 抢盘时读写慢一个数量级,「该在预算内完成的那一半」就被判成超时。写这类用例:① 该完成的那一半要么不让出事件循环(发布 / 落库换成直接返回的替身),要么把读写挪到预算开始之前;② 该超时的那一半等一个事件,或睡一个只在预算失效时才会等满的上限,不靠 sleep 时长卡位,也不断言墙上时钟;③ 走真实读写的那条只断言不随取消落点变化的结果;④ 往读写里注入延迟跑一遍,结果不该变。调大预算不算修([方案](../archive/issue-339-budget-tests-deterministic.md))。
