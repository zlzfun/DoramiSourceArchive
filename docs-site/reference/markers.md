# 界面标记速查

在界面上看到一个标记不知道什么意思，在这里查。按出现的位置分组。

## 早报里

| 标记 | 意思 |
|---|---|
| 重大事件 · 官方一手 | 官方发布的重要消息，不管你订没订阅这个来源都会放进早报，排在最前 |
| 重大事件 · N 家来源 | 多家来源同时报道的重要事件，同样不看订阅 |
| 兴趣 · 某标签 | 因为命中你关注的这个兴趣而入选 |
| 新闻价值入选 | 因为新闻价值分高而入选 |
| 最新更新 | 当天够分的内容不多，这篇是你订阅来源的最新内容，不算正式精选 |
| 未订阅 | 这篇来自你还没订阅的来源（因重大事件或兴趣入选）。鼠标移上去变成「+ 订阅」，点一下订阅 |
| 降级生成 | 当天够分的内容不够，这版早报用最新更新补齐 |
| 部分来源更新尚未完成，按当时已有内容编排 | 编排时还有来源没更新完，点「重新编排」可以按最新情况重编 |
| 部分文章分析尚未完成，按当时已有内容编排 | 编排时还有文章没分析完，点「重新编排」可以按最新情况重编 |
| 部分来源更新和文章分析尚未完成，按当时已有内容编排 | 以上两种情况同时存在 |
| 你的兴趣已更新，下次编排生效 | 你改了兴趣，今天这版还是旧的，点「立即重编」马上生效 |
| 你的订阅已更新，下次编排生效 | 你改了订阅，同上 |
| 你的兴趣和订阅已更新，下次编排生效 | 兴趣和订阅都改了，同上 |
| 共 N 版 | 今天的早报重编过，点开可以看之前的版本 |

详见[读每天的早报](/features/brief)。

## 文章列表和阅读窗里

| 标记 | 意思 |
|---|---|
| 标题左侧的小蓝点 | 未读 |
| 右侧的星标 | 已收藏 |
| 数字（如 7.2） | 新闻价值分，满分 10。分数越高颜色越鲜明，6 分以下显示为灰色 |
| 分析中 / 正在分析 | AI 还在分析这篇，分数和速读稍后出现 |
| 更新中 | AI 正在重新分析这篇，先显示上一次的结果 |
| 模型发布、产品更新、开源动态、学术论文、教程、观点、行业资讯、技术大会、社交讨论、资讯聚合、安全事件、监管政策 | 文章的体裁 |
| 其他标签（如「AI 智能体」） | 文章的主题，点兴趣时用的也是这些标签 |
| 阅读量 N | 这篇文章在站内被打开的次数 |
| + 订阅 | 这篇来自你还没订阅的来源，点一下订阅 |

## 来源栏和发现页里

| 标记 | 意思 |
|---|---|
| 预览 | 你正在看一个还没订阅的来源，订阅后这个标记消失 |
| 暂不可用 | 这个来源暂时不可用，内容暂停显示。订阅会保留，恢复后内容自动回来；也可以直接退订 |
| 自定源 | 你自己添加的 RSS 源，只有你能看到 |
| 已订阅 | 你已经订阅了这个来源或合集 |

## 播客里

| 标记 | 意思 |
|---|---|
| 仅提供原节目 | 这一期只有原版音频，没有中文导读 |
| 中文导读已生成 | 有 AI 整理的中文导读文章 |
| 精品导读音频已就绪 | 有可以收听的中文导读音频 |
| 优质播客 | 这一期的新闻价值分较高 |
| 简介导读 / 全文导读 | AI 速读是根据节目简介还是整期内容写的 |

详见[听播客](/features/podcasts)。

## 榜单里

| 标记 | 意思 |
|---|---|
| 新 | 这个标签本期新上榜 |
| 持平 | 排名和上期一样 |
| ↑ N / ↓ N | 排名比上期上升或下降了 N 位 |

## 翻译和问答

| 标记 | 意思 |
|---|---|
| 原语言 / 译为中文 | 外文文章标题下方的切换，选「译为中文」看中文译文 |
| 翻译中… | 正在翻译，稍等即可 |
| [1]、[2] | 哆啦美回答里的引用编号，点一下打开对应的文章 |

详见[问哆啦美与翻译](/features/ask-and-translate)。
