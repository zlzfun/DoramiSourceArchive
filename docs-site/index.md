## 它能做什么

![阅读器：左侧订阅源，中间条目列，右侧带 AI 速读的阅读窗](../docs/assets/readme/02-reader.png)

### 每天一份属于你的早报

哆啦美每天早上从你订阅的来源和关注的兴趣里挑出当天最值得读的内容，按「重大事件 / 模型发布 / 行业资讯 / 开源动态……」分板块排版。每张卡片带一个**新闻价值分**和一句「为什么重要」。全站范围的头条大事会作为「重大事件」置顶，即使它不在你的订阅里。

![个人早报页](../docs/assets/readme/01-brief.png)

### 一个安静的阅读器

- **订阅制**：左栏是你的订阅源，按官方 / 媒体 / 个人 / 榜单分组。文章、动态（更新日志、发布说明）、社交（X 推文）、播客形态不同，各放一个容器，不混排。
- **兴趣是一面透镜**：左栏可以切到「兴趣」轴，按你关注的主题、行业、公司横切全站内容，不受订阅范围限制。
- **常用动作齐全**：未读、收藏、标读、右键菜单、站内深链与公开分享链接；手机上每个动作都有对应的长按动作单。
- **AI 速读**：配上大模型并打开文章分析后，每篇文章带新闻价值分、一段摘要和一句评分依据。

### 问哆啦美

在阅读窗打开问答面板，可以只问当前这篇，也可以问「我的订阅」。哆啦美先规划检索、在全文索引里找出相关文章，再给出带编号引用的回答，引用可一键跳回原文。文章页还能一键译成中文。

![问答面板：回答带编号引用，引用列表可跳转原文](../docs/assets/readme/04-ask.png)

### 发现来源

发现页是全站来源目录：按角色分组，显示订阅人数与最近更新，可以一键订阅或先预览。策展合集可以整组订阅；也可以贴一个 RSS 地址，添加只有自己可见的私有来源。

![发现页：来源目录与一键订阅](../docs/assets/readme/03-discover.png)

### 手机上直接打开

同一个地址在手机浏览器或微信里打开就是移动版阅读器：底部四个 Tab、全屏正文页、长按动作单。不需要装 App。

<img src="../docs/assets/readme/05-mobile.png" alt="移动端正文页" width="360">

## 内容从哪里来

- **内置来源**：官方博客、工具与平台的更新日志、中英文科技媒体、个人博客、论文与开源榜单、X 账号时间线，以及一批精选播客。每个来源都经过采集器适配和正文质检，入库的是干净的 Markdown 正文。
- **入库即分析**：配上大模型并打开文章分析后，文章落盘即由后台任务用大模型打新闻价值分、写摘要，并按受治理的标签目录（主题 / 行业 / 实体）打标。配图可交给视觉模型识别成文字，一并用于摘要和问答。
- **公共 AI 日报**：管理员可以按计划生成全站视角的每日日报，用同一把评分尺子。
- **对外交付**：普通读者（`user`）各有一个聚合 Feed 令牌，用 JSON 或 Markdown 拉取自己订阅范围内的内容；同一范围也通过 MCP 提供给 Claude、IM 机器人等 Agent。

## 两种角色

- **读者**（`user`）：只有阅读器这一个界面，订阅、阅读、早报、问答、接入集成都在里面。
- **管理员**（`admin`）：另有一个管理台，管采集节点、采集任务、知识台账、AI 日报、运维看板、账户与公告；管理员同时也是读者，可一键切进阅读器。

想知道为什么这样分、数据怎么流，见[设计理念](/design/overview)；想在本机跑起来，见[快速开始](/guide/quick-start)。
