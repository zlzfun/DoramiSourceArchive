# 快速开始

五步，从登录到读完第一份早报。

## 1. 登录你的账号

哆啦美不提供自助注册，账号由你所用站点的管理员发放。拿到账号和密码后：

1. 在浏览器里打开站点网址。
2. 开场画面上按任意键，或点一下屏幕。
3. 在「欢迎回来」卡片里填入账号和密码，点「登录」。

<p align="center"><img src="./images/login.png" alt="登录卡片：标题「欢迎回来」，下面是账号、密码两个输入框和「登录」按钮" width="420"></p>

**你会看到**：第一屏就是「我的早报」。新账号已经预先订阅了一批常用来源，所以一进来就有内容。顶部有一条欢迎提示，先不用管它，第 3 步会用到。

![早报页顶部的欢迎提示：「这是你的第一份早报。设置兴趣，早报会更懂你。」右侧是「稍后再说」和「设置兴趣」](./images/welcome-banner.png)

## 2. 订阅想看的来源 {#subscribe}

早报只从你订阅的来源里选稿（重大事件和兴趣命中的内容除外，见[读每天的早报](/features/brief#why)）。先去挑几个你想看的：

1. 点左侧竖栏的「发现」（指南针图标）。
2. 在顶部选「源」页签。右侧可以按「全部 / 文章 / 动态 / 社交 / 播客」筛选，也可以在搜索框里输入名称。
3. 在想看的来源卡片上点「订阅」。

**你会看到**：按钮变成「已订阅」，页面底部提示「已订阅 …」，这个来源出现在左栏里。点错了，把鼠标移到「已订阅」上，它会变成「取消订阅」。

![发现页的「源」页签：每张来源卡片有简介和订阅人数，已订阅的显示「已订阅」，其余显示「订阅」](./images/discover-sources.png)

不确定要不要订？点卡片上的「预览」先看它最近收录的内容。想一次订一组，切到「合集」页签，按主题整组订阅。

## 3. 选几个感兴趣的方向

兴趣决定早报优先给你看什么。兴趣命中的文章即使来自你没订阅的来源，也可能进入早报。

1. 回到早报页，点顶部提示里的「设置兴趣」。也可以从「发现」进入，选「兴趣」页签。
2. 页面按「主题」「行业」「实体」列出标签，「实体」指具体的公司、产品和模型，例如 Anthropic、ChatGPT。点一个标签，它就加入上方的「我的兴趣」；再点一次就取消。
3. 选好后点「完成」。

**你会看到**：选中的标签带紫色边框，同时出现在「我的兴趣」一行里，右侧显示「已保存」（改动会自动保存）。

![兴趣页：「我的兴趣」一行里有「AI 智能体」「AI 编程」两个标签，右侧显示「已保存」；下方对应的两张标签卡片带紫色边框](./images/pick-interests.png)

第一次点「完成」后会回到早报页，今天这一版随即按你的兴趣重新编排：提示「早报正在按你的兴趣重新编排」时稍等片刻，提示「早报已按你的兴趣重新编排」就是排好了。暂时不想选，就点「稍后再说」，以后随时可以回来设置。

## 4. 读今天的早报

点左侧竖栏最上面的「早报」回到早报页。

- 报头写着日期、这是今天的第几版，以及这一版有几篇、来自几个来源；有文章命中你的兴趣时，也会写出篇数。
- 报头下方的「哆啦美」一行说明这一版是怎么选出来的，右端的「调整兴趣」可以随时改兴趣（还没设置兴趣时，这里叫「设置兴趣」）。
- 下面按板块排着卡片。卡片右上角的数字是新闻价值分，分数高的卡片通常占更大的版面。
- 点任意一张卡片，就在阅读器里打开这篇文章。正文上方的「返回我的早报」回到刚才的位置，「早报下一条」直接读下一篇。

**你会看到**：一版按板块排好的早报，大致如下图。

![我的早报：报头、编排说明和按板块排列的卡片](../../docs/assets/readme/01-brief.png)

卡片上每个标记的含义、往期怎么看，见[读每天的早报](/features/brief)。

## 5. 在手机上打开

用手机浏览器打开同一个网址，登录后就是手机版。底部页签依次是「早报 / 文章 / 播客 / 动态 / 社交 / 榜单 / 我的」，早报在最左边。

想像 App 一样从桌面图标打开，可以把它添加到主屏幕：

1. 点底部的「我的」，再点「添加到主屏幕」。
2. 按弹出的步骤操作。以 iPhone 为例：在 Safari 中打开哆啦美，打开分享菜单，选择「添加到主屏幕」。弹窗底部可以切换查看 Chrome / Edge 等其他浏览器的步骤。

**你会看到**：先弹出一个「添加到主屏幕」窗口，列出当前浏览器的操作步骤；照做后，手机桌面上多出一个哆啦美图标。

<p align="center"><img src="./images/add-to-home-screen.png" alt="手机上的「添加到主屏幕」窗口：列出在 Safari 中添加的三步，底部可切换其他设备的指引" width="300"></p>

从主屏幕图标打开后，可能需要重新登录一次。在微信里打开时，要先通过右上角菜单换到系统浏览器，再添加到主屏幕。

电脑上也可以安装：点左侧竖栏底部的「设置」，在「外观」里找到「添加到主屏幕」。
