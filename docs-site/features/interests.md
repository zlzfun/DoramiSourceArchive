# 管理兴趣

兴趣是你关心的方向，比如「AI 编程」「具身智能」或者某家公司。设置后，早报会优先挑命中兴趣的内容，阅读器里也能按兴趣浏览全站。

![兴趣页：上方是「我的兴趣」，下面按「主题」分组列出标签卡片，已选的带紫色边框](./images/interests.png)

## 选兴趣和改兴趣

1. 点左侧竖栏的「发现」，选顶部的「兴趣」。
2. 标签按三组列出：
   - **主题**：技术方向与长期议题，例如「AI 智能体」「多模态模型」。
   - **行业**：应用领域与产业方向。
   - **实体**：具体的组织、产品、模型、协议与开源项目，例如 Anthropic、ChatGPT。
3. 点一张标签卡片就加入兴趣，卡片带上紫色边框，同时出现在顶部的「我的兴趣」里；再点一次取消。

改动会自动保存，顶部依次显示「保存中…」「已保存」。要移除某个兴趣，也可以把鼠标移到「我的兴趣」里的标签上，点出现的 ×。

找不到想要的方向，就在顶部搜索框里输入名称搜索，中英文都可以。

先选三五个最关心的，比较容易看出早报的变化。

## 兴趣会影响什么

- **早报**：命中兴趣的内容会优先入选，卡片上标「兴趣 · 某个标签」。命中兴趣的内容即使来自你没订阅的来源，也可能入选。
- **阅读器**：来源栏顶部切到「兴趣」，就能按标签浏览全站命中这些兴趣的内容，见[读文章与订阅内容](/features/reader#按订阅或按兴趣浏览)。

## 改完兴趣，早报什么时候变

改兴趣不会马上重编今天的早报。今天这一版的编排说明里会提示「你的兴趣已更新，下次编排生效」，想马上看到效果就点后面的「立即重编」；不点的话，第二天的早报会按新兴趣编排。

唯一的例外是第一次设置：新账号第一次选好兴趣点「完成」后，今天的早报会立即按兴趣重编一次。

## 常见问题

### 为什么我设置了兴趣，早报里还是没有相关内容？

当天可能没有命中这个兴趣、分量又足够的内容。可以多选几个相关的方向，或者到阅读器里切到「兴趣」看看全站最近命中了哪些。

### 标签列表里为什么找不到我之前选过的那个？

每组默认只列出最近比较活跃的标签。你已经选过的标签会一直显示在「我的兴趣」里，不会因为不活跃而消失。

### 我不想设置兴趣可以吗？

可以。不设置兴趣时，早报按你订阅的来源和新闻价值分来选稿。
