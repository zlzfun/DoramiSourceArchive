# 看动态

「动态」集中放产品更新日志、版本发布说明等短条目。想知道你关注的工具最近改了什么，可以先在这里扫一遍标题，再打开感兴趣的更新。

![动态：来源栏、更新列表和选中条目的正文](./images/updates.png)

## 怎么用

### 找到更新

点左侧竖栏的「动态」。点来源栏里的一个来源，只看它的更新；在列表里点一条，右侧打开正文。需要完整说明时，点「查看原文」。

想增加来源，去[发现](/features/discover)预览并订阅，再回到「动态」。

### 留下想再看的条目

动态也可以筛选未读、搜索和收藏。操作与[文章里的未读、标读与收藏](/features/reader#未读、标读与收藏)相同。

## 常见问题

### 为什么有些更新不在「文章」里？

更新日志和版本发布说明归在「动态」，长文归在「文章」。从左侧竖栏切换就能分别看。

### 没看到想看的更新？

先确认已经在[发现](/features/discover)订阅对应来源，再检查是否选中了单个来源或开启了未读、收藏、搜索筛选。
