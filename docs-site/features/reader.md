# 读文章与订阅内容

早报之外的所有内容都在阅读器里：你订阅的来源发了什么，按时间排好，未读的有标记，读到好的可以收藏、分享。

![阅读器：最左是竖栏，接着是来源栏和文章列表](./images/reader-columns.png)

## 认识阅读器

桌面上从左到右是四栏：

1. **左侧竖栏**：最左边一列。上面是「早报」「文章」「播客」「社交」「发现」，下面是「主题」「反馈」「设置」和你的头像。
2. **来源栏**：列出你订阅的来源，按「官方」「媒体」「个人」等分组。
3. **文章列表**：当前范围里的内容，按日期分组，最新的在上面。
4. **阅读窗**：点列表里的一篇，正文在这里打开。

## 切换内容

点左侧竖栏上的入口切换：[播客](/features/podcasts)、[社交](/features/social)各有自己的页面。点来源栏里的某个来源，只看这个来源的内容。

## 按内容类型筛选

文章列表的每一条都有内容类型：资讯、论文、教程、观点、[版本更新](/features/updates)、项目、汇编。除了最常见的「资讯」，其它类型会在来源名后面挂一枚小签。列表标题下面那排类型可以只看某一类，例如只看「论文」；只会列出当前范围里有内容的类型，再点一次回到全部。换到别的来源、兴趣或收藏后会回到全部。

只看某一类时，列表上方的「全部标为已读」会暂时收起，免得把没显示的其它类型一起标掉。右键（手机上长按）菜单里的「标记该源全部已读」照常可用，它标的是这个来源的全部内容。

版本更新用紧凑的单行显示，不铺开摘要，方便和长文混在一起扫读。

## 按订阅或按兴趣浏览

来源栏顶部有「订阅 | 兴趣」两个选项（社交页没有）：

- **订阅**：列出你订阅的来源，列表里是这些来源的内容。
- **兴趣**：列出你关注的兴趣标签，列表里是全站命中这些兴趣的内容，也包括你没订阅的来源。选一个标签就只看这个方向。

按兴趣浏览时，来自未订阅来源的条目会带一个浅色的「未订阅」，鼠标移上去变成「+ 订阅」，点一下就能订阅。怎么设置兴趣见[管理兴趣](/features/interests)。

## 未读、标读与收藏

- **未读**：标题加粗、颜色更深的就是没读过的，读过之后标题变细变浅；社交帖子读过后整条变浅。列表顶部的「全部 | 未读」可以只看未读。
- **标读**：打开一篇就算读过。列表顶部的双对勾按钮把当前范围全部标为已读，点了直接生效，没有确认；按兴趣浏览且未读很多时，可能提示「已标记一批,仍有未读,请再点一次」，再点一次即可。阅读窗右上角的按钮可以把单篇标为已读或未读。
- **收藏**：鼠标移到列表里的条目上，右侧会浮出星标，点亮就收藏了；阅读窗右上角也有星标。列表顶部的星标按钮切换「只看收藏」。

## 搜索

点列表顶部的放大镜，输入关键词，搜索当前范围里的标题和正文，命中的文字会高亮。点 ✕ 关闭搜索并清空关键词。

## 阅读一篇文章

![阅读窗顶部：来源、标题、发布时间、阅读时长、阅读量和「查看原文」](./images/reader-article-head.png)

- 标题下面一行依次是发布时间、「阅读约 N 分钟」和「阅读量 N」（全站累计打开次数）。
- 「查看原文」在新标签页打开原网页；正文末尾也有一个「查看原文 ↗」。
- 标题下的小标签可以点，点了按这个词搜索。
- 大多数文章正文上方有一张 **AI 速读** 卡片：左边是分数，分数下面写着它是新闻价值还是内容价值，右边是几句话的要点。把鼠标停在分数上可以看评分依据，见[问哆啦美与翻译](/features/ask-and-translate#ai-card)。
- 外文文章的标签行旁边有「原语言 | 译为中文」，可以把全文译成中文。
- 正文底部是「← 上一篇」「下一篇 →」，按列表顺序接着读。

## 列表里的分数与标签

列表条目右侧的数字是这篇的主分，满分 10，用于快速筛选值得读的内容，不是阅读量或你的打分。每篇最多有两个分：**新闻价值**（这件事有多重要）和 **内容价值**（值不值得花时间读完）。论文、教程、观点和汇编默认显示内容价值，其余默认显示新闻价值；新闻价值特别高（8.5 分及以上）时一律显示新闻价值。把鼠标停在数字上可以看它是哪一种分；要知道为什么给这个分，打开正文看 AI 速读卡片。

条目上的体裁标签（如「模型发布」「学术论文」）告诉你内容是什么类型；主题标签告诉你讲什么。按兴趣浏览时，还会显示命中的兴趣标签。「分析中」表示分数尚未出来，「更新中」表示正在更新，暂时看到的是上一次结果。没有分数也可以直接读正文。

正文标签用于继续找相关内容；想长期关注这个方向，去[管理兴趣](/features/interests)选择兴趣。收藏、订阅和兴趣各自独立：收藏只留下这一篇，订阅跟踪这个来源，兴趣跨来源找相关内容。

## 分享给别人

点阅读窗右上角的分享按钮，有两种链接：

![分享浮层：上面是站内链接的「复制链接」，下面是公开链接的有效期选项和「生成链接」](./images/share-menu.png)

- **站内链接**（需要登录）：点「复制链接」。对方用自己的哆啦美账号登录后，直接打开这一篇。
- **公开链接**（无需登录）：选有效期「7 天」「30 天」或「永久」，点「生成链接」，链接会自动复制。对方不用账号就能看这一篇的标题和正文，看不到你的订阅和其他内容。

站点开启游客浏览时，分享浮层只有「复制链接」，标注「免登录可看」：收到链接的人不用账号就能直接打开这一篇，还能接着逛。

生成公开链接后，浮层里会显示它还有多久过期、被打开过几次。点撤销按钮，链接立即失效；点「换新链接」会生成一条新的，旧的同时失效。一篇文章同一时间只有一条有效的公开链接。

## 右键菜单

在文章列表的条目上点右键：

<p align="center"><img src="./images/context-menu.png" alt="文章右键菜单：标为未读、收藏文章、复制站内链接、打开原文、标记该源全部已读" width="250"></p>

- 「标为已读 / 标为未读」「收藏文章」
- 「复制站内链接」「打开原文」
- 「标记该源全部已读」

在来源栏的来源上点右键，有「全部标为已读」「打开原站」「退订此源」。

## 取消订阅

- 鼠标移到来源栏的某个来源上，右侧会出现减号，点一下就退订，不会弹确认。
- 也可以右键这个来源选「退订此源」，或者在「发现」页把「✓ 已订阅」按钮点掉。

退订后，这个来源从来源栏里消失，早报也不再从它选稿（重大事件和命中你兴趣的内容除外）。想再看，去「发现」页重新订阅。

## 常见问题

### 来源名后面写着「暂不可用」？

这个来源暂时下架了，点进去会显示「该来源暂时不可用」。你的订阅还在，恢复后内容会回来；也可以直接退订。

### 列表里显示「分析中」？

这篇文章的新闻价值分和 AI 速读还没出来，稍后再看。正文不受影响，可以直接读。

### 读到一半想换设备？

未读、已读和收藏记在你的账号上，换一台电脑或用手机登录同一个账号，状态是一样的。
